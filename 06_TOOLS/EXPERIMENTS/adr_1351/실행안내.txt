통합테스트 원클릭 R1 — 로컬 WSL 개발 환경

저장소에서 실행:
  bash 06_TOOLS/COMMANDS/INTEGRATION_ONECLICK_R1.txt

현재 결과만 보기(모델 호출 없음):
  bash 06_TOOLS/COMMANDS/INTEGRATION_ONECLICK_R1.txt --status

진행 화면:
  04_EXPERIMENTS/ADR/ADR-1351-integration-oneclick-provider-matrix/artifacts/통합테스트_상태.html
결과 파일:
  같은 폴더의 통합테스트_결과.csv, summary.json, provider-selection.json
전체 원시 기록과 단계 로그:
  같은 폴더의 public-live/<문항>-<제공자>/ 및 개별 .log

동작
- R4 원본60개를 빠짐없이 목록화한다. 정답·판정 근거는 모델 질문 입력과 분리한다.
- DeepInfra(BF16), Reka(FP8), Cloudflare(정밀도 미공개), Parasail(FP8) 순서로 같은2문항을 독립 실행한다.
- 2문항 모두 설명이 나오고 원문·권한·실제전송·예산 검사를 통과한 제공자 중 관측 시간이 짧은 곳으로 공개31문항을 확인한다.
- 내부 질문/대사19개는 내부 환경 필요, 화면/출처10개는 실제 화면 확인 필요로 남긴다. 자동 통과 처리하지 않는다.
- 설명 생성 성공과 법률 의미 정답을 구분한다. CSV의 기대 결과와 실제 답변을 함께 검토해야 한다.
- 1회 실행은 최대1560물리 호출, 요청당40호출, 모델호출당180초. 보고비용$10 이상이면 다음 문항 시작을 중단한다. 현재 진행 문항 및 미보고 비용 때문에 실제 총액의 엄격한 상한은 아니다.
- 응답 불명·HTTP5xx 제공자는 이후 시험에서 제외한다. 같은 요청은 재전송하지 않으며 다른 제공자는 새로운 독립 질문으로 비교한다.
- Ctrl+C는 현재 자식 프로세스를 회수하고 중단을 기록한다. 원격 취소 완료를 의미하지 않는다.
- 같은 명령을 다시 실행해도 완료·부분 실행 폴더는 재호출하지 않는다. 완료 후 새 실험은 새 ADR과 실행 동결이 필요하다.

범위
최신 작업1350의528파일을 기반으로 격리한 시험 코드다. 제공자 목록·정밀도 지원과 종속 해시만 시험 후보에 확장했다. MAIN142·운영 기본 제공자·원문DB·현장 GENOS를 변경하지 않는다.
현재 API 목록은 지원 기능과 최근 가동률을 제공하지만 처리속도 값은 비어 있다. 제공자의 자원 여유나 장기 안정성은 이번 소표본으로 인증하지 않는다.

다음 새 독립 시험을 한 명령으로 시작:
  bash 06_TOOLS/COMMANDS/INTEGRATION_ONECLICK.txt --new
현재 시험 보기/이어가기:
  bash 06_TOOLS/COMMANDS/INTEGRATION_ONECLICK.txt
상태만 보기:
  bash 06_TOOLS/COMMANDS/INTEGRATION_ONECLICK.txt --status

--new는 현재 시험의 최종 기록이 완료된 뒤 새 ADR을 자동 예약하고, 새 제공자 목록 조회·코드 사본·기동검사·동결을 거쳐 독립 시험을 실행한다. 이전 요청의 재전송이 아니다. 원본1350 기반 작업코드가 이후 바뀌었으면 해시 검사에서 멈추므로 과거 코드 기준 결과를 최신 코드 시험으로 오인하지 않는다. 실제 실패 원인을 수정한 후 새 조건으로 비교하려면 해당 수정의 별도 동결이 필요하다.

통합테스트 원클릭 실행

저장소 폴더에서 아래 한 줄을 실행합니다.
bash 06_TOOLS/COMMANDS/INTEGRATION_ONECLICK.txt --new

결과만 확인:
bash 06_TOOLS/COMMANDS/INTEGRATION_ONECLICK.txt --status

새 실행은 1378 동결 수정본(조항 경로·공백 생성·원문별 검토·문언과 적용 범위 구분)의 전체 528파일 해시를 확인하고 새 ADR/독립 작업공간을 만듭니다.
DeepInfra / REKA / Cloudflare / Parasail의 현재 공식 제공 상태와 구조화 출력 지원을 확인합니다.
제공자별365/434 두 질문을 먼저 실행하고 원문·권한·전송·예산 검사를 통과한 설명 응답이 있는 제공자에서 공개31문항을 진행합니다.
서로 다른 정밀도와 자원 조건이므로 제공자 자체의 우열·충분한 자원을 인증하는 시험이 아닙니다.
60개 원래 질문과 기대 결과를 보존하며 내부/대사19개와 화면10개는 해당 환경에서 별도 확인해야 합니다.
정답 판정은 실제 답변을 보고 해야 합니다. 설명이 나왔다는 이유만으로 전체 통과로 표시하지 않습니다.

모델 호출은 유료입니다. 기존 실행은 재전송하지 않으며 새로 시작할 때만 --new를 사용합니다.
미확정 응답이 생긴 제공자는 해당 실행에서 중단합니다. 같은 요청을 자동 재시도하지 않습니다.
중복 실행을 차단하고 진행 화면과 전체 원본 로그를 남깁니다.
선택된 MAIN과 원문DB는 읽기 전용으로 사용합니다. 작업 폴더의 별도 변경을 기록하고, 검증한 1378 스냅샷을 독립 공간에 복사해 전체 해시를 다시 확인합니다.

모델 응답 한 번에 최대 180초, 질문 하나에 최대 1800초를 사용합니다.

365조·434조 선별에서는 실제 설명과 원문 연결을 확인하고, 두 질문 모두 ANSWER/COVERED인 제공자만 공개 문항 전체 시험에 진입합니다.

1370 실행은 공개 31문항 중 설명 29건입니다. 후속 1378은 의결권 문항 원문 전용, 434조 확인 도중 로컬 자원 기준에 따른 중단으로 전체 통과를 확인하지 못했습니다. --new는 새 독립 실험입니다. 로컬 자원 중단이 발생하면 남은 제공자와 문항을 모두 중단하고, 진행 중이었던 호출을 미확정으로 보존합니다.

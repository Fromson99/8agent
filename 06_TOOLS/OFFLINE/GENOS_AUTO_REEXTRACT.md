# GENOS 자동 재추출 실행기

실행 묶음: `09_ARTIFACTS/HANDOFF/ADR-0250/genos-auto-reextract.tar.gz`.
ADR-0250 repair rev-001을 담은 오프라인 후보다. 운영 MAIN은 변경하지 않는다.
설치·prepare·run·handoff·load-handoff의 기본 사용법은
[기존 안내](GENOS_GROUNDED_AUTHORING.md)를 따르되 이 새 묶음을 사용한다.

## 자동 처리

```text
추출 → 원문/스키마 검증
  실패 → 이전 응답 + 검증 경로/오류 + 인용 일치 좌표 후보 → 재추출
  통과 → 의미 검토
          반려/미해결 coverage → 이전 후보 + 검토 지적 → 재추출 → 재검토
          통과 → REVIEW_PASSED_CANDIDATE → DRAFT 인계
예산 소진 → FAILED 또는 NEEDS_REVIEW로 보류 → 다음 조문 계속
```

- `--max-attempts 3`: 작업별 추출 3회, 검토 3회 이하. 재추출 시 카운터를 초기화하지 않는다.
- `run --max-calls N`: 해당 실행 전체 호출 상한. 상한에서 멈춘 작업은 다음 실행에서 이어간다.
- 검증 오류의 schema 경로, 직전 모델 출력, 모델 검토 지적을 SQLite 영수증에서 복원한다.
- 잘못된 인용 좌표는 원문 안의 정확한 일치 위치를 피드백으로 알려준다. 코드가 인용을 바꾸거나
  다중 일치 위치를 임의로 선택하지 않는다. 재출력도 기존 원문/타입/단서/coverage 검증을 전부 거친다.
- 재검토는 새로 검증된 후보를 대상으로 한다. 이전 후보의 통과/반려 결과를 재사용하지 않는다.
- 저장된 응답은 재시작 시 검증부터 진행한다. 응답 저장 전 종료는 결과 불명으로 기록되며 재호출될 수 있다.
- 한 조문의 반복 실패로 다른 조문을 중단하지 않는다. 인증/서버/네트워크 오류는 기존대로 실행을
  멈추고 상태를 보존한다. 서버 복구 후 같은 명령으로 재개한다. 무한 서버 재요청은 하지 않는다.

## 버전과 재시작

기존 ADR-0248/0249 큐는 코드 해시가 달라 이 실행기로 직접 열 수 없다. 원본 큐/실패 영수증을
보존하고, 새 버전에는 같은 원본 source DB로 **새 경로에 prepare**한다. 과거 큐의 완료 작업과
실패 피드백을 새 큐로 자동 이관하는 기능은 포함하지 않는다. 전수 작업을 이미 실행 중이라면
기존 큐를 새로 prepare하여 중복 호출하지 말고 동결된 기존 실행기로 이어간다.

이 버전으로 준비한 큐는 같은 묶음·모델·revision으로 재시작하면 기존 진척과 오류 피드백이 유지된다.
예산이 소진된 특정 작업은 `rework --job-id ... --reason ...`으로 명시적인 수정 작업을 만들 수 있다.
그때도 원래 시도/영수증은 보존된다. 완료분만 부분 인계할 경우 `handoff --allow-partial`을 사용한다.

검증: 단위 테스트 20개 통과(자동 재추출, 검토 반려, 예산 상한, 다음 작업 계속,
응답 저장 후 강제 종료·재시작, 영수증 위변조 거절, DRAFT/Projection 적재 포함).
실제 Haiku/GENOS 모델이 오류를 고치는 성공률과 전체 RAG 답변 품질은 이번에 재측정하지 않았다.

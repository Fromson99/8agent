# 99_ARCHIVE

완료된 구 세대·이행 영수증·읽기 전용 자료를 둔다. 완료 ADR과 그 hash
계보는 이동 영수증이 없으면 현재 경로에 남긴다.

- `EXPERIMENTS/ROOT_ORPHANS/`: 정식 ADR 계보 밖에서 회수한 과거 작업
- `IMPORTS/`: 외부 시스템에서 가져온 원본
- `TOOLS/ORIGINAL_BACKUPS/`: 편집 전 원본 백업
- `TESTS/ORIGINAL_BACKUPS/`: 테스트 편집 전 원본 백업
- `LEGACY_DATA_ARCHIVE/`: 데이터 이행 당시 봉인된 보관본

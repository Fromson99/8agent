# examples — 두 신규 Agent의 예시 Q&A와 예시 내규

2026-08 협의된 두 과제의 첫 산출물. 답변 설계에 앞서 "무엇을 물으면 무엇이 나와야 하는가"를
고정하는 예시 Q&A 셋과, 과제5에 필요한 가상 내규 문서들이다.

모든 외규 근거 조문은 `corpus/` 실물(법령 XML·금투협 HWP·KRX)에서 실측 확인했다.
내규는 전부 **가상 예시**이며 문서 머리에 그렇게 표기되어 있다.

## 과제3 — 법·규정 조회 RAG 챗봇 (`task3-law-chatbot/`)

실무자가 업무 상황을 서술하면 필요한 법령·조문을 근거와 함께 제시한다.
범위는 법령·규정만(내규·내부 검토자료 제외 — 협의 결과).

- `qa.yaml` — 상황 질문 16건. IPO·인수 실무 시나리오 중심
  (증권신고서 30억 기준, 대표주관계약 신고, 공동주관 5%, 초과배정옵션 15%/30일,
  조사분석자료 제한, 제3자배정·실권주, 미공개정보(상장예정법인), 투자설명서,
  정정신고서, 신용평가 복수 의무, 허수성 수요예측, 상장규정, 기업실사 모범기준).

## 과제5 — 리스크관리 규정 Agent (`task5-risk-agent/`)

서브태스크 4종. 각 QA 파일이 하나의 서브태스크에 대응한다.

### 예시 내규 (`internal-rules/`, md가 원본·docx는 변환본)

| 문서 | 역할 |
|---|---|
| `위험관리기준시행세칙_v1_2024` | 구판. 감독당국 보고 시점 오류(분기 후 45일) 포함 |
| `위험관리기준시행세칙_v2_2026` | 현행. v1의 오류는 고쳤지만 개정으로 **새 상충 2건** 발생 |
| `투자및인수위험관리지침_2025` | IB 딜 승인·인수 한도·채무보증 한도 |
| `uploads/신규딜_리스크검토요청서_예시` | 서브태스크 3용 업로드 문서. 저촉 4건 + 정상 2건 |

v2에 의도적으로 심어둔 검증 포인트:
- **상충**: 제12조② 신규 장외파생 중지 기준 150%→120% (자본시장법 §166의2①3호는 150%)
- **상충**: 제18조② 경미사항 부서장 전결 개정 (금투업규정 §3-43①4호·§3-44④와 불일치)
- **음성 예시**: 제9조 내부 관리목표 500%는 외규 100%보다 보수적 → 상충 아님
- v1→v2 diff 전체 목록은 `qa/4-신구대비.yaml` 머리 주석에 있다.

`internal-rules/md_to_docx.py` — md 수정 후 `.venv/bin/python`으로 재실행하면 docx 갱신.

### 예시 Q&A (`qa/`)

| 파일 | 서브태스크 | 건수 |
|---|---|---|
| `1-내외규-qa.yaml` | 내규 또는 외규 단순 조회 | 8 |
| `2-상충점검.yaml` | 내규 ↔ 외규 상충 판정 (verdict: 상충/미비/부합) | 5 |
| `3-업로드점검.yaml` | 업로드 문서의 내·외규 저촉 점검 | 4 |
| `4-신구대비.yaml` | 내규 신·구판 대비 | 5 |

## QA 필드 공통 형식

```yaml
items:
  - id: ...
    question: 실무자 말투의 질문
    answer: 기대 답변 요지 (근거 조문 포함)
    sources: [{doc: 문서명, article: 조문}]   # doc은 corpus 폴더명 또는 예시 내규 이름
    eval_points: [답변이 반드시 짚어야 하는 포인트]  # 채점 기준
```

# 법령해석 지식 베이스 — 인덱스

법제처 유권해석(raw/expc)·입안·심사 기준 교과서(raw/moleg)·대화에서
걸러낸 지식(raw/conversations)을 개념 단위로 컴파일한 위키. raw 는 불변,
위키는 재작성 — 모든 수치·인용은 Raw 필드의 원문으로 되짚어진다. 운영
규율은 docs/expc.md §위키.

갈래 구도 (2026-08-14 재편): **해석원칙 = 해석기**(법을 어떻게 읽는가 —
답 합성의 배경), **쟁점 = 쟁점기**(질문을 어떤 쟁점으로 쪼개는가 — 검색
전 질의 분해), **법령갈래 = 지도**(법령별 사례 안내). 사례기는 위키가
아니라 raw/expc + 사례 판이다 — 모든 카드가 `#case/` 링크로 그리로
떨어진다.

## 데이터 유의

- 법제처는 같은 안건을 안건번호 둘로 중복 등재하곤 한다 — 코퍼스에 7쌍 실재
  (14-0438=14-0621 · 15-0641=15-0652 · 18-0261=18-0583 · 18-0370=18-0481 ·
  20-0446=20-0563 · 22-0333=22-0422 · 24-0239=24-0240). 사례 판에는 둘 다
  남기고(raw 충실) 위키는 한쪽만 인용한다.
- 안건명 관례상 해석 대상 법령은 「낫표」로 인용된다 — 수집·연결이 이 신호를
  쓴다. 코퍼스 법령을 인용하지 않는 사례는 raw 에 넣지 않았다.
- 교과서(raw/moleg)는 쪽 단위 이관본이라 `## p.N` 마커가 원문 좌표다 —
  법령 기준서는 p.N = 인쇄쪽 + 66, 행정규칙 기준서는 p.N = 인쇄쪽 + 4.
  가운뎃점 표기가 책마다 다르다(법령 "⋅" · 행정규칙 "･") — 인용은 원문
  표기 그대로.

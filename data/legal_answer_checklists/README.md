# 법률 답변 검증 체크리스트

이 디렉터리는 회수된 근거와 생성 답변 사이의 오류를 적발하기 위한 데이터 원장이다.
체크리스트는 답을 생성하거나 수정하지 않으며, 원문 근거를 대신하는 법적 권위도 아니다.

## 구조

- `items/LC-NNN.yaml`: 하나의 독립적이고 검증 가능한 검사 항목
- `VERSION`: 사람이 읽는 시험 버전
- `ledger.jsonl`: 추가·승격·은퇴의 append-only 변경 이력

`scope: core` 항목은 모든 답에 적용한다. `scope: routed` 항목은 질문과 회수 근거에
`triggers`가 실제로 나타날 때만 적용한다. 현재 모든 항목은 `trial`이며 제품 경로에는
연결하지 않는다.

## 누적 절차

1. 오답에서 정확한 질문·답변·근거·오류 좌표를 ADR에 보존한다.
2. 한 사례의 표현이 아니라 다른 법령에도 적용되는 검사 명제로 일반화한다.
3. PASS, FAIL, UNCLEAR 경계 예시와 저장소 내부 근거 좌표를 작성한다.
4. 새 항목은 `trial`로 추가하고 ledger에 생성 사건을 append한다.
5. 기존 정답 수용률과 오답 적발률을 그림자 평가한다.
6. 미사용 holdout에서도 기준을 통과한 항목만 `active`로 승격한다.
7. 부작용이 있는 항목은 삭제하지 않고 `retired`로 바꾸고 사유를 append한다.

## 판정 규약

- `PASS`: 해당 항목과 관련해 답변의 결론·이유가 회수 근거와 일치한다.
- `FAIL`: 답변 안에서 확인 가능한 구체적 위반이 있다.
- `UNCLEAR`: 필요한 근거가 없거나 인용·범위가 모호해 판정할 수 없다.
- `NOT_APPLICABLE`: 라우팅은 됐지만 해당 답변이 그 명제를 실제로 주장하지 않는다.

blocker의 FAIL은 REJECT, blocker의 UNCLEAR은 UNCLEAR로 집계한다. 나머지만 ACCEPT한다.
검증 결과가 ACCEPT가 아니더라도 이 계층은 답을 고치지 않고 검토 큐로만 보낸다.

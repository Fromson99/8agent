사진의 E rehydration 오류: E 근거의 extent/cursor 검증을 실행 전으로 이동합니다.
기존 exact/null 수정 제안과 모델 재진입을 재사용합니다. 원문 범위·해시·세대 검증은 유지합니다.
런타임 파일 1개와 해당 엔진/PIPELINE pin만 변경합니다. 데이터 재구축·워크플로우 Python 교체·환경변수 변경은 필요 없습니다.
기존 ~/DEV Git checkout에 백업 후 적용합니다. 이미 적용된 파일은 확인하며 미지원 코드·다른 코드 drift는 쓰기 전에 거부합니다.
MODE=verify는 실제 generation을 선택하고 commit한 checkout에서 실행합니다. 그 commit을 push하고 코드서빙 새 리비전을 배포합니다.
질문 검증은 워크플로우 테스트 화면에서만 합니다. 현장 배포·실제 내부 모델의 복구 성공은 미확인입니다.
원복은 MODE=rollback과 적용 로그 BACKUP_READY 경로를 사용하고 이전 코드서빙 리비전으로 복귀합니다.

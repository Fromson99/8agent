모델 도구 호출의 ProposalError를 수정 요청으로 돌려주고 원래 질문에 다시 응답하게 합니다.
E 근거 재읽기의 실행 전 검증을 포함하며 handler에서 뒤늦게 판명한 호출 오류도 기존 repair loop로 돌려줍니다.
거절한 결과를 근거로 저장하지 않습니다. 성공한 근거·출처 선택·독립 행동은 보존합니다. 실제 SQL·저장소·계약·통신 오류와 모델 예산은 기존대로 처리합니다.
기존 EVIDENCE_READ 패치를 대체합니다. 해당 패치 적용 전/후의 등록된 코드에서 모두 적용 가능합니다.
런타임 파일 2개와 엔진/PIPELINE pin만 변경합니다. 기존 ~/DEV checkout에 백업 후 적용하고 commit 검증 후 push·새 코드서빙 리비전을 배포합니다.
데이터 재구축·워크플로우 Python 교체·환경변수 변경은 필요 없습니다. 질문 검증은 워크플로우 테스트 화면에서만 합니다.
MODE=rollback과 적용 로그 BACKUP_READY 경로로 코드/pin을 복구한 뒤 이전 리비전으로 돌아갑니다. 현장 배포·내부 모델 성공은 미확인입니다.

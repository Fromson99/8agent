GENOS 팀별 로그·질문 답변 요약 패치 R3 (2026-09-28)

TEAM_REQUEST_LOGS R1/R2 대신 이번 R3 ZIP/실행 TXT를 사용하세요.
R2의 incompatible report function: DeferredReport.__init__ 오류를 재현했습니다.
PACKAGE_HASHES PASS 이후 함수 검사에서 소스 쓰기 전에 중단한 실행은 원복할 변경이 없습니다.

원인과 수정
R2가 Python 3.14에서 ast.dump로 만든 함수 해시를 GENOS에서 비교했습니다.
Python 3.13부터 빈 AST 필드의 출력 방식이 바뀌어 같은 함수도 3.11과 해시가 달랐습니다.
Python 3.11에서 사진의 생성자 오류 해시를 정확히 재현했습니다:
  ebec1d1454229f6c8d6d9fbef0b684c6dc61fa6f46d663f172efee0d2898ac54
R3는 AST 필드를 고정 형식으로 직렬화해 빈 필드도 보존합니다.
3.12에 추가된 빈 type_params만 정규화하며 실제 함수/상수/호출 차이는 그대로 검사합니다.
함수 9개와 필수 import만 수정하고 무관한 현장 코드 바이트는 보존합니다.
호환되지 않는 함수는 목록으로 함께 표시합니다. 기존 engine/PIPELINE/소스/스키마의
SHA-256 검증은 그대로 적용합니다. 기존 해시 불일치를 새 pin으로 승인하지 않습니다.

실제 Python 3.11과 로컬 3.14에서 함수 서명·변환 결과 일치를 확인했습니다.
3.11 프로세스에서 ~/DEV → 실제 Git checkout 링크, LF/CRLF 파일, 적용·재실행·commit
바이트 검사·원복과 모의 요청의 팀별 plain .log/질문답변.xlsx/CSV 생성을 확인했습니다.
현장 파일 전체 내용/함수 9개와 generation/서빙 결과는 현장 검증 전까지 미확인입니다.

사진에 함께 나온 SSE 오류
Symlink is not an apply target: /home/genos/DEV는 별도 SSE R1 설치 오류입니다.
이미 발송된 GENOS_SSE_20260928_R2_APPLY.txt를 사용하세요. TEAM_REQUEST_LOGS R3가
SSE 설치기나 워크플로우 본문을 변경하지는 않습니다.

적용

파일이 현재 폴더에 있으면 TRANSFER/를 빼고 실행하세요.
필요할 때만 DEPLOY_ROOT=/기존/실제/Git/checkout, PYTHON_BIN=/기존/python3를 지정합니다.

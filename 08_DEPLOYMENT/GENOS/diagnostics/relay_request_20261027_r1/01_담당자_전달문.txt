제목: 법제처 API 중계 조회 확인 및 별표·서식 다운로드 연동 요청

안녕하세요. 안내해 주신 DRF 경로로 법령 데이터를 수신하는 작업을 진행하려고 합니다.

호출 시스템은 GENOS의 수집·구조화용 코드서빙이며, 목표 흐름은 Dataiku 일일 배치 → GENOS → API 중계 → 법제처 조회 → Dataiku 결과 보관·적재입니다. 최초 전체 수집 후 매일 변경 사항을 확인할 계획입니다.

이번 법제처 API 대상은 법령 37종과 행정규칙 12종, 총 49종입니다. 전체 명칭은 첨부 CSV에 정리했습니다. 우선 아래 네 요청의 실제 XML 수신을 확인하고자 합니다.

1. 자본시장과 금융투자업에 관한 법률 목록 조회: lawSearch.do / target=eflaw
2. 위 법률의 현행 본문 조회: lawService.do / target=eflaw / ID=010513
3. 금융투자업규정 목록 조회: lawSearch.do / target=admrul
4. 금융투자업규정 본문 조회: lawService.do / target=admrul / LM=금융투자업규정

원천 주소는 http://www.law.go.kr/DRF/ 기준으로 작성했습니다. 각 요청의 전체 파라미터와 기존 샘플에 맞춘 target_url 헤더·GET 쿼리는 첨부 명세에 있습니다. OC는 승인된 법제처 인증값을 별도 보안 경로로 전달·주입하겠습니다. 해당 OC의 서비스 사용 범위와 실제 중계 출구 IP 등록도 확인 부탁드립니다.

회신 시 요청별 HTTP 상태, Content-Type, 응답 XML 파일, 호출 시각, 실제 사용한 중계 URL·target_url·쿼리(OC 등 인증값 제외)를 부탁드립니다. 동일한 요청을 GENOS에서 재현할 수 있는 호출 예제도 함께 부탁드립니다.

기존 GENOS 점검은 중계서버 TCP 연결 후 TLS 단계에서 종료되어 HTTP 요청 전송에 도달하지 못했습니다. 당시 접속 주소는 https://45.101.64.86:8443 이며, 2026-10-23 13:56:21~13:56:31 KST에 TLS reset이 관찰됐습니다. GENOS에서 사용할 정확한 중계 프로토콜·도메인·포트·경로, 필수 인증/인증서·프록시 여부와 허용 출발지 IP를 확인 부탁드립니다. 원천의 HTTP 주소와 GENOS가 접속할 중계 주소는 별도로 확인하고자 합니다.

추가로 본문에 연결된 별표·서식의 HWP/HWPX/PDF 등 원본 파일도 필요합니다. XML 응답의 실제 다운로드 링크를 이용할 수 있도록 /LSW/flDownload.do 및 실제 반환되는 관련 다운로드 경로에 대한 방화벽·중계 지원을 요청드립니다. 필요한 신청 항목과 작업 범위를 안내 부탁드립니다. 파일 다운로드 연동을 진행하는 동안 DRF의 목록·본문 수신부터 먼저 확인하고자 합니다.

호출 빈도·응답 크기·타임아웃 제한, 한글 쿼리 전달 방식, 원천 오류 응답 전달 방식도 알려주시면 수집기에 반영하겠습니다.

감사합니다.

내규 위임·준용·참조 연결 점검 — 실행 파일

요청하신 표현 기반 검색과 연결 점검 도구를 보냅니다. 위임·준용·따름·정함·관련 준칙·별도 정함 등 13가지 표현 묶음과 신상품을 실제 내규 원문에서 찾아, 참조 색인·대상 원문·구조 좌표·해시·역참조를 확인합니다.

코드 검토상 기존 참조 서술어 사전은 구조 마커 판별용입니다. 표현이 있다는 것만으로 문서 간 연결이 생성되지는 않습니다. 사진의 “관련 준칙에서 정한 바에 따라”처럼 문서명·조문이 생략된 지점을 우선 확인할 수 있게 했습니다. 사진만으로 연결 누락을 확정한 것은 아닙니다.

TRANSFER 폴더에서 세 줄 실행

첨부 ZIP을 실제 업로드한 TRANSFER 폴더를 현재 위치로 두고 실행하세요.

python3 -m zipfile -e ./GENOS_INTERNAL_LINK_AUDIT_20261021_R1.zip ./GENOS_INTERNAL_LINK_AUDIT_20261021_R1
bash ./GENOS_INTERNAL_LINK_AUDIT_20261021_R1/RUN_INTERNAL_LINK_AUDIT.txt check
bash ./GENOS_INTERNAL_LINK_AUDIT_20261021_R1/RUN_INTERNAL_LINK_AUDIT.txt run

기본값은 risk_team 내규 전체입니다. ~/DEV/00_SYSTEM/GENOS_SERVING_PATHS.json의 고정 generation과 hash를 사용합니다. 설정이 없으면 실제 선택 경로를 --generation /실제/선택된/generation/절대경로로 지정하세요. 예전 NFS 경로나 최근 폴더를 추정하지 않습니다.

상품위원회 문서만 먼저 보려면 마지막 명령에 --document-contains 상품위원회를 추가합니다. 용어 추가는 --keyword 신상품심사처럼 지정할 수 있습니다.

HTML 내려받기

실행 마지막의 DOWNLOAD_ZIP 파일을 코드스페이스 파일 탐색기에서 내려받고, 내부 PC에서 압축을 풀어 index.html을 여세요. 검색창에 신상품 또는 관련 준칙을 입력하면 내규 출처·실제 원문·저장된 정의·연결 상태를 한 행에서 볼 수 있습니다. 대상 링크를 누르면 실제 연결 원문이 열립니다.

상태는 참조 없음 / 같은 문장에 연결 존재(의미 대응 검토 필요) / 대상 미확정·부분 연결 / 원문·구조·색인 불일치 / 권한 범위 밖 / 구형 계약으로 구분합니다. 인접한 참조를 위임 대상으로 자동 확정하지 않습니다.

합성 legacy/compact 자료 검사, 최종 ZIP의 실행·오류 보존·중복/변조 거부 10개 명령 검증을 마쳤습니다. 모델·네트워크 호출은 없고 원문·색인·MAIN·배포를 변경하지 않습니다. 실제 GENOS 내규 결과는 현장 실행으로 확인해야 합니다. 기존 generation용 도구이며 Oracle publication이나 동적 관계 원장 검증을 대신하지 않습니다.

첨부: 도구 ZIP / 별도 전체 실행 TXT / 상세 안내 TXT. ZIP 안에도 같은 실행 TXT가 있습니다. 생성 보고서는 내부 원문을 포함하므로 허용된 내부 환경에서 열람하세요.

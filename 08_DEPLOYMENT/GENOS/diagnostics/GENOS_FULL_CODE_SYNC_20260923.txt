sha256sum 값이 위 값과 다르거나 verify가 실패하면 여기서 중단합니다. 기존 DEV 코드는 그대로입니다.

2) 새 코드 폴더에서 기존 NFS generation을 입력으로 새 fulltext 결속 세대를 만듭니다. 기존 세대/영수증은 수정하지 않습니다. 코드스페이스에 GENOS_GENERATION이 비어 있으면 아래 명령을 실행하기 전에 코드서빙 binding.resolved 로그의 generation_path를 확인하여 GENOS_GENERATION에 실제 기존 generation 절대 경로를 설정합니다. 빈 문자열을 --source-generation에 전달하지 마세요.

먼저 아래 명령을 복구에 사용할 동일한 Python에서 실행합니다. 코드 ZIP에는 Python 패키지가 들어 있지 않습니다.

ModuleNotFoundError라면 코드스페이스의 이 python3 환경에 requirements.txt 고정 버전 kiwipiepy==0.23.2, kiwipiepy-model==0.23.0을 GENOS에서 허용된 내부 패키지 소스/휠로 설치한 뒤 위 검사를 다시 실행합니다. 다른 가상환경에 설치하면 이 명령에는 적용되지 않습니다. 향후 코드서빙의 Python 환경에도 같은 버전이 필요하며, 코드스페이스 설치만으로 코드서빙 의존성이 설치되지는 않습니다. 기존 r4 ZIP의 복구 스크립트는 의존성 검사 전에 NFS 복사를 시작하므로, 사진과 같은 실패 뒤에는 아래 검사를 통과한 후 원래 generation 경로로 재실행합니다. 실패한 복사는 임시 staging을 삭제하며 기존 generation을 수정하지 않습니다.

이 재실행은 앞선 build-all/구조화/용어집 구축을 다시 하지 않습니다. 이미 완료된 원래 generation을 사용합니다. 다만 실패한 r4 복구 명령의 임시 복사본은 삭제되었으므로 source 검증과 NFS 복사는 다시 수행합니다.

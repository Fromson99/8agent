2026-10-18 MAIN82 최소 모델 출력 인계
정본: basis-link-lifecycle-20261016-r1 / active pointer generation 82 / ADR-0853 integrated
서빙 파일 370개 모두 선택 MAIN과 동일. 최신 워크플로우와 압축이 이미 함께 반영돼 있어 포인터를 변경하지 않는다.
포함: 대사 1.9.0, 내규 근거 발굴 1.0.0, 근거 링크 검토/승인/철회, 편집기 비동기 수정, 최소 출력 재조립, Oracle DP 연결.
압축은 필요한 판단/이유/인용을 삭제하지 않으며 스키마의 필수 고정값과 확정 가능한 빈 구조만 시스템이 복원한다.
구문/필드/근거/권한/상태 검증과 원본 모델 응답을 보존한다. 기존 단계별 단일 복구 담당과 총 예산을 그대로 사용한다.
허용되지 않은 출력/상충 고정값은 오류로 남긴다. codec은 추가 모델 재시도를 만들지 않는다.
설치 복구 담당: RUN의 코드 교체기. 중단 시 같은 apply가 백업으로 복구하고 재개하며, 변경된 사용자 코드는 자동 덮어쓰지 않는다.
check/apply는 코드·작은 설정/manifest만 검사한다. 데이터·검색 선택·DP 설정을 바꾸지 않는다.
최종 상태: CODE_APPLIED_DEPLOYMENT_PENDING. commit/gate/push/리비전/편집기 저장/워크플로우 테스트는 별도다.
실제 LLM 호출, GENOS busy 여부, timeout 해소 및 출력 토큰/지연 감소는 현장 미확인이다.

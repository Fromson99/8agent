현장 실행
ZIP과 APPLY TXT를 기존 ~/DEV/TRANSFER에 저장합니다. 기존 Git checkout에 적용합니다.
~/DEV 별칭은 사진처럼 /workspace 실제 root로 해결됩니다. 현장은 python3를 사용하며
실행 로그에 실제 sys.executable과 버전을 남깁니다. Python 3.11 이상이 필요합니다.

cd "$HOME/DEV/TRANSFER"
export GENOS_DEV="$HOME/DEV"
export GENOS_GENERATION="/nfs-root/diamo/8-agent/term-releases/financial-risk-success-20261005-schema-r2/generation"
bash GENOS_INVESTIGATION_COMPLETION_20261007_R1_APPLY.txt inspect
bash GENOS_INVESTIGATION_COMPLETION_20261007_R1_APPLY.txt all "$GENOS_GENERATION"

실제 현장 generation 선택이 달라졌다면 GENOS_GENERATION에 정확한 절대경로를 지정합니다.
기본값은 사진에서 선택된 기존 generation이며 날짜순 폴더를 자동 선택하지 않습니다.

inspect는 코드/Git 상태를 읽고 CHECKOUT_PREFLIGHT JSON을 기록합니다. 적용/커밋/push는
수행하지 않습니다. all도 동일 검사를 먼저 수행합니다. 관리 대상의 알려진 해시와
다른 수정은 덮어쓰지 않고 중단합니다. 관계없는 staged/추적 변경 및 merge 충돌도
파일 적용 전에 중단합니다. 관리 파일에 working tree와 다른 미확인 staged 내용이
있어도 보존하고 중단합니다. 원문이나 키 내용은 보고서에 넣지 않습니다.

보고서에는 다음 목록이 있습니다.
  mismatches: 허용되지 않은 코드의 경로와 실제/목표 해시
  unrelated_tracked_or_staged_paths: 이번 ZIP 범위 밖의 수정 파일명
  unknown_staged_bytes: 관리 파일에서 미확인 상태로 staged된 내용의 경로/해시
  unmerged_paths: merge 충돌 파일명
사진 2의 미표시 수정 파일명은 이 보고서로 확인할 수 있습니다. 보고서 파일 경로는
CHECKOUT_PREFLIGHT 이벤트에 출력됩니다. 미확인 변경이 남으면 원래 변경을 검토해
분리 처리한 뒤 다시 실행합니다. 일괄 reset/checkout/stash/commit으로 우회하지 않습니다.

all 순서
  적용 전 코드·Git 상태 → 선택 generation/cache 확인 → 파일별 백업/적용 →
  실제 checkout service/service.py 로더 검사 → generation E2E 및 verify_assets →
  ZIP 범위 파일만 commit → 같은 checkout release gate → 기존 remote/branch로 push

코드서빙·워크플로우는 별도 반영
GIT_PUSHED/RELEASE_GATE_PASS의 정확한 commit과 같은 generation으로 새 코드서빙
리비전을 배포합니다. 다음 설정과 기존 내부 모델·임베딩·인증 설정을 대조합니다.
  SEMANTIC_LLM_BACKEND=genos
  GENOS_RAG_IMPLEMENTATION=legal-agent-unified-v6
  GENOS_GENERATION=이번 실행에서 검증한 절대경로
  GENOS_RUNTIME_DIR=/nfs-root/diamo/8-agent/runtime
키 값을 사진/메일/로그로 출력하지 않습니다. 워크플로우 Python 단계는 제공한
WORKFLOW_PASTE_ALL TXT 전체를 편집기에 반영합니다. Git push만으로 편집기가 바뀌지 않습니다.
실제 warmup/질의는 워크플로우 테스트 화면에서만 확인합니다. 코드서빙 직접 테스트
UI/API 실행을 요구하지 않습니다. 요청 ID·내부 model ID·시간·코드 리비전·generation과
실제 판단/행동/이유 체인, 원문 인용, 상태 보존을 기록합니다.

원복

이전 코드 리비전/검증된 generation, 이전 워크플로우 전체 코드로 복귀합니다.

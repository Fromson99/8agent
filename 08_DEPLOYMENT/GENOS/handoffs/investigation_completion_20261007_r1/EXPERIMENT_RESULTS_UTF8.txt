# 조사 완료 계약의 로컬 MAIN 반영

선택 릴리스는 `investigation-completion-v6-20261007-r1`, 활성 포인터 generation **44**다. 검증 후보·작업 코드·선택 릴리스의 서빙 268파일 해시가 일치한다. 세대 `01_DATA/TERM_RELEASES/local-genos-parity-20261006-r1/generation`를 유지했다.

읽기·채택 분리, 보류 원문 재열람과 기존 RETURN_TO, 진전 없는 반복 종료, 마무리 예산·같은 요청 재개 예산, 쟁점별 부족분과 제한된 재조사, 실제 원문 span 인용, 판단 이후 새 법률 문장 생성 방지, 오류 분류·확인된429 재시도 및 워크플로우·직접 채팅 JSON/SSE의 완료·부분·미완료·상류실패 표시를 연결했다. 일반 규칙 설명과 개별 사실 적용의 구분을 지침에 보완했다. **개인정보 자료제출 질문(REG-IC24)은 감독 권한 맥락을 정정·삭제 증거자료 제출로 좁히는 의미 오류가 이번에도 남았다.** 인용 정확성과 응답 성공을 의미 정답으로 보지 않는다.

핵심 계약30개와 최신 채팅 JSON/SSE 소비자25개 통과. 공통 gateway 회귀는 후보와 기존 MAIN 모두18통과·3실패로 동일하며 모든 저장소 테스트 통과를 주장하지 않는다. 동결 패키지·엔진 의존성·접근권한·워크플로우 소비 검사를 통과했다. 새로운 주 조문16질문의 응답은 14/16, 단일 자동 평가 정답은 14/16, 알려진 회귀 응답은 10/12다. 결과 분류는 {'correct': 14, 'judgment_mistake': 0, 'no_answer': 2, 'not_run': 0}이다. 의미 정답을 모두 맞혀야만 승격하는 기준은 사용하지 않았고, 원문·권한·해시·상태·게시 무결성을 검사했다.

실제 새 `service.service`에서 HEALTH/RAG_SEARCH/RAG_ASK를 확인했다. 실제 native binding이 평가 binding과 일치하며, 종전 마무리/재시도 프로필 보정 차이도 해소했다. 실제 확인 답변은 [서비스 실행 영수증](artifacts/main-smoke.json)에 보존했다. 평가 대상 밖 법률·내부 데이터 품질 인증은 아니다.

금융소비자 보호에 관한 법률 제31조 제4항에 따라, 금융교육협의회의 의장은 금융위원회 부위원장이 된다.

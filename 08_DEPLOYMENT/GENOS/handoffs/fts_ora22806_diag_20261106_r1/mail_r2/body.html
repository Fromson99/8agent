ORA-22806 진단 B R2 — 바인드 모양별 확인 (읽기 전용)

R1 결과 요약: ORDS 접속·게시본 열기는 통과. 본문검색 SQL 중 실패한 문장에만 ① 같은 바인드 이름이 여러 번(:q_token0 3번 등) ② 숫자 바인드(:q_documents_n, :q_average)가 있고, 통과한 부분 SQL과 A의 Q1(바인드 없음, ORDS로 2,049행)에는 둘 다 없었습니다.

R2: 실패한 문장을 그대로 / 숫자만 값으로 / 바인드 이름만 자리마다 다르게 / 둘 다 바꿔서 실행하고, DUAL로 작은 확인 7개를 합니다.

실행 — R1을 돌린 같은 터미널, TRANSFER 폴더에서:

bash ./FTS_ORA22806_DIAG_R2.txt

새 터미널이면 export 3줄(ORACLE_ORDS_SCHEMA / CLIENT_ID / CLIENT_SECRET, = 앞뒤 띄어쓰기 없이)을 먼저 넣습니다.

보내줄 결과: 화면 마지막 부분(W_..., D... 줄의 PASS/FAIL) 사진 또는 FTS_ORA22806_DIAG_RESULT_R2.json.

로컬 확인: 개발계 실버 17표 임시 환경(Oracle 23.26.3)에서 20단계 모두 통과, 바꾼 문장들이 원래 문장과 같은 결과 수. 현장 실행은 아직입니다.

MAIN142 통합 코드 + 별도 워크플로우 Python 적용 안내

대상: GENOS 코드스페이스의 기존 ~/DEV Git checkout 및 GENOS 워크플로우 Python 편집기.
릴리스: gold-workflow-review-20261104-r1 / 로컬 MAIN142 / 서빙 528파일.
Gold B003 선택, 원문 클릭 펼치기, 검토 실패 항목 설명, 같은 대화의 후속 재검토를 함께 포함합니다.
이번 MAIN142는 앞서 보낸 MAIN140 및 별도 Gold/검토 수정 전체 ZIP을 대체합니다.
이전 전체 ZIP을 이번 ZIP 위에 차례로 덮어쓰지 않습니다.

1. 코드 파일 반입
아래 두 첨부를 같은 TRANSFER 폴더에 원래 이름 그대로 업로드합니다.
  MAIN142_FULL_ORACLE_20261104_R1.zip
  MAIN142_ONECLICK_R1.txt
ZIP은 미리 풀지 않습니다. 해당 TRANSFER 폴더에서 한 줄 실행:
  bash MAIN142_ONECLICK_R1.txt

기존 ~/DEV 링크의 실제 checkout을 찾아 검사 → 백업 → 코드 반영 → 엔진 검증합니다.
Python 3.11 이상 필요. 완료 표시: MAIN142_ONECLICK_DONE / MAIN142_EXIT=0.
기존 데이터·환경변수·Git 이력은 보존합니다. 기존 app.js는 첨부에서 제외하며 동일 해시를 먼저 검사합니다.
정상 설치 후 다음 명령으로 재확인할 수 있습니다:
  bash MAIN142_ONECLICK_R1.txt status

2. Git 및 코드서빙 반영
변경 검토/스테이징:
  bash MAIN142_ONECLICK_R1.txt stage
  git -C ~/DEV diff --cached --stat
기존 절차로 실제 checkout에서 commit한 다음:
  bash MAIN142_ONECLICK_R1.txt gate-code
이 검사는 첨부 코드와 commit된 checkout의 일치 검사입니다. 실제 데이터 연결 검사는 별도입니다.
기존 절차로 push하고 코드서빙 새 리비전을 배포합니다.
시작 명령은 유지합니다:
  python3 08_DEPLOYMENT/GENOS/start_sse.py
실행 TXT는 push나 리비전 배포를 자동 수행하지 않습니다.

3. 환경변수
ENVIRONMENT.txt를 따릅니다. 기존 Silver를 계속 쓴다면 기존 설정을 유지합니다.
Gold를 선택하려면 실제 Gold owner와 완료된 게시 채널/ID를 설정합니다.
코드만 교체한다고 데이터나 테이블이 Gold로 이관되는 것은 아닙니다.

4. 워크플로우 별도 적용
첨부 MAIN142_WORKFLOW.py는 MAIN142의 워크플로우 전체 원본과 SHA256이 같습니다.
GENOS 워크플로우 Python 편집기에 파일 전체 내용을 교체하거나 파일 가져오기를 사용하고 저장·배포합니다.
코드서빙 ZIP 반영만으로 별도 워크플로우 편집기 내용이 바뀌지는 않습니다.
기존 코드서빙 연결 주소와 인증 설정을 유지합니다.

5. 완료 확인
새 코드서빙 리비전에서 health 및 원문 조회를 확인합니다.
워크플로우 테스트에서 SSE_CHECK의 answer_display_revision은 다음 값입니다:
  workflow-review-followup-20261104-r1
질문 후 출처와 개별 원문을 눌러 펼치고, 정상 설명이 유지되는지 확인합니다.
검토 실패 시 실패 항목과 후속 요청 안내가 보여야 합니다.
같은 chatId/session_id의 새 메시지로 다음처럼 요청합니다:
  방금 실패한 답변 검토를 이미 확보한 원문을 재사용해서 다시 해줘. 주장과 근거의 연결을 확인하고, 질문에 대한 설명과 남은 미확인을 함께 알려줘.
같은 request_id 재조회는 기존 결과 조회이며 재검토가 아닙니다.
검토 실패를 성공으로 바꾸거나 재검토 성공을 보장하지 않습니다.

6. 중단/원복
main142-install-logs에 전체 로그와 백업 경로가 남습니다.
설치 완료 뒤 같은 명령을 다시 실행하면 동일 코드 여부를 확인합니다.
중간 실패 시 출력된 백업 경로를 보존하고 먼저 원복합니다:
  bash MAIN142_ONECLICK_R1.txt undo --backup '출력된 백업 폴더 절대경로'
원복 후 파일 상태를 확인하고 다시 설치합니다. 배포한 리비전은 플랫폼에서 별도로 되돌립니다.
새 v3 검토 기록을 구 MAIN140 reader에 강제 재사용하지 않습니다.

7. 검증 범위
로컬 MAIN142: 준비 검사110개, 실제 선택 서비스16개, Gold 연결기9개 통과.
실제 GENOS 내부 모델·리비전·화면 검증은 현장에서 진행해야 합니다.
최신 작업 ADR1332 수정은 이 MAIN142에 포함되지 않습니다.
GENOS는 DP=oracle로 사용하며 이 ZIP에는 로컬 원문 데이터/선택 포인터를 넣지 않았습니다.

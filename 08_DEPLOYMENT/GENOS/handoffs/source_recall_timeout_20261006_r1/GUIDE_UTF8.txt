GENOS 원문 수집 시간 제한 제거 R1

사진의 source recall policy time limit을 발생시킨 원문 수집 180초와
하위 global 회수 120초 타이머를 제거합니다. 최소 단위 fulltext와 기존 조 단위
원문 읽기 모두 수집 단계의 별도 경과 시간으로 중단하지 않습니다.
전체 요청 deadline, 모델 통신 timeout, 읽기 건수/문자/행동 예산은 유지됩니다.
v6 기본 파일 프로필의 전체 요청 시간은 1800초이며 실제 선택된 프로필은 현장 설정을 따릅니다.
법률 무관 입력의 v6 분기 누락은 이 패치에서 수정하지 않습니다.

기준: GENOS_V6_REQUEST_INPUT_20261006_R2 또는 GENOS_NFS_STATE_SQLITE_20261006_R1.
이번 ZIP은 NFS SQLite R1도 포함하므로 두 기준 모두에서 적용 가능합니다.
compact 용어집 reader, source v2 서비스 로더, 입력 상한 제거와 SQL/AD 설정을 보존합니다.
원문/용어집/연결/색인/상태 DB 재구축과 CURRENT 전환은 없습니다.
새 라이브러리와 워크플로우 Python 교체는 필요 없습니다.

첨부 ZIP과 실행 TXT를 같은 ~/DEV/TRANSFER 폴더에 올립니다.
기존 Git checkout인 ~/DEV에서 다음을 순서대로 실행합니다.

  cd ~/DEV
  bash TRANSFER/GENOS_SOURCE_RECALL_TIMEOUT_20261006_R1_APPLY.txt check
  bash TRANSFER/GENOS_SOURCE_RECALL_TIMEOUT_20261006_R1_APPLY.txt apply
  bash TRANSFER/GENOS_SOURCE_RECALL_TIMEOUT_20261006_R1_APPLY.txt verify

모든 실행은 시작부터 source-recall-timeout-logs에 stdout/stderr와 종료 상태를 남깁니다.
apply는 파일별 백업 후 적용하며 재실행 시 이미 설치한 코드를 검증합니다.
알 수 없는 기존 코드 해시는 보존하고 적용 전에 중단합니다.
GENOS 현장 명령은 python3이며 실행 로그에 인터프리터 경로와 버전을 남깁니다.

verify는 기존 선택 generation을 현재 checkout의 코드로 검사합니다.
GENOS_GENERATION이 없으면 이전 R2가 명시한 다음 경로를 사용합니다.
  /nfs-root/diamo/8-agent/term-releases/financial-risk-success-20261005-schema-r2/generation
다른 세대를 선택했다면 실제 절대경로를 마지막 인수로 지정합니다.
  bash TRANSFER/GENOS_SOURCE_RECALL_TIMEOUT_20261006_R1_APPLY.txt verify /실제/generation/절대경로

적용 파일을 검토하고 기존 ~/DEV에서 커밋한 뒤:
  bash TRANSFER/GENOS_SOURCE_RECALL_TIMEOUT_20261006_R1_APPLY.txt gate
전체 gate가 통과한 commit을 push해 같은 generation 설정으로 새 코드서빙 리비전을 배포합니다.
Git push와 코드서빙 리비전 배포는 별도입니다. 파일 적용만으로 기존 리비전이 바뀌지 않습니다.
최종 질의 확인은 워크플로우 테스트 화면에서만 수행합니다.
긴 원문 검색에서 source recall policy time limit이 더 이상 발생하지 않는지 요청 ID로 확인합니다.
전체 요청 deadline/통신/기타 예산 오류는 별도입니다.

원복은 apply에 출력한 정확한 BACKUP/RECOVERY 경로를 지정합니다.
  bash TRANSFER/GENOS_SOURCE_RECALL_TIMEOUT_20261006_R1_APPLY.txt rollback /정확한/백업경로
데이터/상태 DB/환경변수는 삭제하지 않습니다. 배포했다면 이전 검증 리비전과 generation 설정으로 복귀합니다.

관련 합성 계약 검사 48개 통과. 두 기준 반입본에서 실제 실행 TXT의 검사/적용/재실행/
원복/미등록 변경 보존, 설치 코드의 타이머 제거, 엔진 pin과 compact reader 보존을 확인했습니다.
과거 v3 계약을 요구하거나 배포 범위 밖 연구 packager를 가져오는 네 검사 항목은
별도 진단으로 기록하며 현재 운영 계약의 통과로 보고하지 않습니다.
실제 GENOS generation manifest 해시, 내부 모델 질의 및 리비전 적용은 현장 확인 전까지 미확인입니다.

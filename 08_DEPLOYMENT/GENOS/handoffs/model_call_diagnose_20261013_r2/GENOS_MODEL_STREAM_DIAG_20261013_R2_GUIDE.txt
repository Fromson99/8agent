삼성메일 첨부 안내 — GENOS 모델 스트림 종료 진단 R2

이번 COMPOSE / model stream ended before completion 진단에는 이 R2를 사용합니다.
기존 모델 호출 요약 R1의 정보를 포함하고 저장된 stream_events 요약을 추가했습니다.
최종 답변 토큰 스트리밍 패치 R2와는 별개의 읽기 전용 진단 도구입니다.
기존 요청 JSON을 읽고 새 .stream_diag.txt만 만듭니다. 모델 호출·설치·배포는 없습니다.
원문·질문·프롬프트·답변 본문은 출력하지 않습니다.

1. ZIP을 ~/DEV/TRANSFER에 반입 후 실행합니다.
python3 -m zipfile -e ~/DEV/TRANSFER/GENOS_MODEL_STREAM_DIAG_20261013_R2.zip ~/DEV/TRANSFER/model-stream-diag-r2
cd ~/DEV/TRANSFER/model-stream-diag-r2
sha256sum -c PACKAGE_SHA256SUMS.txt
bash GENOS_MODEL_STREAM_DIAG_20261013_R2_RUN.txt "/실제/요청보고서.json"

/실제/요청보고서.json은 실패 요청의 전체 JSON 절대경로로 바꿉니다.
사진의 .log와 같은 요청의 .json을 선택합니다. .log/.txt/.llm_raw.jsonl은 입력이 아닙니다.
기존 폴더는 /nfs-root/diamo/8-agent/rag-request-reports/2026-10-13/financial_team/ 입니다.
GENOS_SHARED_LOG_DIR이 다르면 실제 설정 경로를 사용합니다.

2. ZIP 대신 별도 첨부 RUN TXT를 사용할 때:
bash ~/DEV/TRANSFER/GENOS_MODEL_STREAM_DIAG_20261013_R2_RUN.txt "/실제/요청보고서.json"

3. 출력
같은 폴더에 .stream_diag.txt를 새로 만들고 마지막 24줄을 화면에 표시합니다.
기존 출력이 있거나 쓰기 권한이 없으면 새로운 출력 경로를 지정합니다.
bash GENOS_MODEL_STREAM_DIAG_20261013_R2_RUN.txt "/실제/요청보고서.json" "$PWD/stream_diag_02.txt"

마지막 memory-compose 블록에서 sse_events, finish_reason_counts,
content_chars/content_json, tool_argument_chars/tool_arguments_json을 확인합니다.
확인할 자료는 이 요약 블록이며 원본 JSON이나 모델 원문은 외부로 보내지 않아도 됩니다.

4. 해석
사진의 response_bytes=6069는 일부 전송 데이터 수신을 뜻하지만 답변 완성의 증거는 아닙니다.
기존 전송은 부분 실패 시 body/model/http_status를 null로 저장할 수 있습니다.
기존 RAW 로그 화면은 stream_events를 표시하지 않습니다.
done_marker=unknown은 기존 전송이 DONE 표식을 따로 저장하지 않기 때문입니다.
stream_complete=False만으로 어떤 종료 신호가 빠졌는지 확정하지 않습니다.
content_json=parsed는 구문 확인일 뿐 답변·근거·스키마 검증 성공이 아닙니다.
실제 현장 원인은 진단 결과 확인 전까지 미확인입니다.

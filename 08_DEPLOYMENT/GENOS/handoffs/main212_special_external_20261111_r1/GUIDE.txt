MAIN212 — MAIN211 위 수정 묶음 (MAIN211 대체)
MAIN211 전체를 포함한 코드입니다. 이 MAIN212만 적용하면 됩니다. GENOS 워크플로우 파일은 MAIN211와 같아서 편집기는 그대로 둡니다.

0. 바뀐 것
  ① 대사: 외규 특례·예외 조문까지 읽기 (새 단계)
     외규 조사가 끝나면 서버가(모델 호출 없이) 같은 검색어 결과 중 조문 제목이 "특례·특칙·예외"인 조문과,
     읽은 외규를 거꾸로 가리키는 특례 조문을 읽고, 그 특례 조문이 가리키는 외규 조문까지 한 단계 더 읽습니다
     (최대 6조·20,000자). 예: 유동성비율 대사에서 일반 조문 제3-64조만 읽고 끝나던 것 →
     시행세칙 제2-8조의3(재무건전성 특례) → 규정 제3-24조의4(종합금융투자사업자의 재무건전성 특례)까지.
  ② 대사: 내규 연결 조문 읽기 — 읽은 내규가 가리키는 내규 조문과 이름으로 넘긴 내규의 질문 낱말 조문을
     개념 정리 전에 읽음(최대 6조). 예: 위험관리기준시행세칙 제6-4조(단기유동성지표) 산식.
  ③ 대사: 하위 조사 입력에 큰 문서 목차를 통째로 넣어 모델이 400(context length)으로 실패하던 것 →
     편·장·절과 질문 낱말 제목만(최대 150줄). 항목 검토가 끝나면 개념 단계 메모를 화면에서 뺌(같은 미확인 문구 중복).
  ④ 연결 조회 좌표(항·호·목)를 선택 항목으로 — 모델이 빈 줄만 180초 내다 끊기던 경우 대응.
  ⑤ 서버 자동 연결 조회는 기본 꺼짐(GENOS_SERVER_FOLLOW=on일 때만), 자동 읽기 한도 원복(정방향 6·12,000자).
  ⑥ Oracle 속도: 조문 행을 요청 안에서 복사하지 않음, 문서 목차를 판본별로 프로세스 메모리에 한 번만 만듦
     (GENOS_ORACLE_SHARED_CACHE=off면 예전처럼 요청마다).
  SQL 문장은 MAIN211와 같습니다(계획 391).

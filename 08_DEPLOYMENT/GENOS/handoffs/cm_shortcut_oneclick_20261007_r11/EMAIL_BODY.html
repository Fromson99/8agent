사진의 조사 한도 설정 R1 적용은 정상입니다. CM R10은 그 변경을 지원하지 않아 코드 적용 전에 중단했습니다.

이전 CM R8/R10 대신 첨부한 R11을 사용하세요. 조사 한도 패치를 원복하거나 다시 적용할 필요 없습니다. 기존 조사 한도 코드·백업·실패 로그·원문·DB 기록을 보존합니다.

ZIP을 기존 ~/DEV/TRANSFER에 올린 뒤 아래 세 줄을 실행하세요. unzip 설치는 필요 없습니다.

python3 -m zipfile -e ~/DEV/TRANSFER/GENOS_CM_ONECLICK_20261007_R11.zip ~/DEV/TRANSFER
(cd ~/DEV/TRANSFER && sha256sum -c GENOS_CM_ONECLICK_20261007_R11_SHA256SUMS.txt)
bash ~/DEV/TRANSFER/GENOS_CM_ONECLICK_20261007_R11_RUN.txt

ZIP 안에 전체 실행 TXT·안내·SHA256SUMS가 있습니다. 전체 실행 TXT와 안내 TXT도 별도로 첨부했습니다. 별도 RUN TXT를 TRANSFER에 올렸으면 마지막 bash 한 줄로도 실행할 수 있습니다.

R11은 공통 51건·근거 98개 확인, commit, 같은 checkout/generation 배포 게이트, 등록·검증, 기존 origin push를 수행합니다. EXIT=0 및 READY_FOR_REVISION_DEPLOYMENT이면 출력된 COMMIT으로 새 코드서빙 리비전을 배포하고 워크플로우 테스트 화면에서 확인하세요.

관련 계약 검사 54개와 사진 순서의 실패→복구, 조사 한도 코드 보존·중복 없는 재실행을 로컬 모의 환경에서 확인했습니다. 실제 GENOS 적용·배포·워크플로우 성공은 별도 확인이 필요합니다. 로컬 MAIN45와 운영 원문 세대는 변경하지 않았습니다.

MAIN159 — 가이드 대화 "계속 찾아줘" 재개 + 답변 전 연결 첫 조회

현재 로컬 릴리스: connection-lookup-20261106-r1 / MAIN159 (MAIN157 기준 제품 13파일 + 엔진/파이프라인 pin, 서빙 532파일)
MAIN158(guided-continue-20261106-r1)은 중간 단계이며 이 MAIN159가 대체합니다.

1. 무엇이 바뀌었나
- 사용자가 "어 계속 찾아줘", "이어서 찾아줘"처럼 짧게 동의하면 새 명령 RESEARCH_CONTINUE로 같은 질문의 조사를 이어갑니다.
  직전 답변이 제안한 미확인 대상을 조사 입력에 그대로 전달합니다. 목적·사실·문서 범위는 바꾸지 않습니다.
- 가이드 답변 전에, 읽은 원문 범위의 연결(인용·역인용)을 한 번 조회합니다. 연결 대상이 2개 이하면 모델 호출 없이 바로 읽습니다.
  예) 상법 제433조를 읽은 뒤 제434조(정관변경의 특별결의)를 자동 확보해 결의 수치를 답합니다.
- 요청당 조사 행동은 6회로 제한합니다. 한도에 닿으면 확보한 원문으로 답하고 "더 찾아볼까요"로 끝냅니다. 사용자가 계속을 요청하면 새 한도로 이어갑니다.
- 재진입 오류 2건을 수정했습니다: 되묻기 후 다시 이어갈 때의 후보 페이지 체크포인트 500, 조문 지정 질문의 ASSESS 재개 시 범위 허용분 미복원 500.
- 가이드 대화의 후속 턴에서 별도 이유 검토 호출 2회를 생략합니다(조사 단계는 기존에도 생략). 현재 요청 대조 검사는 유지합니다.

2. GENOS 코드스페이스
다음 두 파일을 사용자가 올린 같은 TRANSFER 폴더에 둡니다. ZIP은 미리 풀지 않습니다.
  MAIN159_FULL_20261106_R1.zip
  MAIN159_ONECLICK_R1.txt
그 폴더에서 실행합니다.
  bash MAIN159_ONECLICK_R1.txt
기존 ~/DEV를 실제 checkout으로 해석하고 백업·코드 적용·엔진 검사를 수행합니다.
완료 표시는 MAIN159_ONECLICK_DONE 및 MAIN159_EXIT=0입니다.
변경 확인과 스테이징:
  bash MAIN159_ONECLICK_R1.txt status
  bash MAIN159_ONECLICK_R1.txt stage
  git -C ~/DEV diff --cached --stat
  git -C ~/DEV diff --cached --check
기존 절차로 commit한 뒤 확인합니다.
  bash MAIN159_ONECLICK_R1.txt gate-code
검증한 commit을 기존 절차로 push하고 그 commit의 새 코드서빙 리비전을 배포합니다. 설치 TXT는 Git push나 플랫폼 배포를 자동 실행하지 않습니다.
시작 명령: python3 08_DEPLOYMENT/GENOS/start_sse.py
DP=oracle, GENOS_ORACLE_TABLE_MAPPING=gold, 실제 GENOS_ORACLE_GOLD_OWNER, Agent SIDDA *_A 4개 권한은 MAIN157과 동일하게 유지합니다. DB 변경은 없습니다.
MAIN159_WORKFLOW.py는 MAIN157 워크플로우와 바이트가 같아 편집기 교체가 필요 없습니다.

3. 확인과 원복
워크플로우 테스트 화면에서 새 요청 ID로 "정관을 변경할 때 주주총회 결의요건은 무엇인가요?"를 묻고, 이어서 "어 계속 찾아줘"를 보냅니다.
원복: bash MAIN159_ONECLICK_R1.txt undo --backup '출력된 백업 폴더 절대경로'  (플랫폼 리비전은 기존 절차로 이전 리비전 선택)

4. 검증 범위
- 관련 계약/API 검사: MAIN157과 같은 검사 목록 비교, 새 실패 0 / 기존 실패 163 동일 / 새 검사 12 통과.
- 실제 Qwen(로컬 root service, 상법 공개 원문): MAIN157 기준은 두 질문 모두 433조만 읽고 결의 수치를 되물었고 "어 계속 찾아줘"는 CLARIFY였습니다.
  MAIN159는 두 질문 모두 1턴에서 434조 수치(출석 주주 의결권 3분의 2 이상, 발행주식총수 3분의 1 이상)를 확보 원문으로 답했고,
  일반 질문 2턴 "어 계속 찾아줘"는 RESEARCH_CONTINUE로 조사를 이어 435조 종류주주총회 요건까지 추가했습니다.
  433 질문 2턴은 명령 해석 호출이 공급자 응답 미완료(UNKNOWN/504)로 끝나 확인하지 못했습니다(MAIN157에서도 같은 단계에서 발생).
- 각 질문 1회 실행이며 반복 안정성·일반 법률 품질 인증이 아닙니다. 현장 GENOS 내부 모델·리비전은 확인하지 않았습니다.
- 인증정보·원문 데이터는 ZIP에 없고, 기존 JavaScript 파일 1개는 해시만 확인합니다. 상세: VERIFICATION.json / SHA256SUMS.txt

확정 연결 도구 R3 → R4

문제: R3 제작 시 현재 작업 폴더에서 common/basis_batch.py를 가져왔다.
그 파일은 이미 다른 개발의 오류 건너뛰기 변경이 포함된 2f06f1bf...였다.
실제 발송된 GENOS_BASIS_ARTIFACTS_20261020_R1은 ffc9e5bd...를 사용한다.
두 PLAN의 candidate_storage.tool이 달라 RISK_STAGE_JOB을 발생시킨다.
앞선 검증은 고정 연결 도구 자신의 파일로 테스트 PLAN을 만들어 이 차이를 놓쳤다.

수정: 실제 발송된 ARTIFACTS R1 ZIP SHA256
84f2251639458427683aa2f53f6588d57c7944243fde7bfaf0a36257f3a4785e
에서 common 전체와 CODE_REQUIREMENTS를 추출하여 동일 바이트로 결속한다.
기존 고정 연결 핵심 3파일·실행기·RUN은 기존 봉인 R3와 동일하다.
기존 조사 계획/후보/예산과 checkout을 수정하지 않는다.
build.py는 가변 작업 코드에서 조사 엔진을 복사하지 않는다.

대상: GENOS_BASIS_ARTIFACTS_20261020_R1의 기존 JSON 검토 작업.
별도 GENOS_BASIS_BATCH_20261020_R4 checkout용 도구는 아니다.
새 조사를 계획/실행할 필요가 없으며 현재 작업에 확정 연결만 추가한다.

이번 최종 R6 RUN TXT와 안내를 사용해 주세요. 사진처럼 R4 코드 check/apply/verify를 완료했다면 먼저 원복하지 않고 R6 check/apply/verify로 이어갑니다. 앞선 환경변수·배포 안내 R1의 개인 principal 등록 명령은 이번 공통 등록에 사용하지 않습니다. R5는 미발송 검증 실패 이력입니다.

첨부 RUN TXT는 bash로 실행하는 전체 파일이며 공통 등록용 --common을 포함합니다. data-check/import/verify는 실제 원문 generation/runtime과 receipt 경로만 받습니다. 기존 cases-v4.sqlite에 공통51건과 근거98개를 추가하고 같은 SQL에서 공통 legal_wiki를 생성합니다. CM51_SOURCE_PACKAGE.json은 ZIP에 별도로 들어 있어 나중에 따로 이관할 수 있습니다.

질문 요청의 실제 사용자·팀 ID는 기존 문서 권한·대화 이력·감사에 계속 사용합니다. 공통 숏컷도 그 요청에서 볼 수 있는 현재 원문으로만 연결됩니다. 기존 개인 대화·사실·native shortcut을 공통으로 공개하지 않습니다. 예전 기준답변은 검토 observation으로 보존하고 현재 원문을 새로 판단합니다.

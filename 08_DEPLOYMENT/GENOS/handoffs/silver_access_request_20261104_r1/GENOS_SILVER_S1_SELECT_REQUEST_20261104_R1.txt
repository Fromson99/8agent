[권한 요청] 개발계 GENOS Silver(SIDDS S_1) 10개 테이블 SELECT 권한

안녕하세요.

개발계 GENOS 코드서빙에서 Oracle 원문·검색·벡터 자료를 조회하기 위해 아래 Silver 레이어 10개 테이블에 대한 SELECT 권한 확인 및 부여를 요청드립니다.

대상 환경: 개발계 / GENOS Oracle 코드서빙
사용 매핑: GENOS_ORACLE_TABLE_MAPPING=development_g19_1
소유자: SIDDS / 대상 테이블: LGL_G19_*_S_1
권한 부여 대상: 해당 코드서빙의 ORDS 인증에 실제로 연결되는 Oracle DB 계정 또는 그 세션에 적용되는 승인된 역할. 실제 계정·역할명은 인프라/DBA 담당자께서 확인 부탁드립니다. ORDS 스키마 별칭이나 OAuth Client ID를 DB 계정명으로 간주하지 않습니다.
요청 권한: 아래 10개 테이블 각각의 SELECT(조회)

현재 관찰된 오류:
DEV_G19_SCHEMA_COLUMNS: SIDDS.LGL_G19_DOC_VER_S_1
접속 환경변수 누락은 해소되었으며, 테이블 컬럼 목록 확인 단계에서 중단됩니다. 현재 Silver 조회 권한 누락이 의심됩니다. 아래 대상들의 존재 및 해당 ORDS 세션의 조회 권한을 함께 확인 부탁드립니다.

권한 반영 후 확인 요청:
- 실제 GENOS 코드서빙 ORDS 접속으로 위 10개 테이블의 컬럼 메타데이터와 데이터 SELECT가 가능한지 확인 부탁드립니다.
- Dataiku 적재 계정의 권한과 GENOS ORDS 실행 계정의 권한은 별도로 확인 부탁드립니다.
- 반영한 DB 계정/역할과 적용 일시를 회신 부탁드립니다. 이후 워크플로우 테스트 화면에서 서빙 준비 및 실제 조회를 확인할 예정입니다.

이번 목록의 범위는 현재 개발계 S_1 매핑에서 사용하는 SIDDS 실버 테이블 전체 10개입니다. 별도 Gold IDD_B003/IDD_B03 테이블과 SIDDA의 온톨로지·실행기록 A_1 테이블은 이번 실버 조회 권한 요청 대상에 포함하지 않았습니다. INSERT/UPDATE/DELETE/DDL 및 포괄적인 스키마 권한은 이번 요청에 포함하지 않습니다.

목록 검증: 현재 개발계 매핑, MAIN140 전달 ZIP의 동일 매핑, Dataiku 벡터 적재 R4 정의에서 10개 테이블명·컬럼 정의가 일치함을 확인했습니다. 현장 권한 부여와 서비스 정상화 완료를 의미하지는 않습니다.

감사합니다.

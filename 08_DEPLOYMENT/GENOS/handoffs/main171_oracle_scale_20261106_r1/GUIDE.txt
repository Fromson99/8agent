1. 이번 수정 (답변·근거 판단·프롬프트는 그대로, Oracle에서 읽는 방식만)
- 요청 범위 원문 ID 목록 대신 문서 범위를 그대로 넘김(가이드 원문 메뉴·미리보기)
- 문서 전체 나열은 그 문서의 게시 단위 수만큼 한도 + 요청 안 재사용. 형제·하위는 부모 기준 조회, 큰 문서 전체는 "문서 전체"로 검색
- 같은 절 조문: 부모 기준 조회(다른 세션 준비 수정 반영)
- 제목 사전: 1,000행 넘는 묶음은 질문 위치별 정확한 키 조회(실데이터 최대 키 46자, 한도 128자 → 결과 동일)
- 대사: Oracle 저장소로 작업 연결, 원문 ID 없는 조회는 "없음", 원문 반환 하위 조사는 감독 생략(다른 세션 준비 수정)
- 속도: 같은 요청 안에서 검증한 원문·문서·단위·출처 재사용(서빙 캐시 GENOS_ORACLE_SHARED_CACHE=on일 때, 현장 기본),
  블록 길이·원문 묶음 조회, 벡터 후보 100개를 SQL 1~2회로 미리 읽기
- 새 SQL 문장 없음(642개 동일). 새 환경변수 없음.

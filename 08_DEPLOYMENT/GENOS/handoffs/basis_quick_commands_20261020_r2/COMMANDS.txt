전체 실행이 추가된 R2입니다. 이전 간편 실행 R1의 BASIS_RUN.txt 대신 사용하세요.
기존 조사 R4 또는 BASIS_ENTRY_FIX 패키지 폴더는 그대로 필요합니다.

1. 실제 TRANSFER 폴더에 ZIP 업로드 후 한 번만
python3 -m zipfile -e ./GENOS_BASIS_QUICK_20261020_R2.zip .

2. 사진의 engine manifest hash mismatch 진단
bash ./BASIS_RUN.txt check

현재 디스크의 PIPELINE → 엔진 manifest → 코드 해시를 읽기 전용으로 비교합니다.
불일치하면 정확한 경로·기대/실제 해시를 BASIS_CODE_CHECK_*.json에 기록합니다.
PASS는 현재 파일 검사 결과이며 이전 프로세스의 오류 원인까지 확정하지 않습니다.
MISMATCH이면 기존 폴더/PLAN을 지우거나 해시를 고쳐서 통과시키지 마세요.
코드 적용 중 이전 프로세스가 실행됐다면 예전 설정과 새 manifest가 섞일 수 있지만,
사진만으로 이 원인을 단정할 수 없습니다. 기존 R4 gate 결과와 진단 JSON으로 구분합니다.

3. 전체 시작
bash ./BASIS_RUN.txt all

중단했다가 다시 시작할 때도 똑같이:
bash ./BASIS_RUN.txt all

완료된 문서는 다시 조사하지 않습니다.
최초 문서 목록/계획/코드·모델·권한·세대를 보존하며 누적 사용량/기한을 초기화하지 않습니다.
이미 부분·실패로 마감된 문서도 자동 재조사하지 않고 사유를 남깁니다.
새 문서가 추가되거나 새 예산으로 전부 다시 조사하려면:
bash ./BASIS_RUN.txt all all2

4. 상태 / 보고서
bash ./BASIS_RUN.txt status all
bash ./BASIS_RUN.txt report all

보고서는 TRANSFER/basis-report-all/INDEX.html을 여세요.
20개 묶음별 보고서에 내규/외규 출처·실제 원문·연결 이유·미확인이 있습니다.
상태에는 전체 문서 수와 완료·부분·실패·진행·대기 문서 수가 따로 나옵니다.
보고서는 조사 종료/중단 후 생성하세요. 실행 중에는 status만 확인합니다.

5. 검토·이관 묶음이 필요할 때
bash ./BASIS_RUN.txt export all

TRANSFER/basis-export-all/INDEX.html에 묶음별 검토 링크가 생깁니다.
후보가 없는 묶음도 보고서에 남고 빈 이관 묶음은 만들지 않습니다.
각 묶음의 기존 review → check → apply 절차를 사용합니다. 이 명령은 운영 DB에 자동 적용하지 않습니다.

전체 범위
현재 선택 세대와 risk_team 문서 접근권한에서 최신 표시와 본문이 있는 내규 전체입니다.
모든 외규를 서로 무작위 조합하는 것이 아니라, 각 내규를 읽고 대응 외규를 기존 RAG로 찾습니다.
권한 밖 문서·옛 판본·본문 미확보 문서는 포함하지 않습니다.
고정된 목록을 20개씩 명시 ID로 나눠 한 프로세스씩 실행합니다.
이전 일부 작업·확정 연결 후보를 새 전체 작업으로 자동 복사하지 않습니다.
이미 운영 SQLite에 적용한 승인 연결은 그대로 유지합니다.

코드 버전
현재 ~/DEV의 정확한 PIPELINE 해시로 R4 또는 ENTRY_FIX 실행기를 선택하고
그 패키지의 기존 코드 게이트를 그대로 통과해야 합니다. 다른 코드를 자동 덮어쓰지 않습니다.
ENTRY_FIX로 코드가 바뀐 뒤 예전 R4 계획은 강제 재개하지 않습니다.
조사 중 check/apply/rollback/push 등으로 checkout 코드를 바꾸지 마세요.
이름 없는 resume/status/report는 현재 선택된 패키지의 기본 작업을 사용합니다.

기존 일부 작업 명령
bash ./BASIS_RUN.txt new job1 3
bash ./BASIS_RUN.txt plan job2 5
bash ./BASIS_RUN.txt run job2
bash ./BASIS_RUN.txt resume job1

현장 Python은 python3. TRANSFER 절대경로는 가정하지 않습니다.
중단은 조사 터미널 Ctrl+C. 조사 실행은 하나씩.
로그: TRANSFER/basis-quick-r2-logs 및 기존 패키지 로그.
전체 작업: 설정된 runtime/basis-batch/pilot-review-user-all/
전체 목록/기록: ALL_PLAN.json, ALL_STATE.json, ALL_EVENTS.jsonl
후보 정본: parts/part-*/CANDIDATES.json
권한·코드/원문/상태 해시·알 수 없는 오류·자원 부족은 건너뛰지 않고 중단합니다.
정상 종료 0, 부분 종료 2, 그 외 오류/중단입니다. 원본·실패 기록은 삭제하지 않습니다.

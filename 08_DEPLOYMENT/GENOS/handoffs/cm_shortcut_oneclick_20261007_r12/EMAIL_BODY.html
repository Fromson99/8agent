이전 CM R11 대신 첨부한 R12를 사용하세요. 이름 끝의 본문을 추가로 연결합니다. 예: 중소기업기본법 본문.xml. 기존 정식명·폴더·별칭·전문·조문 처리는 유지하며 시행령·시행규칙·개정문을 다른 법령의 본문으로 합치지 않습니다.

R11이 코드 적용 후 package-check에서 실패한 현재 상태에 이어 적용합니다. 조사 한도 코드·설정과 원래 백업, R8/R10/R11 실패 로그, 원문 generation, 기존 DB 기록을 보존합니다. RAW 파일 이름 변경이나 원문 재구축·조사 한도 재적용·새 환경변수 입력은 없습니다.

ZIP을 기존 ~/DEV/TRANSFER에 올린 뒤 아래 세 줄을 실행하세요.

python3 -m zipfile -e ~/DEV/TRANSFER/GENOS_CM_ONECLICK_20261007_R12.zip ~/DEV/TRANSFER
(cd ~/DEV/TRANSFER && sha256sum -c GENOS_CM_ONECLICK_20261007_R12_SHA256SUMS.txt)
bash ~/DEV/TRANSFER/GENOS_CM_ONECLICK_20261007_R12_RUN.txt

ZIP 안에 전체 RUN TXT·안내·SHA256SUMS가 있습니다. RUN TXT와 안내 TXT도 별도로 첨부했습니다. 별도 RUN TXT를 TRANSFER에 올렸으면 마지막 bash 한 줄로도 실행할 수 있습니다.

원문 51건/근거 98개 연결 확인 → commit → 같은 checkout/generation gate → 공통 등록/검증 → 기존 origin push를 수행합니다. EXIT=0과 READY_FOR_REVISION_DEPLOYMENT이면 출력된 COMMIT으로 새 코드서빙 리비전을 배포하고 워크플로우 테스트 화면에서 질문을 확인하세요.

로그/상태/문서 매핑/영수증/백업은 ~/DEV/TRANSFER/cm-oneclick-r12/에 저장합니다. 단계 상세 오류는 package-check.log 등에서 확인합니다. 실제 문서 누락인 경우 이름 수정만으로 해결되지는 않습니다.

SVG R9 개선본과 짧은 핵심 진행 로그를 함께 적용하는 R3를 다시 보냅니다.
이전 GENOS_RAG_PROGRESS_GRAPH_20261007_R2 대신 이번 GENOS_RAG_PROGRESS_GRAPH_20261008_R3를 사용해 주세요.

그래프는 짙은 배경, 청록 법령·블루 원문·앰버 판단 아이콘, 색을 잇는 곡선과 조문별 분기로 개선했습니다. 진행 표시는 대기·경과 초·모델 시작/종료를 줄이고 핵심 판단, 실제 검색값, 법령 열람·조사 복귀 이유를 남깁니다. 원문 인용과 실행 오류 원문은 보존합니다.

후속 CM 인계본에는 이전 표시를 유지하는 코드 계열이 있어, 이번 적용기는 확인된 설치 상태에서 표시와 관련 해시를 다시 연결합니다. 기존 CM R14/R15 문서 연결·공통 등록, 조사 한도, 캐시, service.py, 세션, 데이터 경로와 원문 generation은 보존합니다. 실제 현장에서 누락된 위치는 아직 확인되지 않았습니다.

적용 순서

  1. ZIP을 기존 DEV의 TRANSFER에 올리고 아래 명령으로 해제·검증·적용합니다.
  2. 실제 적용된 DEV의 변경을 검토해 commit하고, GUIDE의 같은 checkout/generation gate를 통과한 commit을 push한 뒤 새 코드서빙 리비전을 배포합니다.
  3. 분리 Python 워크플로우를 쓰면 WORKFLOW_PASTE_ALL.txt 전체를 기존 편집기에 별도 반영합니다. 코드 ZIP 적용이나 Git push로 편집기가 바뀌지 않습니다.
  4. 워크플로우 테스트 화면에서 짧은 진행 표시와 답변 아래 새 SVG, 응답의 표시 R9 버전을 확인합니다.
python3 -m zipfile -e ~/DEV/TRANSFER/GENOS_RAG_PROGRESS_GRAPH_20261008_R3.zip ~/DEV/TRANSFER/rag-progress-graph-r3-delivery
cd ~/DEV/TRANSFER/rag-progress-graph-r3-delivery
sha256sum -c PACKAGE_SHA256SUMS.txt
bash GENOS_RAG_PROGRESS_GRAPH_20261008_R3_RUN.txt

RUN TXT는 별도로 첨부했고 ZIP 안에도 같은 파일을 넣었습니다. TXT만 올렸다면 bash 파일명.txt로 실행할 수 있습니다. ZIP은 TRANSFER용 실행 묶음입니다. DEV 루트에 덮어 풀지 말고 RUN으로 적용해 주세요. 출력의 DISPLAY_WIRING과 DISPLAY_REVISIONS에서 실제 읽힌 파일과 진행 R1·SVG R9를 확인할 수 있습니다. 실제 설치 코드 전체 ZIP과 적용 전 백업은 RUN이 출력한 BACKUP 위치에 생성됩니다.

CM R15 코드 적용 후의 오류 로그 R10 보존 상태도 지원합니다. R15 코드 적용을 마친 뒤 이번 R3를 실행합니다. CM 원문 연결/등록과 표시 적용은 별도 상태입니다.

아주 초기 설치 상태에 선행 DB 상세 로그 롤백 R3가 없으면 GUIDE에 따라 함께 넣은 이전 검증 TXT를 먼저 실행합니다. 현재 R3 check가 통과하면 선행 TXT를 다시 실행하지 않습니다. 알 수 없는 수정과 실패 로그는 보존합니다.

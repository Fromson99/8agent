첨부 ZIP을 실제 업로드한 TRANSFER 폴더에서 아래 두 줄을 실행해 주세요.

python3 -m zipfile -e ./GENOS_FACT_REASON_20261015_R2.zip ./GENOS_FACT_REASON_20261015_R2
bash ./GENOS_FACT_REASON_20261015_R2/GENOS_FACT_REASON_20261015_R2_RUN.txt install

install 한 번으로 기존 ~/DEV의 사전 검사·백업·적용·검증을 진행합니다. 별도 첨부 TXT와 ZIP 안의 TXT는 동일합니다. 성공하면 CODE_APPLIED와 FACT_REASON_EXIT=0이 출력되며, BACKUP 및 APPLIED_CODE_ZIP 경로를 보관해 주세요.

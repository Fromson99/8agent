GENOS 코드 구성 진단 R1 — FACT_REASON R1 설치 중단 확인용

현재 코드 버전·적용 패치 revision·CODE_MANIFEST와 실제 파일 해시·엔진 연결을 읽고,
FACT_REASON R1이 지원하는 기존 코드 1650구성과 대조합니다.
코드, manifest, 데이터, 설정, MAIN 포인터를 수정하지 않습니다.
모델 호출·외부 전송·Git push·배포는 없습니다. 새 진단 결과만 현재 TRANSFER에 씁니다.
.env와 문서 원문/질문/모델 입출력은 수집하지 않습니다.

1. 실제로 첨부파일을 업로드한 TRANSFER 폴더에서 다음 두 줄을 실행합니다.

python3 -m zipfile -e ./GENOS_CODE_INVENTORY_DIAG_20261015_R1.zip ./GENOS_CODE_INVENTORY_DIAG_20261015_R1
bash ./GENOS_CODE_INVENTORY_DIAG_20261015_R1/GENOS_CODE_INVENTORY_DIAG_20261015_R1_RUN.txt

입력해야 할 값은 없습니다. 기존 ~/DEV를 읽고 심볼릭 링크이면 실제 checkout으로 해석합니다.
GENOS_DEV_ROOT 또는 GENOS_DEV를 이미 지정한 경우 기존 설치기와 같은 경로를 사용합니다.
실제 대상이 다를 때만 GENOS_DEV_ROOT에 확인한 checkout 절대경로를 지정합니다.
TRANSFER의 절대 위치는 가정하지 않으며 먼저 DEV로 이동하지 않습니다.
ZIP 안의 실행 TXT와 별도 첨부 TXT는 동일합니다. 독립 TXT를 사용할 때는 다음 한 줄입니다.

bash ./GENOS_CODE_INVENTORY_DIAG_20261015_R1_RUN.txt

2. 결과 확인

현재 TRANSFER/code-inventory-diag-r1-results/실행별폴더/ 아래에 다음을 만듭니다.
- SUMMARY.txt: 화면과 같은 짧은 결과
- DIAGNOSIS.json: 적용 revision, 코드 파일별 예상/실제 해시, 지원 구성 일치 여부
- DIAGNOSIS.log: 시작부터의 실행 로그
- EXIT.txt: 종료 코드

화면 마지막 SUMMARY 또는 SUMMARY.txt와 DIAGNOSIS.json 결과를 전달하면
지원 목록 누락/선행 패치 미적용/실제 파일 변경을 구분하는 데 사용할 수 있습니다.
내부 데이터 본문은 포함하지 않으며 자동 전송하지 않습니다.
재실행해도 기존 결과를 덮어쓰지 않고 새 실행 폴더를 만듭니다.

3. 상태 의미

KNOWN_PREDECESSOR: 이 진단 범위에서 FACT_REASON R1의 알려진 선행 코드와 일치.
KNOWN_FACT_REASON_OUTPUT: FACT_REASON R1의 알려진 적용 후 코드 지문과 일치.
UNSUPPORTED_INVENTORY: 파일/엔진 검사는 맞지만 FACT_REASON R1 지원 목록에 없는 코드 조합.
CHECKOUT_DRIFT_OR_UNREADABLE: manifest와 다른 파일 또는 읽을 수 없는/수집 제외 경로 존재.
ENGINE_BINDING_FAILED: 엔진/스키마 연결 해시 또는 연결 계약 불일치.
CHECKOUT_CHANGED_DURING_DIAGNOSIS: 검사 도중 파일 변경이 확인되어 단일 상태로 판단할 수 없음.
DIAGNOSTIC_INCOMPLETE: manifest 없음/구문 오류/한도 등으로 진단 미완료. 성공으로 처리하지 않음.

종료 코드 0은 알려진 코드 지문, 2는 확인할 차이, 3은 진단 미완료입니다.
지원 여부는 코드 진단 결과이며 실제 설치·generation·서빙 리비전·현장 질의 성공을 뜻하지 않습니다.
이 진단에는 apply/복구/해시 재작성 기능이 없습니다. 기존 FACT_REASON 패치를 대체하지 않습니다.
진단 완료 전 같은 FACT_REASON apply를 반복할 필요는 없습니다.

실행 제한: 표준 Python 3.10 이상, Linux/GENOS python3. 한 번 검사하며 자동 재시도 없음.
180초 제한, 파일당16MiB/합계256MiB/목록10000개 제한. 대상 코드는 두 번 읽어 중간 변경을 확인합니다.
실행 중인 서비스나 데이터 구축을 시작/중단하지 않습니다.
외부 WSL의 보존된 코드 구성 및 실패 주입으로 검증했고 GENOS 현장 실행은 미확인입니다.

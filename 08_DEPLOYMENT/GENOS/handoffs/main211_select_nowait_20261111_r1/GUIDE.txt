MAIN211 — MAIN210 위 수정 2개 (MAIN210 대체)
MAIN210 전체를 포함한 코드입니다. 이 MAIN211만 적용하면 됩니다. 워크플로우 파일은 MAIN210와 같아서 편집기는 그대로 둡니다.

0. 바뀐 것
  ① 질문 오류 수정 (필수): MAIN210에서 모델이 여러 낱말 검색어(예: "보고 원칙")를 내면
     "READ_ONLY: query accepts SELECT only"로 질문이 실패했습니다(MAIN208부터). 검색어 묶음이 본문에 있는지
     확인하는 SQL이 WITH로 시작해서 읽기 전용 검사에 걸린 것입니다. 바깥을 SELECT로 감쌌고 결과는 같습니다.
  ② 시작 직후 질문이 기다리지 않음: 서버 시작 때 캐시(조문 목록·게시 자료·용어 목록)를 올리는 동안
     질문이 최대 5분 기다리던 것을 없앴습니다. 캐시는 백그라운드에서 계속 올라가고, 질문은 바로 시작해서
     아직 안 올라간 것은 Oracle에서 읽고, 다 올라간 부분부터 캐시를 씁니다. 준비가 끝난 뒤의 질문은 전부 캐시를 씁니다.
     용어 목록을 올리는 중에 질문이 그 잠금에 묶이던 것도 풀었습니다.
     로그: 준비 중에 들어온 질문은 request.preparation.running 한 줄, 준비 완료는 request_path.preload (state, seconds, steps).
     예전처럼 기다리게 하려면 GENOS_PRELOAD_WAIT_SECONDS=300.

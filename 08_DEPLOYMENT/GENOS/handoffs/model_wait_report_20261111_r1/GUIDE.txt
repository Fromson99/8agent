GENOS 모델 호출 보고 R1 (2026-11-11)

무엇을 보는가
  화면 "LLM 호출·처리 시간" 표의 각 호출이 실제로 어떤 단계였는지, 출력량에 비례한 시간인지(생성),
  출력량보다 오래 걸렸는지(대기 의심)를 호출마다 보여 줍니다. 번호는 화면 표와 같습니다.

실행 (TRANSFER 폴더에서)
  bash ./GENOS_MODEL_WAIT_REPORT_R1.txt list          최근 요청 목록
  bash ./GENOS_MODEL_WAIT_REPORT_R1.txt 2             목록 2번의 사진 1/2, 2/2
  bash ./GENOS_MODEL_WAIT_REPORT_R1.txt 2 --page 2    사진 2/2만
  bash ./GENOS_MODEL_WAIT_REPORT_R1.txt 2 --slow 15   15초 이상을 상세 표시(기본 20초)
  요청 보고서 위치가 기본과 다르면 끝에 --root /실제/GENOS_SHARED_LOG_DIR

필요 조건
  코드서빙에 LOG=on(또는 GENOS_SHARED_LOG_DIR)이 켜져 있어 요청 보고서 .json 이 있어야 합니다.
  읽기 전용입니다. 코드서빙 재시작·코드 적용이 필요 없고 Oracle·모델에 접속하지 않습니다.

판정 읽는 법
  출력량 비례   이 질문에서 가장 빠른 속도로 계산한 시간과 비슷합니다. 실제 생성 시간에 가깝습니다.
  대기 의심     출력량보다 오래 걸렸고 같은 시각 우리 서비스의 다른 호출이 있었습니다.
  대기 의심*    출력량보다 오래 걸렸지만 우리 서비스의 다른 호출은 없었습니다(다른 앱 대기·서버 부하 가능).
  입력 큼?      출력량보다 오래 걸렸고 입력 토큰이 기준 호출의 1.5배 이상입니다.
  짧음          5초 미만이라 판정하지 않습니다.

한계
  모델 서버 안의 대기열 시간은 로그에 없어 추정입니다. 호출이 전부 같이 밀렸으면 모두 "출력량 비례"로 나옵니다.

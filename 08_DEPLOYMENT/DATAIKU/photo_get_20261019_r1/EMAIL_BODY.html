사진 2와 같은 GET /law/making 요청을 바로 보내는 Dataiku 확인용 파일을 전달드립니다.

이번 확인에는 DATAIKU_PHOTO_GET_20261019_R1을 사용해 주세요. 기존 DATAIKU_RELAY_LAW_20261019_R1은 /law/DRF에 HEAD를 먼저 보내는 다른 조회이며, 같은 run_id이면 이전 실패 결과를 재사용합니다.

  1. 첨부 ZIP을 풀고 안의 ipynb를 Dataiku Python Notebook으로 가져옵니다. 별도 첨부한 동일 ipynb를 직접 가져와도 됩니다.
  2. 코드 셀 1개를 실행하고 입법센터에 등록된 OC, 필요한 경우 현재 중계 Cookie를 입력합니다. 과거 사진의 Cookie나 인증값은 파일에 넣지 않았습니다.
  3. ipynb 가져오기가 어려우면 별도 CELL.txt 전체를 새 Python Notebook의 Code 셀에 붙여 넣어 실행합니다. TXT는 Python 코드이며 bash로 실행하지 않습니다.
  4. HTTP 상태, error_class, body_preview를 확인합니다. 실행할 때마다 GET 1회이며 이전 결과를 재사용하지 않습니다.

실제 파일을 업로드한 TRANSFER 폴더에서 압축을 풀 때:

python3 -m zipfile -e ./DATAIKU_PHOTO_GET_20261019_R1.zip ./DATAIKU_PHOTO_GET_20261019_R1

사진의 중계 주소와 target_url, 금융위원회·지주 조회 조건을 사용했습니다. 원문 요청의 필터가 다르면 FILTERS에서 정정해 주세요. 이 경로는 행정예고 API이므로 현행 법령 본문 수신과는 별도입니다.

HEAD·자동 재시도·리디렉션 추적은 없으며 3xx도 그대로 표시합니다. 연결 timeout 8초, 응답 무수신 timeout 20초이고 전체 실행 28초 제한은 아닙니다. HTTP 200이어도 오류 XML이나 로그인 HTML인지 본문을 확인해야 합니다.

로컬 요청·오류 처리 7개 검사는 통과했습니다. 사내 Dataiku·중계서버 실호출과 방화벽·인증 성공은 아직 미확인입니다. 실제 결과는 실행 후 확인해야 합니다. 본문 미리보기와 오류를 result.json으로 보존합니다.

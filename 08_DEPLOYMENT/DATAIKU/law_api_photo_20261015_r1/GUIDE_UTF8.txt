1. 이번에 받은 화면의 의미

화면의 EVIDENCE_COLLECTED는 진단 프로그램이 결과 기록을 끝냈다는 뜻입니다.
법제처/중계 서버의 HTTP 응답을 받았다는 뜻이 아닙니다.

사진에서 확인한 현장 기록(원본 JSON과 문자 단위 대조 전):
  TCP 출발지: 172.27.43.182:49822
  TCP 목적지: 45.101.64.86:8443
  TCP 시각: 2026-10-15 14:23:04.435~14:23:12.443 KST
  TCP 결과: TCP_TIMEOUT, 8.008초
  curl 시각: 2026-10-15 14:23:12.445~14:23:20.461 KST
  curl 결과: CURL_CONNECT_PHASE_TIMEOUT, 종료코드 28
  HTTP: 000 (실제 HTTP 상태 응답을 받지 못함)
  time_connect: 0.000000, time_appconnect: 0.000000
  size_download: 0, num_connects: 0
  http_request_sent_observed: False
  Cookie 포함: False, 실효 프록시 사용: False

TCP와 curl은 별도 시각의 별도 소켓입니다.
49822를 curl 요청의 출발지 포트라고 사용하면 안 됩니다. curl 쪽 포트는 화면에서 확인되지 않습니다.
172.27.43.182는 실행 네임스페이스의 주소입니다. NAT 이후 실제 출발지는 방화벽 담당자가 확인해야 합니다.
사용자 PC의 IP가 아니라 Dataiku Notebook 실행 노드/컨테이너의 흐름을 확인해야 합니다.

이 기록은 OC·Cookie·target_url을 보내기 전 독립 TCP 검사도 실패했다는 구체적인 근거입니다.
방화벽 DROP, 라우팅/반환 경로, 서버 무응답/개발 주소의 유효성은 아직 구분되지 않았습니다.
방화벽 차단 확정에는 해당 흐름과 시각에 맞는 DENY/DROP 로그 및 적용 정책 ID가 필요합니다.

기존 Notebook의 LAW_OC/Cookie를 가져오는 방식이 아니라 이번 사진 전사값을 사용합니다.
사진의 긴 세션 문자열은 이미지에서 전사한 값입니다. 원본 텍스트와 문자 단위 일치는 미검증이며
I/l, 0/O 같은 문자가 영향을 줄 수 있습니다. 세션 만료·권한 유효성도 아직 확인되지 않았습니다.
HTTP 연결 실패를 Cookie가 틀렸다는 판정으로 사용하지 않습니다.

이번 파일은 사용자 요청에 따라 인증값을 소스에 포함합니다.
네트워크 담당자에게 공유할 진단 결과 JSON에는 OC/Cookie 값을 기록하지 않습니다.

5. 사진의 curl과 비교할 때 남는 차이

조회 경로·파라미터·OC·두 Cookie·target_url은 사진 전사값으로 채웠습니다.
다만 아래 진단 제어는 추가했습니다.
  - 한글 검색어는 URL 인코딩합니다. 검색 조건의 의미는 같습니다.
  - --location을 포함하되 --max-redirs 0으로 최초 응답 뒤 추가 요청은 중단합니다.
  - 연결 8초, 전체 20초 한도, 자동 재시도 0입니다.
  - .curlrc를 자동 로드하지 않고 실행 환경의 실효 프록시/CA를 사용합니다.
  - 인증값은 curl 프로세스 인자 대신 표준입력으로 전달합니다.
  - 결과에는 연결 지표를 기록하며 응답 본문은 저장하지 않습니다.
따라서 이 파일은 최초 사진 요청의 입력값을 채운 연결 확인용입니다.
사진의 제한 없는 리다이렉트 동작이나 전체 예고 본문 수집까지 똑같이 수행한 검사는 아닙니다.

6. 결과에 따른 다음 단계

CURL_CONNECT_PHASE_TIMEOUT / exit 28 / HTTP 000
  사진의 인증값을 채운 시도도 연결 단계에서 끝난 것입니다.
  지금 확보한 TCP 증거와 함께 네트워크/중계 담당자에게 전달합니다.
  Cookie를 바꾸며 반복 호출하는 대신 아래 로그 확인으로 넘어갑니다.

HTTP_RESPONSE_401 / HTTP_RESPONSE_403
  이번 경로에서는 HTTP 응답을 받았습니다.
  API 인증/세션/접근 정책 또는 프록시/WAF의 응답인지 담당 로그로 구분합니다.
  이때 사진 전사 문자열과 현재 유효한 인증값을 대조할 필요가 생깁니다.

HTTP_RESPONSE_200
  HTTP 응답 수신까지 확인한 것입니다.
  응답 본문은 이 진단에서 보존/검증하지 않으므로 실제 예고/법령 데이터 수신 성공은 별도 확인합니다.

HTTP_RESPONSE_302 + curl exit 47
  최초 HTTP 응답을 받았고 추가 리다이렉트를 중단했다는 뜻입니다.
  TCP 시간초과가 아닙니다.

CURL_TLS_ERROR
  인증서 신뢰 또는 TLS 설정을 확인합니다. 인증서 검증을 끄지 않습니다.

안녕하세요.

Dataiku Streamlit에서 실행하는 지식 운영 콘솔의 Python 실행본을 전달드립니다. .js / .jsx / .mjs / .cjs 파일은 ZIP 안에도 포함하지 않았습니다.

첨부는 세 개입니다.

  1. DATAIKU_STREAMLIT_KNOWLEDGE_20261022_R1.zip: 전체 Python 코드와 설정·안내.
  2. DATAIKU_STREAMLIT_APP.txt: Python 편집기에 붙여 넣을 전체 코드. ZIP 안의 app.py와 동일합니다.
  3. START_HERE.txt: 실행·확인·복원 안내.

실행 순서

  1. Dataiku 프로젝트에서 Webapps → New webapp → Code webapp → An empty Streamlit app을 엽니다. 기존 Streamlit 웹앱을 쓰면 현재 코드를 먼저 백업합니다.
  2. Settings → Backend → Code env에서 Streamlit이 설치된 Python 환경을 선택합니다. 검증 버전은 streamlit==1.50.0입니다.
  3. Python 편집기에 DATAIKU_STREAMLIT_APP.txt 전체를 붙여 넣고 Save → Preview로 확인합니다.

별도 JS·CSS·이미지 업로드나 프런트엔드 빌드가 필요하지 않습니다. ZIP을 Managed Folder에 업로드하는 것만으로 자동 실행되는 형식은 아니며, Streamlit Python 편집기에 전체 코드 한 번을 붙여 넣는 방식입니다.

현재 동작 범위: 운영 콘솔 시안으로 목록·원문·집계·시뮬레이션 결과는 예시이고 수정은 현재 세션에만 반영됩니다. 실제 배치 실행·승인 저장·위키 게시·RAG·LLM API는 아직 연결되지 않았습니다. 배치 모니터의 Oracle 점검만 기존 AIDP 연결을 통한 Dataiku SQLExecutor2 읽기 전용 조회를 사용하며, 연결 이름·권한과 현장 접속은 해당 환경에서 확인해야 합니다.

실제 첨부 ZIP에서 꺼낸 코드로 메뉴 표시·검토 조건·초안/게시 분리·시뮬레이션 버전·Oracle 조회 경계의 7개 검사를 통과했습니다. 이 검사는 로컬 Streamlit과 모의 DB 응답으로 실행했으며 실제 Dataiku/Oracle 현장 실행 완료를 뜻하지 않습니다.

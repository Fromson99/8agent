이전 여러 TXT를 붙여넣는 대신, 이번 ipynb를 새로 업로드해서 사용하세요. 이전 노트북을 실행해 두지 않아도 됩니다. 인증 입력·연결 확인부터 코드가 모두 포함되어 있습니다.

  1. 기존 R6 노트북이 있던 같은 Jupyter 폴더에 이번 ipynb를 업로드합니다. 기존 로그 폴더는 보존합니다.
  2. Python 3 커널에서 00 → 01 → … → 08 순서로 셀을 실행합니다.
  3. 02 입력창에 승인된 client ID/secret을 입력합니다. 인증값은 첨부에 넣지 않았습니다.
  4. 03 연결 → 04 점검 → 05 원문 이관 → 06 전체 대조 → 07 색인·용어집 업로드 → 08 완료 결과입니다.

추가 테이블 SQL도 노트북 맨 아래에 모았습니다. 이미 생성했다면 다시 만들 필요 없습니다. 완료 시 DP_RELEASE_ID와 이관/게시 기록 경로를 보관하세요.

기존 작업을 이어갈 때는 01의 LOG_DIR가 기존 ords_stepwise_r6_logs 폴더를 가리켜야 합니다. 다른 위치에 업로드했다면 기존 로그 폴더 절대경로를 지정하세요. 기존 동일 행은 재사용하고, 이전 기록과 예산을 유지합니다.

05/07이 PAUSED면 해당 셀부터 이어 실행하며, 06 전체 대조는 다시 처음부터 확인합니다. 커널을 재시작했으면 00~03 후 진행하던 셀로 이동하면 됩니다.

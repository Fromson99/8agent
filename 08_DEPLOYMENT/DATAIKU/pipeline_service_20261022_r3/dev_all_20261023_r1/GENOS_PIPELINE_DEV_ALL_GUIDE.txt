Python 의존성과 PDF/스캔 PDF의 오프라인 파서·OCR 모델은 배포 이미지에 준비해야 합니다.

Dataiku 쪽 연결
이미 보낸 DATAIKU_PIPELINE_RUN_20261022_R3.txt를 Dataiku 노트북에서 계속 사용합니다.
LEGAL_PIPELINE_URL: 새 파이프라인 코드서빙의 실제 HTTPS 호출 URL
LEGAL_PIPELINE_TOKEN: 해당 서비스 호출 토큰 (Bearer 접두어 없이 값만)
LEGAL_ORACLE_CONNECTION: 기존 AIDP
준비 완료했던 WORK_DIR와 JOB_NAME을 유지하고 ACTION="run"으로 실행합니다.

현재 동작과 남은 보강
GENOS는 비동기로 구조화·색인하고, Dataiku가 POST로 상태를 조회하며 결과를 받아 Oracle 적재·검증까지 실행합니다.
이번 묶음은 기존 R2 코드의 재포장이므로 자동 재개나 실버·골드 저장 보장 기능을 새로 추가한 버전은 아닙니다.
현재 결과 다운로드 후 GENOS 임시 파일을 정리하며 그 뒤 Oracle 적재를 진행합니다.
중단 후 같은 WORK_DIR를 통한 재개는 가능하지만 작업 폴더가 사라진 경우의 자동 복구는 보장하지 않습니다.

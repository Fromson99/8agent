LEGAL_PIPELINE_URL 설정 안내와 Oracle 테이블 목록 조회 코드를 보냅니다.

LEGAL_PIPELINE_URL은 Dataiku가 원문 구조화·색인을 요청할 새 GENOS 파이프라인 전용 코드서빙의 실제 HTTPS 호출 주소입니다. 앞서 보낸 GENOS_PIPELINE_SERVICE_20261022_R2.zip으로 전용 서비스를 배포하고, 해당 서비스의 호출 예제에서 POST에 사용하는 전체 주소를 넣습니다. 전용 서비스를 아직 배포하지 않았다면 먼저 주소를 확보해야 합니다.

Dataiku 프로젝트 변수값

사진의 READY는 파일 준비 완료입니다. GENOS 연결이나 Oracle 테이블·적재 완료를 확인한 결과는 아닙니다. 앞선 안내에서 run 실행 전 필요한 설정·DB 확인을 충분히 설명하지 못했습니다.

지금 할 일: 첨부 DATAIKU_ORACLE_TABLE_CHECK_20261022_R1.txt 전체를 LEGAL_RAG 프로젝트의 Python 노트북 새 셀에 붙여넣고 실행하세요. SELECT 조회만 하며 DB 데이터를 변경하거나 GENOS를 호출하지 않습니다.

적재 대상은 7개이고, 현재 공통 스키마 검증이 ACTIVE·STATE 2개도 확인하므로 이번 목록 조회 대상은 총 9개입니다. 이 파이프라인이 ACTIVE·STATE 값을 바꾸는 것은 아닙니다.

  • 9개가 조회되면 현재 연결에서 필요한 테이블 목록을 확인한 것입니다.
  • 빠진 항목은 테이블 미생성 또는 접근 권한을 확인해야 합니다.
  • 목록 조회 성공만으로 컬럼·인덱스·제약조건·쓰기 권한까지 확인된 것은 아닙니다. 현재 실행 코드는 테이블을 자동 생성하지 않습니다.

테이블 목록 확인과 전용 서비스 배포·변수 설정이 끝나면 기존 Dataiku R3 실행 셀의 ACTION을 "run"으로 바꿉니다. prepare만 완료한 현재 작업의 WORK_DIR와 JOB_NAME은 그대로 유지합니다.

첨부 3개: 조회 코드·안내를 묶은 ZIP, 노트북 실행 TXT, GUIDE.txt. 이번 첨부는 앞서 보낸 Dataiku 실행 R3 / GENOS 서비스 R2를 대체하지 않는 추가 확인 자료입니다. 기존 데이터 재업로드나 NFS 변경은 없습니다.

PC에서 ZIP을 풀어 TXT를 열어도 됩니다. Linux 터미널에서 풀 때:

python3 -m zipfile -e ./DATAIKU_PIPELINE_CONFIG_CHECK_20261022_R1.zip ./

TXT는 Python 노트북에 붙여넣는 코드입니다. 로컬 Python 3.11 문법과 ZIP 무결성을 확인했으며, 실제 내부 Oracle 조회는 아직 수행하지 않았습니다. 토큰은 메일로 회신하지 말고 현장 관리 설정에 입력하세요.

온톨로지 기록 → 초안 → 승인 UI r3 · 2026-10-28

1. 모인 기록: 사람이 준비함의 조사 판단과 근거 원문을 확인하고 묶음 하나를 선택합니다.
   현재 기존 ontology_work의 INPUT 등 등록된 작업만 읽습니다.
   전체 숏컷 저장소 자동 반입·여러 작업의 개념 병합은 연결하지 않았습니다.
2. 초안 만들기: 사람이 버튼을 눌러야 Workflow.propose가 실행됩니다.
   연결된 LLM이 조건·예외·근거를 작성하고 기존 검증기를 통과한 초안만 DRAFT로 저장합니다.
   생성 완료 후에는 사람이 초안 검토하기를 눌러 다음 단계로 이동합니다.
3. 검토·승인: 사람이 내용·원문 확인 체크 후 승인하거나, 이유를 적어 반려합니다.
   생성·내용 승인만으로 골드 게시/활성화하지 않습니다.

데모와 운영
- 공개 데모: 합성 원문·기록과 명시적 예시 생성 어댑터. 실제 LLM 호출0.
  버튼은 예시 초안 만들기이며 결과도 예시라고 표시합니다.
- 설정 연결: 기존 GENOS_RAG_ONTOLOGY_CONFIG와 GENOS_ONTOLOGY_CODE_ROOT를 사용합니다.
  ontology-connection-v1의 model.kind=genos와 기존 GENOS 모델 환경이 연결되면
  버튼이 실제 기존 생성 함수에 연결됩니다. 이번 작업에서 실제 호출은 하지 않았습니다.
- 모델 미설정은 생성 비활성. 연결 실패를 데모로 대체하지 않습니다.
- ONTOLOGY_DASHBOARD_DEMO=1과 운영 설정을 동시에 사용하면 차단합니다.

오류·중복
- 생성 직전 현재 권한·원문·표시 판본을 확인하며 이미 초안이 있는 작업은 재생성하지 않습니다.
- 같은 브라우저 세션의 결과 불명은 재실행을 막고 담당자 확인을 안내합니다.
- 새 세션/다중 사용자에 걸친 영속 작업 예약·장기 작업 재접속/재개는 아직 미구현입니다.
  Dataiku 작업 원장과 멱등 실행 연결은 별도 후속이며 이번 UI를 그 완료로 보지 않습니다.
- 모델 형식 보완과 저장 실패 처리는 기존 Workflow 계약을 유지합니다.

Dataiku 반입
- Python 4개를 기존 프로젝트 라이브러리의 같은 폴더에 교체합니다.
- 웹앱 진입: from ontology_dashboard import main; main()
- 기존 semantic_runtime, 스키마, Oracle/GENOS 의존성과 인증 설정이 필요합니다.
- 이 ZIP은 UI 교체본이며 전체 백엔드 패키지가 아닙니다.

  새 숏컷 저장소 반입기나 현장 Flow 설치를 이번 UI 작업에서 수행하지 않았습니다.

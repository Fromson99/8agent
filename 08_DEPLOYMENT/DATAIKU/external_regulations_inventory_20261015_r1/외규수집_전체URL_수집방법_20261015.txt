외규 수집: 공식 API / 웹 수집 방식과 전체 URL (2026-10-15)

공식 Open API 확인: 국가법령정보센터 DRF.
기존 코드에서 확인한 웹 수집 경로: 금투협, 한국거래소, 금융위 회신사례. 공개 Open API 계약이 확인된 것은 아닙니다.
기관 게시판/파일 제공 방식 추가 확인: 금융위·금감원 기관 자료, FIU, 한국은행, 국세청, 개인정보위, 예탁결제원.
국민참여입법센터 REST는 사용자가 제공한 사진 목록 근거이며 현행 운영·인증 계약은 미확인입니다.

수집 방식
1. 공식 API: 목록 전체 페이지 → 문서/버전 ID → 본문 → 부칙·별표·첨부.
2. 웹 수집: 목록 HTML 또는 웹사이트 조회용 JSON → 문서 링크/ID → 상세 HTML → HWP/HWPX/PDF 원본 다운로드.
3. 세션이 필요한 사이트: 같은 원천 사이트 세션의 Cookie/Set-Cookie를 유지하고 페이지의 CSRF 토큰을 취득·갱신합니다. 사진의 고정 Cookie를 계속 재사용하는 방식으로 운영하지 않습니다.
4. Dataiku에서 실행하려면 중계가 대상 URL·GET/POST form·헤더·원천별 세션·파일 응답을 지원해야 합니다. Dataiku의 requests.Session만으로 중계 뒤 원천 사이트의 세션 처리가 자동 해결되는 것은 아닙니다.
5. 중계가 이 기능을 지원하지 않으면 외부 접근이 가능한 승인된 중계/수집 구간에서 크롤러를 실행하고 수집 파일·메타데이터를 내부로 전달하는 방식이 대안입니다. 해당 실행 기능/반입 방식은 담당자와 계약해야 합니다.
6. 동적 화면은 먼저 실제 조회 요청을 확인합니다. 브라우저 실행이 꼭 필요한 경우에만 실행 환경을 추가하고, 비공개 자료는 승인된 접근/파일 공급 방식으로 확보합니다.

URL 읽는 법
- 아래는 도메인을 포함한 요청 주소입니다. {값}은 실제 조회 응답이나 승인된 설정으로 치환하는 자리표시자입니다.
- POST 주소는 브라우저 주소창에 붙이는 것만으로 조회되지 않습니다. 각 항목의 요청값을 form 본문으로 보내야 합니다.
- 첨부 ID·규정 버전 ID는 목록/상세에서 얻으므로 모든 파일의 최종 URL을 사전에 고정 나열할 수 없습니다.
- 확인 수준이 사진/현재 코드인 경로는 현장 통신 성공이나 사이트의 공식 지원 보장을 뜻하지 않습니다.

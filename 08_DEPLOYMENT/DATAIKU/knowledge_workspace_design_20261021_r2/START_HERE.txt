Dataiku · 지식 운영 콘솔 시안 v2

메뉴: 0 배치 모니터 / 1 구조화 누락 승인 / 2 숏컷 승인 / 3 Legal Wiki / 4 온톨로지 관리 / 5 시뮬레이션

1. 기존 Oracle 조회 예시와 같은 Dataiku 프로젝트에서 Streamlit 웹앱을 엽니다.
2. Settings > Backend > Code env에서 Streamlit이 설치된 Python 환경을 선택합니다.
   로컬 검증 버전은 streamlit==1.50.0입니다. 기존 현장 호환 환경을 사용하세요.
3. Python 편집기에 STREAMLIT_KNOWLEDGE_OPS.txt 전체를 붙여 넣고 Save 합니다.
   .py와 .txt의 내용은 같습니다. 외부 CSS/이미지/서버를 추가하지 않습니다.
4. Preview에서 여섯 메뉴를 눌러 봅니다.

확인할 동선
- 배치 모니터 → 구조화 누락 → 원문/보완안 대조 → 사유와 확인 체크 → 승인.
- 숏컷 승인 → 완료/부분 완료 실행 비교 → 승인 또는 보류/반려.
- Legal Wiki → 편집 → 초안 저장 → 검토 요청 → 게시 내용이 유지되는지 확인.
- 온톨로지 관리 → 관계 보기/조건 편집 → 이 버전으로 시뮬레이션.
- 결과 화면 미리보기 → 불일치 사례 → 연결된 조건 수정 → 새 버전 저장.
- 다시 시뮬레이션으로 이동하면 이전 결과와 수정한 버전을 구분해 표시합니다.
- 배치 모니터의 검토 이력에서 현재 세션의 변경을 확인합니다.

범위
모든 문서·목록·집계·시뮬레이션 결과는 합성 예시입니다.
승인·편집은 현재 세션에만 반영되고 세션 종료 시 사라집니다.
실제 배치·관리·RAG·시뮬레이션 API는 연결되지 않았습니다. 실제 승인/배포/모델 호출은 없습니다.
배치 모니터 > Oracle 점검은 기존 AIDP SQLExecutor2 읽기 전용 조회입니다.
Oracle의 실제 현장 접속은 이 작업에서 확인하지 못했습니다. 개발자용 웹앱 접근 범위에서 사용하세요.
문서별 사용자 권한은 미연결이며 조회 미리보기를 RAG 근거로 자동 전달하지 않습니다.
MAIN98·GENOS는 변경하지 않습니다. 자세한 연결/실패/검증 범위는 DESIGN.txt에 있습니다.

앞 메일에는 전체 법령 API 확인 노트북을 보냈고, 별도로 쓰던 API 중계서버 직접 호출본을 빠뜨렸습니다. 이 파일을 추가로 보냅니다.

10월 15일 마지막으로 전달했던 사진 샘플 재현본입니다. 기존 원본 코드와 동일하며, .ipynb를 직접 첨부했습니다.

실제로 요청을 보내는 주소
GET https://45.101.64.86:8443/law/making
중계에 전달하는 헤더:
target_url: https://opinion.lawmaking.go.kr/rest/ptcpAdmPp.xml

Dataiku에 가져와 첫 번째 코드 셀(사진 입력값) → 두 번째 코드 셀(curl 직접 호출) 순서로 실행하세요. 2번 코드 셀 맨 아래 collect_photo_replay(...)가 시작점이며, 내부 evidence_curl()이 중계서버로 curl 요청을 1회 보냅니다. 결과에는 HTTP 코드와 연결 시간 등이 표시됩니다.

사진 당시 OC·Cookie·검색 조건을 채운 기존 파일 그대로입니다. 인증값의 현재 유효성은 미확인이며, 같은 결과 폴더에 실행 기록이 있으면 저장된 결과만 표시합니다. 이 요청은 행정예고 샘플입니다. 법령·행정규칙 본문 호출은 앞 메일의 DATAIKU_LAW_API_20261015_R1.ipynb에서 5번 셀을 실행하면 https://45.101.64.86:8443/law/DRF로 요청합니다.

ZIP과 별도 CELL.txt·실행 가이드도 첨부했습니다. CELL.txt는 Python Notebook 코드 셀에 전체를 붙여 넣는 파일입니다. 사내 API 호출은 이번에 새로 수행하지 않았습니다.

실행 순서

  1. ZIP을 내려받아 압축을 풀고, DATAIKU_STREAMLIT_ORACLE_TEST_20261021_R1 폴더의 GUIDE.txt를 확인합니다.
  2. Dataiku 프로젝트 → Code → Webapps → New webapp → Code webapp → Streamlit → Empty Streamlit app으로 생성합니다. 기본 웹앱 방식은 DSS 14.3 이상 기준입니다.
  3. Settings → Backend → Code env에서 Streamlit과 pandas가 설치된 Python 3.9 이상 환경을 선택합니다. 추가 패키지 예시는 streamlit>=1.40,<1.57 및 pandas입니다. 사내 제공 패키지와 Python 호환 버전을 사용합니다.
  4. Python 편집기의 기본 코드를 지우고 STREAMLIT_ORACLE_TEST.txt 전체를 붙여 넣은 후 Save합니다. 별도 첨부 TXT와 ZIP 내부 TXT는 동일합니다. 이 코드는 웹앱 편집기용입니다.
  5. 화면 왼쪽 연결 이름은 기존 이관 자료의 AIDP로 설정했습니다. 실제 연결 이름이 다르면 변경합니다.
  6. Oracle 연결 확인 → 테이블 목록 불러오기 → 테이블 선택 → 선택한 테이블 조회 순서로 누릅니다. 다른 스키마는 왼쪽 스키마 입력을 바꾸고 목록을 다시 불러옵니다.

이번 테스트는 읽기 전용입니다. 최대 20행·40개 열을 조회하며 문자열과 긴 본문은 앞 300자만 표시합니다. 연결/권한/조회 오류는 화면의 확인 번호와 ORA 코드로 확인하고, 원래 오류는 Webapp 백엔드 로그에서 조회합니다.

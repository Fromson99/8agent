증분 처리용 추가 Gold 3표 — 메타 등록·개발계 생성·권한 R2 (2026-11-12)
R1(메일 SENT 1a1cdbe5d85ddf82)을 대체한다. R1은 기존 Gold에 없는 도메인(코드·일자·순번·비율)과 크기(VARCHAR2(30)·(8)·(2000)·
NUMBER(10,0)·(5,4))를 썼다. R2는 기존 RAG Gold 등록본에 실제로 쓰인 도메인과 크기 안에서만 골랐다.

========================================================================
0. 요약
========================================================================
- 기존 RAG Gold 13표는 이미 등록·적재 완료 → 추가 신청 없음.
- 새로 신청할 Gold 3표 (29컬럼):
    IDD_B003_LGL_RGLT_DOC   규정문서내역   MASTER   문서 하나 = 1행. 판본이 바뀌어도 그대로인 원천문서ID와 지금 서빙 판본
    IDD_B003_LGL_RGLT_VER   규정판본내역   HISTORY  들어온 원문 파일(판본) 하나 = 1행. 공포·시행일시, 판정 상태, 반영된 Gold 세대
    IDD_B003_LGL_ARTC_CMPR  조문비교내역   HISTORY  바뀐 조문 하나 = 1행. 신구조문 대비(변경 유형·이전/이후 조문)
  개발계는 같은 이름으로 SIDDS, 운영은 SIDDG(메타 등록 → DBA 생성).
- Agent 표는 새로 만들지 않는다. GENOS 결과는 기존 SIDDA.LGL_PIPE_RESULT_A, 증분 실행 기록(판단 실행·대비표 HTML·
  되돌리기용 옛 원문 파일 최근 3개)은 Dataiku 관리 폴더(S3)에 그대로 둔다.

1. 도메인·크기 — 기존 RAG Gold 등록본 기준 (엑셀 07 시트)
========================================================================
  도메인   쓸 수 있는 크기                     기존 Gold에서 쓴 예
  ID       VARCHAR2(50), VARCHAR2(100)         구조단위ID(50), 규정문서ID·조회자료ID(100)
  값       VARCHAR2(100)                       각종 해시값, 조회자료유형값
  내용     CLOB, VARCHAR2(3000)(기준1000×한글3)  본문내용(CLOB), 조회자료식별내용(3000)
  명       VARCHAR2(100), VARCHAR2(2250)       조회채널명(100), 규정문서명(2250)
  번호     NUMBER(30,0)                        변경번호, 작업버전번호
  여부     VARCHAR2(1)                         부가정보미지정여부
  일시     TIMESTAMP(6) WITH TIME ZONE         등록일시
  build.py가 R20 엑셀(기존 Gold 등록본 60컬럼)에서 이 목록을 다시 뽑아 같은지, 새 컬럼이 모두 이 안에 있는지 검사한다.

R1 → R2 바꾼 것
  규정문서코드 RGLT_DOC_CD VARCHAR2(100)(코드)     → 원천문서ID SRC_DOC_ID VARCHAR2(100)(ID)
  원천구분코드 SRC_SE_CD VARCHAR2(30)(코드)        → 원천유형값 SRC_TYPE_VALU VARCHAR2(100)(값) — 기존 '조회자료유형값'과 같은 방식
  원천파일명 VARCHAR2(2000)                         → VARCHAR2(2250)(명)
  공포번호 VARCHAR2(100) · 공포일자 VARCHAR2(8)     → 공포일시 PRMG_ASTM(일시), 공포번호는 버전부가정보내용 JSON으로
                                                      (행정규칙 발령번호는 '제2025-12호'처럼 숫자가 아니라 번호 도메인 NUMBER에 못 넣음)
  시행시작일자 ENFC_STRT_DT VARCHAR2(8)(일자)      → 시행일시 ENFC_ASTM(일시) — 그날 0시(한국시간)
  버전상태코드 VER_STTS_CD VARCHAR2(30)(코드)      → 버전상태값 VER_STTS_VALU VARCHAR2(100)(값)
  비교순번 CMPR_SEQ NUMBER(10,0)(순번)             → 비교번호 CMPR_NO NUMBER(30,0)(번호)
  변경유형코드 CHAN_TYPE_CD VARCHAR2(30)(코드)     → 변경유형값 CHAN_TYPE_VALU VARCHAR2(100)(값)
  유사비율 SMLR_RATE NUMBER(5,4)(비율) · 조문 시행시작일자 → 비교부가정보내용 CMPR_ADDN_IFMN_CTNT CLOB(내용) JSON으로
  새 표준단어 후보 20개 → 13개: 원천 SRC · 활성 ACTV · 파일 FILE · 공포 PRMG · 시행 ENFC · 상태 STTS · 대체 SPSD ·
                               비교 CMPR · 기준 BASE · 이전 BFR · 이후 AFTR · 조문 ARTC · 키 KEY (05 시트)
  나머지 약어는 기존 Gold 것을 그대로 씀(규정 RGLT·문서 DOC·변경 CHAN·버전 VER·유형 TYPE·조회 RFRN·게시 POST·부가정보 …).

  (가) 표 만들기: SIDDS 소유자 또는 DBA가 CREATE_INCREMENT_GOLD_SIDDS_R2.txt 실행(4문장).
       Dataiku 계정이 직접 만들려면 CREATE ANY TABLE · CREATE ANY INDEX. 공간은 작다(문서 약 2,121행 + 판본·바뀐 조문).
  (나) Dataiku 계정 PIDD2APP(AIDP 연결, 증분 셀): 3표 SELECT, INSERT, UPDATE, DELETE (개발계는 실험 재실행 정리용 DELETE 포함)
       운영은 SELECT, INSERT, UPDATE (이력이라 지우지 않음) → GRANT_INCREMENT_GOLD_SIDDG_R2.txt
  (다) GENOS ORDS 계정·코드서빙: 지금은 필요 없음.
실행 순서 (Dataiku SQL 노트북, [번호] 한 개씩, 문장 끝 ; 없음)

  2. GRANT_INCREMENT_GOLD_SIDDS_R2.txt   G01~G03
  3. CHECK_INCREMENT_GOLD_SIDDS_R2.txt   Q01 3행, Q02·Q03 0행, Q04 3표 DELETE,INSERT,SELECT,UPDATE

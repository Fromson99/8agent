Dataiku 개발계 직접 설정값

LEGAL_EMBED_LLM_ID=openai:genos-embedding:embedding-kure-v1
LEGAL_EMBED_DIMENSIONS=1024

기존 승호님 코드와 같은 Dataiku LLM Mesh 등록 모델입니다.
Dataiku에 실제 환경변수로 등록하거나 프로젝트 변수에 같은 이름으로 등록하세요.
둘 다 있으면 실제 환경변수를 우선합니다. 프로젝트 변수의 차원은 숫자 1024 또는 문자열 "1024" 모두 가능합니다.
실행 코드는 설정값을 읽어 별도 Python 실행 프로세스에 전달합니다.
환경변수 설정 셀이나 코드 안 모델명 수정은 필요하지 않습니다.
Dataiku 등록 인증을 사용하므로 GENOS_EMBED_URL/KEY 같은 별도 URL·토큰은 입력하지 않습니다.

프로젝트 변수 예시(JSON 객체에 아래 항목 추가, 기존 다른 설정 유지):
{
  "LEGAL_EMBED_LLM_ID": "openai:genos-embedding:embedding-kure-v1",
  "LEGAL_EMBED_DIMENSIONS": 1024
}

모델 ID는 등록 별칭입니다. 같은 별칭의 실제 모델을 교체하면 기존 벡터 작업을 그대로 이어 쓰지 마세요.

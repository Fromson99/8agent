Dataiku 압축 해제 OSError 확인

사진에서는 ZIP 다운로드 후 RESTORE_AND_VERIFY 단계에서 OSError가 발생했습니다.
오류 처리에서 상세 원인이 가려져 있어, 현재 화면만으로 공간 부족이라고 확정할 수 없습니다.
이번 코드는 원래 예외에 남아 있는 오류번호와 상세원인, 작업경로의 남은 공간을 출력합니다.

실행 순서
1. 오류가 난 Dataiku 노트북을 그대로 둡니다. 커널을 재시작하지 마세요.
2. DATAIKU_OSERROR_CHECK_20261022_R1.txt 전체를 같은 노트북의 새 셀에 붙여넣습니다.
3. 그 새 셀만 실행합니다. 기존 파이프라인 셀을 다시 실행할 필요는 없습니다.
4. 출력된 오류번호·상세원인·작업경로·남은공간을 전달해주세요.

기존 R2 파이프라인 실행본을 교체하는 파일이 아닙니다. 오류 확인용 추가 코드입니다.
다운로드·압축 해제·GENOS 호출·Oracle 적재·파일 삭제·NFS 설정 변경을 하지 않습니다.
이미 받은 ZIP과 기존 작업 폴더는 그대로 유지하세요.
오류 기록이 없다는 출력이면 커널 재시작이나 이후에 다른 오류가 발생했는지 알려주세요.

리눅스 터미널에서 첨부 ZIP을 풀어야 한다면 ZIP이 있는 폴더에서 실행합니다.
python3 -m zipfile -e ./DATAIKU_OSERROR_CHECK_20261022_R1.zip ./
풀린 TXT는 bash 실행 파일이 아닙니다. 오류가 난 Dataiku Python 노트북의 새 셀에 붙여넣습니다.
PC에서 ZIP을 풀어 TXT를 열어도 됩니다. 별도 첨부 TXT와 ZIP 안 TXT는 동일합니다.

Linux 오류번호 예시
28: 남은 공간 또는 파일시스템 자원 부족
122: 사용자/프로젝트 저장 할당량 초과
36: 파일명 또는 경로 길이 제한 초과
13: 접근 권한 거부
이는 예시이며 실제 발생한 오류번호를 확인하기 전에는 원인을 확정하지 않습니다.
남은 공간 출력은 파일시스템의 수치이며 사용자/프로젝트 할당량을 따로 측정하지 않습니다.

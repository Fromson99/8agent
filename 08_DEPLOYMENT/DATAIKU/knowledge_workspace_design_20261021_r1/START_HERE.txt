Dataiku에서 화면 시안 띄우기

1. 기존 Oracle 조회 예시가 있는 Dataiku 프로젝트에서 Code > Webapps로 이동합니다.
2. New webapp > Code webapp > An empty Streamlit app을 선택합니다.
3. Settings > Backend > Code env에 Streamlit이 설치된 Python 환경을 선택합니다.
   이 시안의 로컬 검증 버전은 streamlit==1.50.0입니다. 사내 패키지 저장소/호환 환경을 사용하세요.
4. Python 편집기에 STREAMLIT_KNOWLEDGE_DESIGN.txt 전체를 붙여 넣습니다.
   .py와 .txt는 같은 내용입니다. 노트북/SQL 편집기에 붙이는 파일이 아닙니다.
5. Save 후 Preview에서 업무 검토 / 검토 지식 / 원문 데이터 / 게시 이력을 열어 봅니다.
6. 기존 Oracle 연결을 확인하려면 원문 데이터 > Oracle 조회에서 AIDP 연결을 확인합니다.
   연결 확인 > 테이블 목록 조회 > 선택 테이블 미리보기 순서입니다.

별도 HTML/CSS/이미지 파일 업로드는 필요하지 않습니다.
질문과 지식 편집·게시 동선은 화면 시안이며 실제 RAG/관리 API 호출은 연결하지 않았습니다.
예시 편집·게시 이력은 현재 세션에만 남으며 실제 DB에 저장되지 않습니다.
Oracle 조회만 실제 Dataiku SQLExecutor2 경로이며 이 세션에서는 현장 연결을 검증하지 못했습니다.
조회 결과는 사용자 문서 권한이 연결되지 않은 개발 확인용입니다. 개발자용으로 접근을 제한하세요.
현재 MAIN 및 GENOS 코드는 변경하지 않습니다. 웹앱을 중지/삭제해도 DB 원복이 필요하지 않습니다.

메뉴나 버전 기준은 Dataiku 공식 안내를 확인하세요.
https://developer.dataiku.com/latest/tutorials/webapps/streamlit/getting-started/index.html
자세한 화면/연결/실패 계약은 DESIGN.txt에 있습니다.

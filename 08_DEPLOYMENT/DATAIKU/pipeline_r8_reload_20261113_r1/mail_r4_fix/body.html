R8 재적재 R4 정정 — 앞서 보낸 R4 메일(SENT 1a1d35c381de5b77)의 "설치 셀이 멈출 때" 표 두 줄만 고칩니다. ZIP·설치 셀·기본 순서는 그대로 쓰세요.

왜 고치나

개발계 OBS 폴더 Settings > Storage 화면에는 Bucket 칸이 없습니다(Type / S3 connection / Path in bucket 세 줄뿐). 그래서 R4 메일의 "Settings에서 Bucket 값을 넣는다"는 화면에서 할 수 없습니다.
원인: 설치 셀이 코드로 만든 폴더에는 Dataiku API가 연결 이름과 경로 /${projectKey}/${odbId}만 넣고 버킷은 넣지 않아, 연결 기본 버킷 AIDP-YNY-DEV-BUC-SRI로 가서 404가 납니다. 화면에서 만든 LGL_R8_CODE는 연결 기본값이 같이 들어가 열립니다. R4 셀은 LGL_R8_CODE가 실제로 쓰는 버킷·경로를 읽어 넣으므로 기본 순서는 그대로입니다.

새 프로젝트는 필요 없음 — 지금 LEGAL_RAG_R8에서 그대로

  1. LGL_R8_PARTS에 진행 중인 업로드 취소
  2. LGL_R8_CODE에 DATAIKU_ZIP_R8_RELOAD_R4.zip 업로드 (R3 ZIP은 둬도 됨)
  3. 같은 노트북에 DATAIKU_SETUP_R8_RELOAD_R4.txt 전체 붙여 실행 → FOLDER_STORAGE_SET 5줄, RECIPE_UPDATED 4줄이면 성공
  4. LGL_R8_PARTS 새로고침 — 빨간 오류가 없으면 조각 34개 + ORIGINAL.sha256 + PARTS.sha256 업로드, LGL_R8_CODE에 SEARCH_SELECTION_GENERATION.json 업로드
  5. Scenarios > LGL_R8_RELOAD_RUN_ALL > RUN

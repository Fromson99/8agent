Gold 판본 보완 플로우 R7 — 직접 만든 프로젝트에 설치 · JSON 함께 ZIP (2026-11-09)

앞선 R7 메일들을 대체합니다. 설치 스크립트가 더 이상 프로젝트를 자동으로 만들거나 ZIP을 내보내지 않습니다.

개발계

  1. 새 프로젝트를 직접 만든다(빈 프로젝트)
  2. 그 프로젝트의 노트북에서 첨부 DATAIKU_CREATE_GOLD_FIX_FLOW_R7.txt 실행 (REFERENCE_FOLDER는 비워 두기 → 폴더를 DSS 서버 디스크에 만듦)
  3. 생긴 gold_selection_input 폴더에 판본 선택 JSON 업로드 → 같은 셀 다시 실행 → 입력 JSON 확인 … term-source-533a… bf643c59… 확인
  4. 프로젝트 메뉴 → Export → '관리 폴더(Managed folders) 내용 포함'을 켜고 ZIP 받기 → JSON이 ZIP에 같이 들어감

운영

  1. Import project → ZIP (폴더 연결 filesystem_folders 그대로, 버킷에 쓰지 않음)
  2. 변수 확인 GOLD_FIX_MODE=APPLY, AIDP / PIDD2APP / SIDDG → 레시피 RUN 한 번 → APPLIED → 코드서빙 재기동
  3. 권한 부족이면 로그에 GRANT 줄, 끊기면 다시 RUN, 확인만은 CHECK, 되돌리기는 ROLLBACK

검증: 레시피는 이전과 같은 코드(로컬 Oracle 12항목, 폴더 쓰기 0). 설치 스크립트는 Dataiku API 대역 6항목 통과. 미확인: 실제 Dataiku의 Export 폴더 내용 포함·가져오기, 출력 없는 레시피 허용, 운영 규모 시간·로그량(6,097만 행 UPDATE — DBA 공유), 운영 권한.

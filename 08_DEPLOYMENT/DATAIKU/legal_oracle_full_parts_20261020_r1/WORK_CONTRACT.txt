전체 generation 데이터 운반 계약
입력: 기존 추가본과 동일한 명시 generation. manifest에 등록된 원문/store, navigation, fulltext, glossary, SEARCH_SELECTION을 모두 포함. 필터/샘플링 없음. 원시 업로드 파일/다른 세대/운영 이력은 이 계약 밖.
출력: full-data.zip.partNNNNNN <= 49,000,000 bytes + parts-manifest.json. Dataiku 복원 generation을 기존 source migration -> assets publish -> query publish가 소비.
실패: 해시/스키마/대상 변경은 중단. 불명확한 쓰기 응답은 실패 기록 후 같은 ACTION을 명시 재실행하여 기존 행 대조. 자동 재시도 없음.
복구: 단계 소유권/잠금/원본 파일과 연결 지문 고정. 첫 deadline 7일 유지, 1회 1..21600초 단계 예산. 단계별 누적 SQL 100만 회, 연결 identity 별도 1회. 큰 파일 해시/투영은 호출 경계에서 시간 제한이 검사될 수 있음.
중단: 기록/부분 ZIP/부분 파일 보존, 원본 불변. 완성 ZIP이 없으면 압축 단계 재실행, 완성 조각은 해시 대조 재사용. Dataiku source/asset 단계는 checkpoint 재개, query는 앞 행부터 불변 대조. 최종대조는 처음부터 수행.
성공: 원문 전체 행+자산 분할 전체 읽기+조회 전체 행과 총건수+release 해시 일치 FULL_DATA_VERIFIED. ACTIVE/STATE/서빙 변경 없음.
검사: 정상 전체반출/복원/빈 타깃 적재, 실제 TXT, 재개/응답유실/잘못된조각/변조/대상변경/예산/누락스키마/최종원격변조. 합성 데이터 하나씩 실행, RSS 1GiB 초과시 추가실행중단. 모델호출 없음.

## 입력·구조화 — 작업 코드 연결, 현장 검증 대기

- 입력 manifest를 요구하는 계약을 해제하고 파일·폴더로 입력받는다.
- 같은 문서의 여러 표현본은 **XML이 있으면 XML → 없으면 PDF → 둘 다 없으면 DOCX·HWP 등**의 순서로 선택한다. 서로 다른 문서는 각각 처리한다.
- PDF에는 **LLM 구조화 틀 생성 → 코드로 구조 적용 → VLM의 원본 페이지 검수·보정** 경로를 사용한다.
- PDF 경로는 기존 `recipe_runtime`에 연결되어 있다. 2026-09-12 규칙 부재 시 자동 생성 → 원문 검증 → 재구축·VLM 검수 → 문서별 저장·재사용을 작업 코드에 반영했다. [동작·제한](REFERENCE/OPERATIONS/GENOS_RECIPE_VLM.md).
- 합성 테스트로 연결을 확인했다. GENOS 실호출·배포, 수집 사전 PDF 전수 용어 추출은 미실행이다. 2026-09-13 파일 기반 입력·동일 문서 형식 우선 선택·구조화 뒤 새 용어집 연결을 구현했다. 현행 진입점은 `pipeline.py build-data-stages`다.

## BL-001 · XML 이외 문서의 구조화에 용어집 활용 실험

- 등록일: 2026-09-11
- 상태: 대기 — 미실행, ADR 미생성
- 질문: **XML이 아닌 형식을 구조화할 때 용어집을 사용하면 더 효과적으로 구조화할 수 있는가?**
- 대상: PDF·DOCX·HWP 등 비XML 문서. PDF는 위 LLM 틀 생성·VLM 검수 경로를 기준으로 한다.
- 비교안: 같은 문서·모델·설정에서 용어집 없이 구조화한 결과와, 관련 용어를 힌트로 제공한 결과를 비교한다.
- 활용 후보: 제목·절 경계·항목 소속 판단, 구조화 틀 생성, VLM 검수에 용어집을 제공하는 방식. 구체적인 주입 위치는 실험 설계 때 결정한다.
- 확인할 것: 계층·부모 연결·표/첨부 소속·누락/잘못된 분할과 토큰·호출 수·처리 시간. 효과가 있다고 미리 가정하지 않는다.
- 실행 전 준비: 사용할 용어집 버전·문서 표본·성공 기준을 고정하고 ADR을 연결한다. 용어 힌트로 원문을 바꾸거나 법률 의미를 확정하지 않는다.
- 환경: 공개 또는 모의 자료로 외부 검증을 준비한다. 실제 내부 문서·GENOS 내부 모델 검증은 현장에서 수행하며 현재 Codex에서는 GENOS 세션에 접근할 수 없다.
- 결과/ADR: 미정

- 완료된 후보 연결: `glossary_linking.project`의 `occurrence`·`catalogue_link`·`knowledge_catalogue_link`를 기존 `build_generation → compile_index`에서 소비한다. 159문서의 원문·ID·hash를 보존하고 출현 전량을 채택/보류 원장에 기록했다. 용어 ID253,324·용어–조문 연결5,539,572이며 고유 단어 수나 품질 점수는 아니다.
- 완료된 후보 제어: 번역·정규화·별칭·정의·관계 조회에서 실제 문서 검색으로 연결하고, 정의·명시 참조 원문을 ID와 함께 회수한다. 한도 초과는 검색 미완료로 남기며, 미회수 참조 본문은 숨긴다. 엄격한 로컬 원문 ID 검증을 유지한 전송 수정 후 모의8질문8/8·필수근거9/9·회귀0을 확인했다.
- 2026-09-16 확대 검사: [ADR0424](../04_EXPERIMENTS/ADR/ADR-0424-glossary-broader-validation/README.md)에서 기존 계약131건, 실제159문서 조회194건·추가계약30건이 통과했다. 반복조회 p95 62.7ms·최대 RSS 527.8MiB·초기화13.91초(로컬 단일 프로세스)다. 새 합성24문항의 양쪽 실행에서 후보의 조기 FINISH, 긴 원문 미열람, 동점 검색의 접수 근거 누락, 키워드만 남는 STOP 출력이 드러났다. 후보 코드와 MAIN은 변경하지 않았다.
- 새 문항의 동결 기준은 기존16/24·후보10/24다. 후보만 통과1건, 기존만 통과7건이며 그중2건은 gold 과다·중복 요구 가능성을 표시했다. 필수·진단 원문 선택은 기존26/44·후보19/44다. 이 결과로 품질 기준을 통과하거나 MAIN 승격 조건을 충족했다고 보지 않는다.
- 2026-09-16 CM51 Gemini 검증: [ADR0426](../04_EXPERIMENTS/ADR/ADR-0426-cm-glossary-network-validation/README.md)에서 실제159문서·동일51문항을 양 경로에 전수 실행했다. 기존51건은 두 번째 검토 요청 HTTP400, 후보51건은 첫 검토 전 로컬20,000자 입력 제한으로 실패했다. 제품153요청·오프라인 채점102요청을 기록했고 생성된 법률 답변은0건이다. 근거 조문 가용성은 전부 확인됐으나 검색 결과가 모델 검토로 이어지지 않았다. 선행 [ADR0425](../04_EXPERIMENTS/ADR/ADR-0425-cm-glossary-validation/README.md)의 ConnectError8회·응답0 기술실패는 별도 보존했다.
- 2026-09-16 사용자 지시 반영: [ADR0427](../04_EXPERIMENTS/ADR/ADR-0427-glossary-structure-body-reverse-match/README.md)에서 초기 Gemini 표현 추출을 제거하고 질문 전체를 구조·본문 용어에 각각 역매칭했다. [상세 흐름](REFERENCE/OPERATIONS/GLOSSARY_ALIGNMENT.md#질문-전체의-구조본문-역매칭-후보--2026-09-16).

- 운영: 후보 모의 결과는 품질 승인이나 자동 승격 근거가 아니다. 현재 로컬 MAIN generation13은 그대로다. GENOS 내부 모델 검증·반입·MAIN 승격은 각각 별도 상태다.

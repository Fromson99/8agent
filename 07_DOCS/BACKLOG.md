## BL-001 · XML 이외 문서의 구조화에 용어집 활용 실험

- 등록일: 2026-09-11
- 상태: 대기 — 미실행, ADR 미생성
- 질문: **XML이 아닌 형식을 구조화할 때 용어집을 사용하면 더 효과적으로 구조화할 수 있는가?**
- 대상: PDF·DOCX·HWP 등 비XML 문서. PDF는 위 LLM 틀 생성·VLM 검수 경로를 기준으로 한다.

- 실행 전 준비: 사용할 용어집 버전·문서 표본·성공 기준을 고정하고 ADR을 연결한다. 용어 힌트로 원문을 바꾸거나 법률 의미를 확정하지 않는다.
- 환경: 공개 또는 모의 자료로 외부 검증을 준비한다. 실제 내부 문서·GENOS 내부 모델 검증은 현장에서 수행하며 현재 Codex에서는 GENOS 세션에 접근할 수 없다.
- 결과/ADR: 미정

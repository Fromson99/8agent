# 운영매뉴얼

현장 운영자가 서빙 코드를 기능 단위로 이해하고 고칠 수 있게 정리하는 폴더. 기준 코드는 현장에 보낸 최신 MAIN 전달본이다(현재 MAIN181).

| 파일 | 내용 |
|---|---|
| `00_서빙코드_기능별안내_MAIN181_2판.docx` | 전달 ZIP 556개 파일을 기능 56개로 나눈 표(기능별 설명 열 포함), 진입점 정리, 핵심 기능에 없는 코드("없음") 목록, 수정 시 주의. 삼성메일 SENT `1a1bf200788c7881` |
| `00_서빙코드_기능별안내_MAIN181.docx` | 1판(설명 열 없음, B1·D1 파일 구성 오류 있음). 2판으로 대체 |
| `01_첫요청분류.md` | 첫 요청 분류(B1)의 세부 기능, 서버 검사, 결과 사용처, 관련 파일 |
| `02_가이드조사루프.md` | 가이드 조사 루프(D1): 모델이 행동을 고르고 서버가 원문을 읽는 반복, 메뉴, 자동 읽기, 한도와 멈춤 |
| `수정사항.md` | 정리하며 결정한 코드 변경 목록(화면 접두어 분리 제거, 과거 기록 후보 제거 등), 영향 범위와 정할 것 |
| `후속_진행계획.md` | 다음에 할 일(기능별 상세 문서, 진입점·"없음" 코드 정리 등) |

기능 번호(A1, B1, …)는 00번 문서의 기능별 요약표 번호와 같다.

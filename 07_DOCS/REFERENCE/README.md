# Reference documents

이 디렉터리는 파일을 평평하게 쌓지 않고 용도별 컨테이너에 보관한다.

- `ARCHITECTURE/`: 시스템·도메인·스키마 설계
- `OPERATIONS/`: 배포·동기화·현장 운영
- `RAG/`: 검색·추론·검토 규칙
- `EXPERIMENTS/`: 실험 설계 설명서
- `REPORTS/`: 완료 분석 보고서
- `AUDITS/`: 감사 결과와 근거
- `EXAMPLES/`: 예제 입력·출력
- `TASKS/`: 작업 지시·체크리스트
- `ASSETS/`: 문서용 이미지·도식
- `ARCHIVE/`: 더 이상 현행이 아닌 문서

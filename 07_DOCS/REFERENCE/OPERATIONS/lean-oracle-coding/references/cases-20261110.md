## 공통 원인 (왜 이렇게 됐나)

1. 로컬 SQLite·파일 구조를 그대로 둔 채 저장 위치만 Oracle로 옮겼다(2, 3, 9, 12~14, 23, 28~30, 32).
2. "혹시 몰라서" 단계마다 다시 확인했다(1, 4, 10, 17~19, 31).
3. 서버가 죽어도 이어 가게 하려고 중간 저장·잠금·영수증을 넣었다(12, 13, 21, 27).
4. 로컬 왕복 0.2ms에서는 횟수가 안 보였다. 현장은 5~10ms, 커밋 130ms(전부).
5. 개발용 로그·진단을 운영에서도 켜 두었다(5, 6, 7, 22).

# DOCX 내규: Word 선언을 구조화에 되살리기 (2026-09-18)

내규는 docx(또는 doc)로만 오는 경우가 있다. hwpx만 있는 문서는 없다. docx는 docling이
읽는데, 이때 Word 파일이 직접 선언한 계층 신호 세 가지가 사라졌다.
`.doc`는 GENOS 전처리기 쪽 일이라 여기서 다루지 않는다.

## 무엇이 사라졌나 (실측)

Word 자동 번호로 `제%1조 / ① / %3. / 가.` 네 수준을 매긴 문서를 docling에 넣으면 이렇게 나왔다.

| Word 화면 | docling 텍스트 |
|---|---|
| 제1조 (목적) … | `제1조 (목적) …` |
| ① 첫째 항이다. | `첫째 항이다.` (① 사라짐) |
| 1. 첫째 호 | `1.1.1. 첫째 호` |
| 가. 가 목 | `가 목` (가. 사라짐) |

- 들여쓰기(w:ind), 목록 수준(w:ilvl), 글자 크기는 요소에 실리지 않았다.
  화면용 가짜 지면에 모두 같은 자리로 찍혀 사다리의 들여쓰기 증거가 동률로 침묵했다.
- docling은 번호 목록을 묶음째 옮긴다. 합성 문서에서는 `나.`가 `가.` 앞에 왔다.
  실제 신청서(외국주권등 신규상장 예비심사신청서)에서는 원문 701번째 문단 `3. “주식 등의 종류”는…`이
  644번째 `2. 종류주식에 대하여…` 바로 뒤로 끌려왔다. 원문에서는 그 사이에 646번째 `(3) 종류주식에 관한 사항`이 있다.

## 지금 하는 일

docx 원본 XML을 함께 읽어 docling 요소에 짝지어 싣는다. 값은 모두 파일에 선언된 것이다.

- 자동 번호를 numbering.xml의 형식·표시 문자열대로 다시 그린다.
  원문자, 가나다, ㄱㄴㄷ, 로마자, 한글 숫자, (1)을 지원한다.
  조마다 다시 시작하는 목록(startOverride)과 스타일에 연결된 번호도 따른다.
- 문단 첫 줄 시작점(문단 > 번호 수준 > 스타일 순으로 적용)을 가짜 지면에 그대로 옮긴다.
  사다리의 들여쓰기 증거가 이 값을 본다.
- 글자 크기(본문 대비 배율)와 굵기를 싣는다.
- 요소 순서를 원문 순서로 되돌린다. 짝지은 요소가 이어진 구간 안에서만 옮긴다. 표와 짝 없는 요소는 넘지 않는다.

## 검증

### 합성 내규 10종 (편·장·절 유무 × 계층 표현 5가지, 조 12~24개)
내규 프로파일을 적용했고, 정답 트리와 경로를 비교했다.

| 계층 표현 | 항·호·목 재현율 (전 → 후) |
|---|---|
| 번호 타이핑, 들여쓰기로 층 표현 | 0.78 → **1.0** |
| 다단계 자동 번호 | 0.0 → **1.0** |
| 조는 타이핑, 항·호·목은 자동 번호(조마다 재시작) | 0.0 → **1.0** |
| 스타일 연결 번호 | 0.0 → **1.0** |
| 번호 타이핑, 들여쓰기 없음 | 0.78 → 0.78 |

마지막 경우는 원문에 항과 목을 가를 신호가 없어서 무엇도 꾸며내지 않는다.

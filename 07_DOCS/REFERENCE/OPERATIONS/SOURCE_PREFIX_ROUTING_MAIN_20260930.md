# 질문 앞 내규·외규 라우팅 — 2026-09-30

사용자 지시에 따라 질문 시작 표시를 기준으로 원문 범위를 고정했다.
`내규: 내규데데이터 뭐있냐`가 목록 요청으로 인식되지 않는 문제를 수정해
로컬 MAIN `legal-agent-source-prefix-20260930-r2`(포인터 generation 36)로 재전환했다.
이후 명시한 출처 범위를 모델에도 알리는 r3를 로컬 MAIN generation 37로 적용했다.
선택 데이터 세대는 직전 릴리스와 같다.

## 입력과 실행 경로

- `내규: 승인 절차는?`, `내규 승인 절차는?`는 저장된 `internal` 문서만 사용한다.
- `외규: 승인 절차는?`, `외규 승인 절차는?`는 저장된 `external` 문서만 사용한다.
- 맨 앞에 독립된 표시가 없으면 기존 전체 문서 범위를 사용한다. 본문 중간의 `내규`·`외규`나
  `내규상`은 표시로 인식하지 않는다.
- 표시만 있고 질문이 없거나 해당 범위에 문서가 없으면 422로 중단한다.
- `내규: 내규데데이터 뭐있냐`, `외규: 데이터 뭐 있냐`처럼 데이터 보유 목록을 묻는
  표현은 저장된 문서 목록으로 응답한다. 이 경우 모델 호출 없이 선택 category 문서를
  나열한다. 질문 본문에 다른 category 이름이 있어도 맨 앞 표시가 우선한다.

`service.py` → `/v1/rag/ask` → `Pipeline.run/plan`에서 표시를 제거한 질문과 문서 ID
교집합을 만든다. 저장 세대에 결속된 origin projection·문서 메타데이터의 category를
`folder_navigation.bind_catalogue`로 읽는다. 제목·현재 RAW 폴더로 내규 여부를 추정하지 않는다.
요청의 `document_ids`, `scope`, `team_id`와 교집합을 적용하고, 같은 문서 ID를
검색·원문 읽기·관계 탐색·답변 세션에 전달한다. `GET /v1/rag/search`도 같은 `Pipeline.plan`을 쓴다.
출처가 미확인인 문서는 명시한 내규/외규 범위에 넣지 않는다.

내용 질문으로 모델 세션을 열 때는 선택된 category와 세션 문서 ID의 category가
모두 일치하는지 확인한다. `내규`를 선택하면 시스템 프롬프트에 현재 내규 데이터에
한정해 작업 중이며 허용된 내규 문서만 사용하라는 문구를 추가한다. `외규`도 같은
방식이다. 표시가 없는 질문에는 이 문구가 추가되지 않는다. 문서 목록 요청은 모델을
호출하지 않고 저장된 문서 목록을 반환하므로 이 문구의 영향을 받지 않는다.

기존 Request/Query 스키마, 데이터 세대와 GENOS 워크플로우 입력 형식은 변경하지 않았다.
표시는 자료 선택 지시이며 접근권한이나 외부 모델 반출 허가가 아니다.

## 확인과 상태

모의 혼합 출처로 접두어·문서 ID·요청 범위·실제 `/v1/rag/ask` 목록 경로를 검사했다.
관련 계약 검사 41개가 통과했고, 활성 릴리스 기반 stage에서 159문서 중 외규 145문서
범위와 외규 목록 HTTP 200을 확인했다. stage의 엔진/PIPELINE 해시를 고정하고
이전 활성 릴리스를 롤백 대상으로 보존했다. 검증·승인 기록은
`09_ARTIFACTS/AUDITS/20260930-source-prefix-main/`에 있다.

GENOS 내부 세대·내부 모델의 현장 질의는 확인하지 않았다. 현장에서는 같은 코드와
엔진 manifest·PIPELINE을 코드서빙 새 리비전에 함께 적용한 후 워크플로우 테스트 화면에서
`내규: [내용 질문]`, `외규: [내용 질문]`, 접두어 없는 질문을 확인한다.

R2 검증은 관련 계약 44개 통과와 활성 공개 세대의 실제 질문 문장 HTTP 200,
내규 범위 10문서의 비어 있지 않은 목록 응답을 포함한다. 검증·승인 기록은
`09_ARTIFACTS/AUDITS/20260930-source-prefix-main/fix-r2/`에 있다.
현장 선택 적용 ZIP·실행 TXT와 checkout 검증 절차는
[GENOS R2 인계](../../../../09_ARTIFACTS/HANDOFFS/20260930-source-prefix-r2/README.md)에 있다.

R3는 관련 계약 검사 46개와 모델 메시지 구성 모의 검사를 통과했다. 현재 로컬 활성
릴리스는 r3이며 검증·승인 기록은
`09_ARTIFACTS/AUDITS/20260930-source-prefix-main/prompt-r3/`에 있다. 내부 모델과
GENOS 워크플로우에서의 실제 답변은 아직 확인하지 않았다.
[GENOS R3 인계](../../../../09_ARTIFACTS/HANDOFFS/20260930-source-prefix-r3/README.md)는
R2 적용 checkout을 전제로 한다.

## 선택 릴리스와 현재 작업본

현재 작업본은 generation 43의 선택 릴리스와 **14개 파일**이 다르다. 직접 채팅 전송 3파일, PIPELINE 1파일, 엔진 선언 10파일이며 모두 최신 직접 채팅 반입본의 해시와 일치한다. 승격 당시의 작업 코드·후보·선택 릴리스 265파일 일치 기록은 당시 검증 결과다. 이후 작업본 전체를 선택 릴리스와 동일하다고 설명하지 않는다.

실제 `06_TOOLS/pipeline.py check`는 `service.service`를 통해 동결 릴리스와 같은 원문 세대를 선택하며 성공했다. 이번 검사는 모델 질의·재채점·재승격을 실행하지 않았다. 상세 파일별 차이와 코드·프로필·데이터 해시는 [상태 지문](GIT_WORK_STATUS_20261007.json)에 기록했다.

## 검증 결과와 미완료 항목

현재 작업본의 조사 제어·법령 탐색·AD·서비스 입구·shortcut 계약 검사에서 **138개 통과, 1개 실패**를 확인했다. 실패한 `test_v6_default_profile_and_derived_unit_index_boot_without_manual_injection`은 작업본의 `legal-agent-rag-v6` 프로필 선언 해시가 실제 `profile-unified-v6.json`과 다른 문제다. 작업본에서 기본 프로필로 직접 `create_app`을 구성하는 경로는 미완료다. 명시적인 실행 프로필을 사용하는 로컬 선택 릴리스의 서비스 연결 검사와 구분한다.

직접 채팅·SSE, 데이터 ZIP 도구, NFS SQLite의 관련 검사 **48개 통과**도 확인했다. 변경·보관 Python 2,426파일의 문법 검사, 포함 대상 JSON 파싱, WSL 개발 경계 검사와 인증키 패턴 검사에는 오류가 없었다. 전체 저장소 회귀 통과를 주장하지 않는다. 새로 추적하는 과거 코드·인계 소스의 기존 EOF 공백 등 형식 경고는 해시 고정 원본을 보존하며 함께 기록했다.

승격 당시 ADR-0677 기록은 계약 146개 통과, 독립 32질문 중 정상 응답 26개·세부 정답 23개, 기존 회귀 8질문 중 정상 응답 7개다. 당시 평가 프로필과 실제 서비스 프로필은 전송 재시도 1회에서 0회로 보정된 차이가 있으며, `quality_certified=false`를 유지한다. 이번 작업에서 당시 실험의 기준·판정·해시를 변경하지 않았다.

## Git에 포함하는 범위

구현·계약·설정 예시·테스트·실험 재현 소스와 인계 작성/설치 소스·필요한 코드 픽스처·안내·manifest를 구분해 커밋한다. `run_tool.py`가 실제 의존하는 code-v19와 기존 authoring 지원 3파일은 보존한다. 연구·보관 경로라는 이름만으로 실행 의존성을 제외하지 않는다.

원문·DB·runtime·활성 포인터·동결 릴리스 payload·ADR 원장/모델 입출력·코드 ZIP은 기존 정책대로 로컬 볼륨에 보존한다. 메일 요청 본문의 인코딩 첨부, 복사한 작업 백업, XML/압축 검증 로그, 렌더링한 Word/PDF/미리보기, 큰 자동 생성 감사·카탈로그는 Git에서 제외하고 원래 파일을 유지한다. 따라서 Git checkout만으로 로컬 운영 세대와 모든 과거 실험을 재현할 수는 없으며 기존 볼륨·manifest·receipt가 함께 필요하다.

커밋을 나누는 도중 새로 작성된 `06_TOOLS/EXPERIMENTS/adr_0678/test_wire_boundary.py`는 진행 중인 작업으로 구분해 이번 저장 범위에서 제외하고 로컬에 보존했다.

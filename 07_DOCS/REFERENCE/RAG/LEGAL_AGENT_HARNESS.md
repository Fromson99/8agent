# 법률 질의 에이전트 하네스 설계 v2

- 작성: 2026-09-18
- 상태: **설계안, 미구현.** 운영 MAIN·GenOS 배포는 이 문서로 바뀌지 않는다.
- 이전 설계와의 관계: 같은 날 대화에서 나온 v1 설계(앞단 분류 → 하네스 → 열린 탐색 → 검증)를
  과거 실험 기록과 ADR-0462 채점 결과로 고친 판이다. 바뀐 점은 §11에 모았다.
- 근거: 레거시 회고(ADR-0001~0160), ADR-0164~0462 결정 요약, 현재 세대(159문서) 실측.
- 구현 구조: [새 시스템 legal_agent](../ARCHITECTURE/LEGAL_AGENT_SYSTEM.md) — 새 패키지로 짓는 중(2026-09-18 사용자 결정).

## 0. 한 장 요약

```
질문
 │
 ├─[F] 앞단 분류 ─ 기능·목록·직독·용어·범위 밖은 여기서 끝낸다(모델 0~1회)
 │
 ├─ 도메인 하네스 (무엇을 확인하나 · 무엇을 믿나 · 어기면 안 되는 것)   ← 도메인이 같으면 불변
 ├─ 에이전트 프로파일 (얼마나 강하게 · 얼마나 많이)                    ← 모델·예산·문맥에 따라 조절
 │
 ├─[O] 탐색 ─ 모델이 도구를 고른다. 신호가 잡히면 서버가 대상 조문을 카드로 가져다 놓는다
 │
 ├─ 답변 전 종합 관문 ─ 확인 항목 장부가 전부 "근거" 또는 "미확인+검색 기록"이어야 쓴다
 ├─ 답변 작성 ─ 채택 조문 전체를 보고 자유 서술, 인용문은 코드가 붙인다
 ├─[V] 답변 뒤 결정론 검사 ─ 인용 일치·수치·부정 보존. LLM 검증자는 기록만(그림자)
 │
 ├─ 답변 + 작업 기록(읽은 조문·판정·경로·신호·관문)
 └─[FB] 사람 판정 → 다음 질문의 힌트(예약 자리에만 추가)
```

원칙 다섯 가지:

1. **도메인 하네스는 "무엇을", 에이전트 프로파일은 "얼마나"를 정한다.** 프로파일은 도메인의
   불변 제약을 풀 수 없다.
2. **도구를 주는 것으로는 부족하다. 서버가 가져다 놓는다.** 신호가 잡히면 서버가 대상 조문을
   카드로 올리고 장부에 등록한다. 모델은 처분만 한다.
3. **관문은 탐색을 멈추지 않는다.** 거절 대신 "무엇이 부족한지"를 돌려준다. 원문을 한 번도
   읽기 전에는 되묻지 않는다.
4. **답변 전에는 장부로 막고, 답변 뒤에는 결정론 검사만 한다.** LLM 검증자는 답을 떨어뜨리지 않는다.
5. **평가는 의미정확도가 먼저다.** 읽기·채택률과 계약 통과율은 진단용이다.

## 1. 지금 어디에 있나 — ADR-0462 측정

CM 골든 51문항을 같은 채점기로 쟀다. 채점기는 ADR-0056 채점 프롬프트와 Gemini flash-lite이고,
arm 이름은 채점 입력에 넣지 않았다.

| 답변 묶음 | 의미정답 |
|---|---:|
| 새 런타임, FTS 정렬 이전 (ADR-0460) | 15/51 |
| **새 런타임, FTS 정렬 (ADR-0461 run1, 현재)** | **26/51** |
| 같은 설정 재실행 (ADR-0461 run2) | 25/51 |
| 검색 없이 정답 조문만 준 Qwen3.8-27B | 44/51 |
| 검색 없이 정답 조문만 준 Haiku 4.5 | 40/51 |
| 검색 없이 정답 조문만 준 Opus 4.8 | 48/51 |

- 채점기 타당성: 상한 답변 153건에서 Gemini 판정과 ADR-0056 Opus 원판정이 139건(0.908) 일치했다.
- FTS 정렬은 읽기만이 아니라 정답도 올렸다. 새로 맞은 문항 14, 새로 틀린 문항 3.
- Qwen 상한과 비교하면 상한만 맞힌 문항이 20개, 런타임만 맞힌 문항이 2개다. 20개는 둘로 나뉜다.

| 격차 원인 | 문항 수 | 예 |
|---|---:|---|
| 결정 조문에 못 닿음(미독·미채택) | 10 | cm-050 「100분의 10이 적용되는 경우는?」 — 증권 인수업무 등에 관한 규정 제15조를 읽지 못함 |
| **닿았는데 답을 잘못 조립** | **10** | cm-042 「사외이사 관련 개정 내용은?」 — 아래 |

cm-042의 실제 답변은 다음과 같다.

> 상법 제542조의8 개정(2025.7.22)을 통해 사외이사를 '독립이사'로 명칭을 변경하고, 독립이사 선임
> 요건 및 후보추천위원회 구성 등에 관한 규정을 정비함.
>
> 채택 원문이 인용한 조문 1건을 읽지 않았습니다: 제542조의6

기준답변의 핵심은 "이사 총수의 3분의 1 이상을 독립이사로"와 "대통령령으로 정하는 상장회사는
3명 이상이면서 과반수"다. **"3분의 1"은 답을 쓴 모델이 받은 원문과 채택 인용 안에 있었다.**
cm-013(100분의 50), cm-014(20억), cm-045(주주총회)도 빠진 요건의 핵심어가 종합 입력에 있었다.
종합 단계가 받은 확인 항목은 `Q1` 하나였다. 모델은 요건을 "요건 등"으로 뭉개고, 진단 문구가
답변 본문에 섞였다. 런타임 답변 길이 중앙값은 296자이고 Qwen 상한은 494자다.

**이 설계의 우선순위는 여기서 나온다.** 회수만 고쳐서는 격차의 절반만 줄어든다. 확인 항목을
질문과 원문에서 제대로 뽑아 답변 전에 채우게 하는 것(§4.1, §7)이 회수 개선과 같은 비중이다.

## 3. [F] 앞단 분류

### 3.1 결정론 관문 (모델 0회)

| 유형 | 판별 예 | 응답 |
|---|---|---|
| 기능 질문 | "뭐 할 수 있어", "어떻게 써" | 고정 기능 카드: 되는 것·안 되는 것·질문 예시, 저장 문서 요약 |
| 목록·목차 | "어떤 문서 있어", "코스닥시장 상장규정 목차" | 문서·폴더·목차를 그대로 보여 줌 |
| 조문 직독 | 문서명 + 좌표만 있고 물음이 없음. 예: "코스닥시장 상장규정 제26조" | 원문 그대로. 긴 조는 항 목차(§4.5) |
| 인사·빈 질문 | 길이·패턴 | 짧은 안내 |

애매하면 통과시킨다. 법률 질문을 잘못 쳐내는 쪽이 더 나쁘다.

CM 질문은 대부분 이런 모양이다. 문서와 조문을 말하지만 **내용을 묻는 질문**이다.

> 벤처금융 및 전문투자자의 100분의 10 한도는 합산 기준인가?
> (업무 문맥: 신규상장 의무보유 - 코스닥시장 상장규정 제26조)

ADR-0458에서는 문서를 언급했다는 이유로 범위 밖 선택을 거절해 탐색이 시작도 못 했다.
**문서 언급은 범위를 좁히는 힌트이지 직독 요청이 아니다.** 물음이 있으면 법률 질문으로 보낸다.

### 3.2 분류 호출 (모델 1회)

| 분류 | 뜻 | 다음 |
|---|---|---|
| `capability` | 결정론이 못 잡은 기능 질문 | 기능 카드 |
| `catalogue` | 목록·목차 | 목록 |
| `lookup` | 특정 조문·별표·서식 원문 | 직독 |
| `definition` | 용어 뜻만 | §4.6 순서로 정의 제시. 정의가 위임으로 끝나면 위임을 한 번 따라간다 |
| `legal_question` | 해당 여부·기준·계산·권한·근거·절차 | 탐색 진입 |
| `out_of_scope` | 저장 문서 밖 법령, 개인 사건 상담, 법 아닌 질문 | 무엇이 범위 밖인지 + 있는 자료 안내 |
| `clarify` | 대상 문서·표현이 전혀 안 잡힘 | 되묻기. 단 문서 후보가 하나라도 있으면 먼저 읽는다 |

## 4. 도메인 하네스 (legal-kr-finance-v1)

> **2026-09-18 측정으로 좁혀진 범위(ADR-0465·0466).** 확인 항목 장부는 **답변 조립 단계에서 빼기로 했다.**
> 항목을 고정하고 순서를 뒤집어도 의미정답 이득이 0이었고(30 = 30), 모델이 항목을 다 채우지 못했으며
> (92 case-run 중 90회 서버 보완 요청, 잔여 누락 292), 호출은 3배였다. 조립 단계에서 값어치가 확인된 것은
> 아래 §4.8 불변 규칙과 코드 인용 조립이다. 장부는 "무엇을 더 찾을지" 정하는 탐색 단계에서 다시 시험한다.



한국 금융법 도메인이 바뀌지 않으면 바뀌지 않는 것만 둔다. 파일 하나로 컴파일하고 항목마다
출처(법제처 입안·심사 기준 쪽수, 해석례 번호, 근거 ADR)를 단다. 바꾸려면 근거와 ADR이 있어야 한다.

### 4.1 과업 유형 → 확인 항목

질문 하나에 유형이 여럿일 수 있다. 확인 항목은 **종합 단계의 요구사항**이 된다.
cm-042처럼 `Q1` 하나로 뭉치지 않게 하는 것이 이 표의 첫째 목적이다.

| 유형 | 확인 항목 |
|---|---|
| 해당 여부 | 원칙 규정 · 요건별 충족 · 예외·단서 · 주체 · 시점 |
| 기준 | 기준 조문 · 수치·기간·비율 원문 · 적용 범위 · 예외 |
| 계산 | 산식 · 산식 안 모든 변수의 정의 · 기준일 · 특례 |
| 권한 | 권한 규정 · 위임·재위임 · 결의 요건 · 정관·내규 위임 |
| 절차 | 단계·기한 · 제출 서류 · 담당 기관 · 예외 |
| 효과·제재 | 의무 조항 · 위반 효과(무효·벌칙·과태료) · 양벌·면책 |
| 설명·개정 | 정의 · 요건(수치 포함) · 효과 · 예외 · 개정 시점 |
| 근거 | 직접 근거 · 상위 근거(위임 사슬) |
| 내규 대조 | 내규 조항 · 상위 외규 · 차이·상충 |

cm-042 「사외이사 관련 개정 내용은?」은 "설명·개정"이다. 확인 항목이 "요건(수치 포함)"으로 열리면
"3분의 1 이상", "3명 이상이면서 과반수"를 채우지 않고는 종합 관문을 넘을 수 없다.

### 4.2 문형 신호

신호는 **채택한 원문에서** 서버가 결정론으로 찾는다. 찾으면 두 가지를 한다.
대상 조문을 카드로 가져다 놓고, 장부에 확인 항목을 추가한다. 실제 조문으로 보면 이렇다.

> **코스닥시장 상장규정 제26조(신규상장 의무보유)**
> ① 보통주식 신규상장의 경우 다음 각 호에서 정하는 바에 따라 상장신청인의 주식등을 의무보유하여야
> 한다. **다만,** 의무보유 대상자가 상장주선인과의 협의에 따라 요청하는 경우 … 2년 이내의 범위에서
> 의무보유 기간을 연장할 수 있다.
> …
> 5. 상장주선인(「증권 인수업무 등에 관한 규정」제6조에 따른 공동주관회사를 포함한다)이 취득한
> 투자기간(상장예비심사 신청일을 기준으로 한다)이 6개월 미만인 주식등: 상장일부터 6개월.
> **다만, 세칙으로 정하는 방법으로 산정한** 취득가격과 공모가격의 괴리율이 100분의 30 미만인 경우는
> 상장일부터 3개월로 한다.
> …
> ③ **제1항 및 제2항에도 불구하고** 신규상장신청인이 유가증권시장 주권상장법인이거나 해외증권시장에
> 상장한 기업인 경우에는 의무보유 대상에서 제외할 수 있다.

| 문형 | 이 조문에서 | 서버가 하는 일 | 장부에 추가 |
|---|---|---|---|
| 다만 | 제1항 본문 단서, 각 호 단서 | 효과를 세 가지로 분류한다: 예외(EXCEPTION_TO) / 한정(QUALIFIES_RULE) / 대체(OVERRIDES_RULE) | 단서 적용 여부, 적용 후 **형제 호 재확인** |
| 다음 각 호 | 제1항 제1호~제8호 | 호 목록 카드 | 질문과 관련된 호 전부 확인 |
| 세칙으로 정하는 | 제5호 단서 | 세칙에서 "규정 제26조제1항제5호"를 인용하는 조문을 찾아 카드로 | 세칙 내용 확인 |
| …에도 불구하고 | 제3항 | 제1항을 읽고 있어도 제3항을 신호로 올림 | 뒤집는 항 확인 |
| 이 경우 | (다른 조문) | 후단을 본문과 한 묶음으로 | 후단 조건 |
| 준용한다 | (다른 조문) | 준용 대상 카드 | 대상과 바꿔 읽을 항목 |
| 로 본다 / 로 추정한다 | (다른 조문) | - | 의제 범위, 반증 가능 여부 |
| (이하 "○○"이라 한다) | (다른 조문) | 같은 문서·버전의 정의 호만 카드로 | 정의 확인 |
| 부칙 경과조치·시행일 | (부칙) | - | 적용 시점 |
| 제외한다 / 그러하지 아니하다 | 종결형 | cue 자체를 결과로 고정(레거시 ADR-0155) | 제외 대상 원문 인용 |
| 정당한 사유, 상당한, 지체 없이 | 불확정 개념 | 판례·해석례 관문 조건 1(§4.4) | - |

**위임 사슬의 실제 예 — cm-004 「제5호의 괴리율은 어떻게 산정하는가?」**
ADR-0460에서는 규정 제26조까지만 읽고 "괴리율은 세칙으로 정한다"고 답해 틀렸다. 사슬은 다음과 같다.

```
코스닥시장 상장규정 제26조제1항제5호 단서 "세칙으로 정하는 방법으로 산정한 … 괴리율"
  └▶ 코스닥시장 상장규정 시행세칙 제23조
       ⑥ 규정 제26조제1항제5호 단서에 따른 취득가격과 공모가격의 괴리율은 다음 각 호에 따라 산정한다.
       1. 취득가격: 상장주선인이 상장예비심사 신청일 전 6개월 동안 취득한 … 가중 산술평균한 주식 취득가격
       2. 공모가격: 「증권 인수업무 등에 관한 규정」 제5조제1항에 따른 가격
            └▶ 증권 인수업무 등에 관한 규정 제5조제1항
       3. 취득가격과 공모가격 간 괴리율 = (공모가격 – 취득가격) ÷ 취득가격 × 100
```

규정에서 세칙으로 내려가는 위임은 law.go.kr API로 받을 수 없다. 대신 세칙 쪽이
**"규정 제26조제1항제5호 단서에 따른"**이라고 역으로 인용한다. 이 역인용으로 결정론 연결이 된다.
레거시 ADR-0093의 교훈에 따라 위임은 조건부로만 따라간다. **채택한 항의 원문에 위임 문구가 실제로
있고, 그 문구가 열린 확인 항목과 연결될 때만** 따라간다.

신호 원천의 순서는 이렇다.
1. **이미 검증된 자산을 현재 세대로 옮긴다.** 조건·예외·시점·수량 span 추출(레거시 ADR-0015, 49,626 span을
   1초에 추출)과 단서 조건·결과 그래프(ADR-0154, 단서 14,203개, 방향 교정 ADR-0155)가 있다.
2. 법제처 입안·심사 기준 2편은 빠진 문형을 찾는 **감사용**으로 쓴다.
3. 해석례 180건과 위키 쟁점 12편은 불확정 개념과 "이 표현이 보이면 이 쟁점을 의심" 목록으로 컴파일한다.
   설명글을 프롬프트에 넣지 않는다.

### 4.3 근거 위계와 권위 등급

```
법률 → 시행령 → 시행규칙 → 거래소 규정 → 시행세칙 → 내규 → (서식·점검표·안내서: 근거 불가)
```

- 결론은 규범 근거로 선다. 하위 근거만으로 결론을 내면 상위 근거 확인 항목이 생긴다.
- 권위 등급은 **순위를 뒤로 보내는 방식**으로만 쓴다. 후보에서 지우지 않는다.
- cm-011 「사내규정 정비가 상장심사에서 요구되는 근거는?」은 ADR-0460에서 기업실사 점검표의
  점검 항목을 근거로 답했다. 기대 근거는 코스닥시장 상장규정 제29조였다.
- **형제 문서 확정:** cm-005 「유가증권시장에도 벤처금융·전문투자자에 대한 의무보유 규정이 있는가?」는
  ADR-0460에서 기대 근거인 유가증권시장 상장규정 제27조 대신 같은 시장의 시행세칙 제21조를 채택했다.
  규정과 그 시행세칙, 코스닥과 유가증권처럼 구조가 닮은 형제 문서는 질문의 문서명·시장명과 위계로
  순위를 정한다.

### 4.4 판례: 다리와 근거

판례는 두 역할로 나눈다.

| | 다리(길찾기) | 해석 근거 |
|---|---|---|
| 모델이 판례를 보나 | 안 본다. 조문 카드만 보인다 | 본다 |
| 켜는 조건 | 비슷한 판례 점수가 기준 이상 | 서버가 확인할 수 있는 조건만 |
| 답변에서 | 인용하지 않는다 | 규범 근거와 따로 표시 |

**실제 예 — 판례 골든 `대법원 85도2297`**

> 질문: 회사 설립할 때 주금을 은행에 넣어 납입증명을 받고, 설립등기가 끝나자마자 그 돈을 빼면 문제가 되나?

질문 말(넣다·빼다·주금)과 조문 말(가장)이 겹치지 않는다. 판시사항에서 법 이름·조문 번호를 지운
질문으로 쟀을 때 현재 검색에서 상법 제628조는 후보 **1,729위**였다.

> **상법 제628조(납입가장죄등)** ①제622조제1항에 게기한 자가 납입 또는 현물출자의 이행을 가장하는
> 행위를 한 때에는 5년 이하의 징역 또는 1천500만원 이하의 벌금에 처한다.

다리가 켜지면 비슷한 판례의 판결요지가 걸린다. "주금으로 납입할 의사없이 … 돈을 은행에 예치하여
주금납입보관증을 교부받아 … 그 예치한 돈을 바로 인출하였다면 … 상법 제628조 제1항에 정한 이른바
납입 가장죄가 성립". 그 판례의 참조조문 상법 제628조가 후보 맨 앞에 올라온다.
모델에게는 `via: 판례 다리`만 표시된다.

**해석 근거 관문의 조건**(ADR-0275 교훈으로 모델 선언은 뺐다):
1. 채택한 조문에 불확정 개념 신호가 있다.
2. 채택한 조문이 다리 판례의 참조조문이고 유사도가 기준 이상이다. 위 예가 여기에 해당한다.
3. 채택한 규범 근거 둘이 같은 확인 항목에 다른 결론을 주고, 둘 다 인용됐다.

판례를 열면 서버가 그 판례의 참조조문을 **현행 번호로 바꿔** 카드로 올린다. 판결 당시 번호는 다를 수 있다.
공정거래법 2020년 전부개정 전 판례의 "제19조"는 지금 제19조가 아니다. 바꿀 수 없으면 그 판례는 다리에서 뺀다.

**배선 전 필수 측정:** 판례 다리는 판례 골든(101건)에서 1쪽 적중을 49에서 84로 올렸다.
하지만 나빠진 문항이 35개였고, ADR-0274의 판례 용어 다리는 일반 질문에서 recall을 떨어뜨렸다.
CM 51과 112문항 셋에서 손실이 없는 기준값을 모델 0회 순위 측정으로 먼저 정한다.

### 4.5 읽기 단위: 조 머리 + 항 + 호

현재 세대 실측(조 17,848개):

| 지표 | 값 |
|---|---|
| 조 글자 수 중앙값 / p75 / p90 / p99 | 296 / 795 / 1,859 / 8,308 |
| 2,000자 넘는 조 | 1,621개(9.1%). 이 조들이 전체 글의 58%를 차지 |
| 항이 있는 조 / 5개 이상 | 10,225 / 3,285 |
| 같은 조의 다른 항을 가리키는 항 | 8.2%. "제N항에도 불구하고"는 792건 |

기본 읽기 단위:
1. **짧은 조(프로파일 기준값 이하)는 통째로 준다.** 조의 75%는 800자 이하다.
2. 긴 조는 **조 머리 + 걸린 항과 그 아래 호 전부**를 준다.
3. **항 목차**를 같이 준다. 나머지 항은 번호, 첫 40자, 글자 수와 그 아래 호 번호만 보여 준다.
   형제 호를 못 봐서 틀린 레거시 ADR-0144의 교훈이다.
4. 같은 조의 다른 항이 이 항을 뒤집으면(제26조 ③ "제1항 및 제2항에도 불구하고") 신호로 올린다.
5. 더 보고 싶으면 펼치기(항·호·목·조 전체)를 쓴다.

**읽기 단위와 답변 입력은 다르다.** ADR-0462에서 오답의 절반은 원문을 받고도 답에서 빠뜨린 경우였다.
그러니 탐색은 항 단위로 좁혀도, 답변 작성 때는 채택한 조의 관련 항·호를 모두 준다(§7).

### 4.6 용어 뜻을 찾는 순서

현재 세대 용어 사전:

| 순서 | 출처 | 규모 | 쓰임 |
|---|---|---:|---|
| 1 | 우리 문서의 정의 조항 | 8,533 | 규범 근거로 인용 가능. 문서마다 정의가 다르면 문서별로 보여 준다 |
| 2 | 법제처 법령정의사전 | 17,887 | "다른 법령의 정의"로 출처 표시 |
| 3 | 경제교육 / 국세청 용어 | 3,029 / 1,718 | "참고 설명" 라벨. 근거 아님 |
| - | 법제처 지식용어→일상용어 관계 | 95,043 | 뜻이 아니라 다리(검색 확장 힌트) |

정의가 "대통령령으로 정하는 자"처럼 위임으로 끝나면, 뜻 질문이라도 위임을 한 번 따라간다.

### 4.7 사실 포섭 (해당 여부 질문)

```
요건(원문 인용) │ 사용자 사실 │ 판정
────────────────┼─────────────┼──────────────
요건 1          │ 질문 속 표현 │ 충족 / 불충족 / 미상
요건 2          │ (없음)       │ 미상 → 조건부 결론 또는 되묻기
예외·단서       │ …           │ …
```

ADR-0220에서 질문 문장 ID로 사실을 연결하고 설명·적용 틀을 더하자 조건 검사가 11/18에서 17/18로
올랐다(자동 답변 채점은 7에서 9).
미상인 요건이 있으면 조건부 결론으로 답한다. 예: "○○이면 해당, 아니면 비해당".

### 4.8 불변 제약 (어떤 프로파일도 못 푼다)

1. 인용문은 모델이 쓰지 않는다. 모델은 인용 참조만 고르고 본문은 코드가 붙인다.
2. 인용은 원문과 글자 그대로 일치해야 한다.
3. 수치·기간·비율·부정 표현은 원문 표기 그대로 옮긴다("100분의 30 미만", "제외할 수 있다").
4. 원문에 없으면 "규정 없음"이다. "불가"나 "허용"으로 바꾸지 않는다.
5. 결론은 규범 근거로 선다. 판례는 해석 근거로 따로 표시하고, 관문이 안 열린 판례는 인용하지 않는다.
6. 기준일을 모르면 현행 기준임을 밝히고 경고한다(레거시 ADR-0018).
7. 시스템 진단 문구(읽지 못한 조문, 범위 밖 인용)는 답변 본문이 아니라 작업 기록에 둔다.

### 4.9 피드백의 의미

- 사람이 판정한 것만 순위에 반영한다. 모델 판정은 기록만 한다.
- 과거 판단은 **예약된 자리에만 추가**한다. 현재 후보를 밀어내지 않는다(레거시 ADR-0064).
- 원문 세대가 바뀌면 그 판단은 "낡음"으로 표시한다.
- 자동 학습 후보는 자동 승인하지 않는다(ADR-0433).

모델·예산·문맥 관리 능력에 따라 조이거나 푼다. ADR 실험으로 자유롭게 조정한다.

| 조절 항목 | GenOS Qwen | Gemini flash-lite (실험) | 큰 모델 |
|---|---|---|---|
| 호출 예산 / 종합 몫 예약 | 14 / 4 | 14 / 3 | 20 / 2 |
| 읽기 창 | 4구간·8천 자 | 6구간·18천 자 | 12구간·60천 자 |
| 통째로 주는 조 길이 | 800자 | 1,500자 | 4,000자 |
| 신호 처리 | 서버가 카드로 가져오고 종합 관문에서 강제 | 같음 | 카드는 제안, 검사는 답변 뒤 |
| 단계 관문 | 방향잡기 → 찾기 → 종합 | 같음 | 종합 관문만 |
| 한 번에 보이는 도구 | 단계별 4~6개 | 8개 | 전부 |
| 형식 오류 | 서버가 가장 가까운 유효값으로 고치고 기록 | 같음 | 거절 후 재시도 |
| 스키마 변환 | 짧은 ID, enum 최소, 얕은 중첩, thinking 끔 | 짧은 ID, enum 제거 | 제한 없음 |
| 과거 판단 힌트 | 상위 3건 요약 | 5건 | 원문 기록 |
| 판례 다리 k·m·기준값 | 코퍼스별 측정값 | 같음 | 같음 |

규칙:
1. 프로파일은 §4.8 불변 제약을 풀 수 없다.
2. 프로파일은 확인 항목의 **내용**을 바꾸지 못하고 **집행 강도**만 바꾼다.
3. 어떤 프로파일도 원문을 읽기 전에 되묻거나 멈추지 않는다.
4. 장부·관문·ID는 서버가 소유한다. 모델은 제안한다.
5. "모든 구간을 한 번씩 판정하라" 같은 계약은 두지 않는다. ADR-0460에서 35회 위반했다.

## 6. [O] 탐색

**도구**(BGE-M3 의미 검색은 뺀다):

| 갈래 | 도구 |
|---|---|
| 구조 | 목차, 읽기(조 머리+항+호), 펼치기, 이웃, 참조 따라가기, 역인용, 위임, 정의 |
| 검색 | 역매칭(용어), 형태소 FTS, 판례 다리(서버 자동), 공통 필터(문서·폴더·외규/내규·본문/개정이력·장절·본문/부칙) |
| 판단·기록 | 메모, 판정(채택/제외/보류), 관계 거부, 확인 항목 미확인 선언, 답변 |

**본문에 없는 말**은 세 가지로 메운다. 판례 다리, 용어 다리(일상용어 → 지식용어 → 본문),
모델이 쓴 가상 조문 문장을 FTS에 넣는 방법이다. 결과마다 어느 경로로 걸렸는지 표시한다.

**모델이 매 턴 보는 것**: 질문, 확인 항목 장부, 서버가 가져다 놓은 카드, 메모, 방문 목록,
직전 결과, 남은 예산. 원문은 검토·종합 턴에만 넣고, 나머지 턴에는 개수와 핸들만 넣는다.
작업 루프 규모 교훈에서 종합 호출이 92k자까지 불어난 적이 있기 때문이다.

**"미확인"의 조건**: 그 확인 항목에 대해 표적 검색을 1회 이상 한 기록이 있어야 한다.
ADR-0297에서 모델이 근거 없이 쟁점을 닫으려 했다.

## 7. 답변과 검증

### 7.1 답변 전 종합 관문

장부의 모든 확인 항목이 "근거 있음(인용)" 또는 "미확인 + 검색 기록"이어야 답변을 쓴다.
확인 항목은 §4.1 유형표와 §4.2 신호에서 온다. 질문 하나를 `Q1` 하나로 두지 않는다.

### 7.2 답변 작성

- 입력: 채택한 조의 관련 항·호 전체, 신호로 가져온 카드, 장부.
- 형식: 확인 항목 순서를 따르는 **자유 서술**이다. 각 문장 끝에 근거 핸들을 달면 코드가 인용문을 붙인다.
  ADR-0219에서 근거를 보존한 자유 답변이 12/18로 가장 좋았고, 카드를 더하면 11/18이었다.
- 형식 효과는 아직 분리되지 않았다(§10 1단계). 모델 차이(flash-lite 대 Qwen 27B)와 형식 차이(구조화
  finding 대 자유 서술)를 같은 채택 원문으로 먼저 가른다.
- 규범 근거 / 해석 근거 / 참고 설명을 구분해 표시한다.

### 7.3 답변 뒤 결정론 검사

| 검사 | 실패 시 |
|---|---|
| 인용 참조가 실제로 읽은 원문을 가리키는가 | 해당 문장 제거 + 기록 |
| 수치·기간·비율이 인용 원문에 글자 그대로 있는가 | 경고 표시 |
| 부정 표현("하지 아니한다", "제외")이 뒤집히지 않았나 | 경고 표시 |
| 관문이 안 열린 판례를 인용했나 | 해당 문장 제거 |

LLM 검증자는 **그림자**로 돌려 기록만 한다. 사람 판정으로 보정된 뒤에만 역할을 다시 정한다.

### 7.4 작업 기록 (사용자에게 보임)

- 앞단 분류, 과업 유형과 바꾼 이유
- 읽은 조·항과 판정(채택/제외/보류), 한 줄 이유
- 어떤 경로로 닿았나(FTS / 역매칭 / 판례 다리 / 용어 다리 / 위임 / 역인용)
- 잡힌 신호와 처리 결과, 판례 관문 개폐
- 읽지 않은 상위 후보 수(예산 부족 표시)
- 과거 판단 힌트를 썼다면 그 출처와 날짜

## 8. [FB] 피드백 루프

현재 상태:
- 새 런타임은 피드백을 제안서로 저장만 하고, 탐색에서 읽지 않는다. 쌓인 것은 1건이다.
- 레거시 경로의 원장에 판정 848줄과 질의 튜플 183줄이 있다.
- 8월 감사 때 "5개월치 기록에 승인 0건"이었다. 사람이 판정하게 만드는 장치가 없으면 루프는 닫히지 않는다.

설계:
1. 답변 화면에 👍/👎, "이 조문이 맞다/아니다", "빠진 조문 추가" 버튼을 둔다. 이것이 판정 트리거다.
2. 판정은 세대 해시와 함께 사건 원장에 쌓인다.
3. 다음 질문이 오면 비슷한 과거 질문의 **사람 판정**을 방향잡기 단계 힌트로 보여 준다.
   - 채택 판정: 예약 자리 k개에 후보로 추가한다. 기존 후보를 밀어내지 않는다.
   - 제외 판정: 진입 후순위로 보낸다. 삭제하지 않는다.
4. 레거시 원장 1,031줄을 새 세대 조문 ID로 옮겨 첫 씨앗으로 쓴다. 못 옮기는 줄은 "낡음"으로 둔다.
5. 효과는 짝지은 재실행으로 잰다. 새로 맞은 문항과 새로 틀린 문항을 따로 센다.

## 9. 평가 계약

| 지표 | 위치 | 비고 |
|---|---|---|
| **의미정답 수/51** | 1순위 | ADR-0462 채점 계약: ADR-0056 채점 프롬프트, Gemini flash-lite, arm 블라인드, seed 섞기 |

| 단계 생존 | 진단 | 결정 조문 읽음 → 채택 → 정답. ADR-0462: 채택 38건 중 24건 정답 |
| 상한 대비 격차 분해 | 진단 | 회수 측 / 조립 측 |
| 확인 항목 충족률, 신호 처리율, 관문 준수 | 진단 | 계약 통과를 성능으로 보고하지 않는다 |

- 실행 변동이 있다(run1 26, run2 25, 문항별 9건 뒤바뀜). 한 번 실행한 차이 ±2는 결론으로 쓰지 않는다.

## 10. 단계 계획

각 단계는 ADR 하나로 남기고, ADR-0462 채점 계약으로 의미정답을 함께 보고한다.

| 단계 | 내용 | 모델 호출 | 통과 기준(사전 고정 예시) |
|---|---|---|---|
| 1 | **답변 조립 분리 실험**: ADR-0461 run1의 채택 원문을 그대로 두고 (a) 현재 구조화 종합, (b) 자유 서술 + 확인 항목 분해, (c) 진단 문구 제거만 비교 | 51×3 + 채점 | 조립 측 10건 중 절반 이상 회복, 회귀 ≤ 2 |
| 2 | 신호 자산 이식: span 추출·단서 그래프·역인용 위임을 현재 세대로, 전수 출현 수·오탐 측정 | 0 | 표본 사람 확인 오탐률 기록 |
| 3 | 판례 다리 기준값: CM 51·112문항·판례 101의 순위 손익 | 0 | 일반 질문 손실 0에서 판례 이득 최대 |
| 4 | 앞단 분류 + 결정론 인용 검사 + 출력 수리 | 분류만 | 법률 질문을 쳐낸 오분류 0 |
| 5 | 항 단위 읽기 + 펼치기 + 신호 카드 + 판례 다리 배선 | E2E | 회수 측 10건 중 절반 이상 회복 |
| 6 | 사실 포섭 표, 피드백 트리거와 레거시 원장 이식 | E2E | 짝지은 비교에서 회귀 ≤ 2 |
| 7 | 검증자 LLM 그림자 운영 + 사람 blind 보정 세트 | 채점 | 오탐·누락 비율 기록 |

1단계를 맨 앞에 둔 이유: 격차의 절반이 조립 측이고, 회수를 건드리지 않고 51건 재생성만으로 잴 수 있다.

## 12. 열린 질문

1. GenOS에서 실제 도는 모델과 그 모델의 구조화 출력 안정성. 프로파일 값은 그 측정 뒤에 확정한다.
2. 사람 blind 판정 세트의 크기와 담당. Gemini 채점기는 Haiku 상한 답변에서 Opus보다 7건 엄격했다.
3. 판례 다리 기준값(3단계 측정 전까지 미정).
4. 항 목차 첫 40자가 충분한지. 항 첫 문장이 긴 규정에서 따로 재야 한다.
5. 내규 대조 유형은 기존 비교기를 쓴다. 이 하네스 장부와 비교기 결과를 어떻게 합칠지 정해야 한다.

# 최신 법령 선택과 실제 API 연결

2026-09-11, ADR-0362의 데이터 유지보수 결과다. 시스템은 기존 하나의 통합 파이프라인이며,
이번 변경은 동일 코드가 읽는 데이터 세대 선택이다. ADR-0361 후보의 운영 승격은 아니다.

## 법제처가 이미 주는 연결

| 단계 | API | 실제 응답의 연결 정보 |
|---|---|---|
| 일상용어 목록 | `dlytrm` | 용어명과 `dlytrmRlt` 조회 링크·MST |
| 일상용어→법령용어 | `dlytrmRlt` | 법령용어명, 관계 종류·코드, 대상 MST, 용어 및 조문 관계 링크 |
| 법령용어→조문 | `lstrmRltJo` | 법령명, 조번호·가지번호, 조문내용, 법령 ID·JO가 포함된 역방향 링크 |
| 조문→용어 | `joRltLstrm` | 기존 수집기 지원 endpoint; 이번에는 역방향 링크만 확인하고 호출하지 않음 |

실제 확인: `계약취소(MST=152377)` → **연관어** `청약철회(MST=567779)` →
`전자상거래 등에서의 소비자보호에 관한 법률`의 제17조 등.
`환불` → `대금환급`, `반품` → `물품반납`·`환불` 연결도 있다.
`반품`에는 **반의어** `납품`도 나오므로 모든 간선을 동의어로 처리해서는 안 된다.
이 예시는 API가 제공하는 검색 연결이며 특정 사안의 적용 법률을 판단한 결과가 아니다.

3개 일상용어 응답에서 간선 9개, 각 응답의 첫 법령용어에 대한 조문 조회 3회에서
조문 레코드 102행을 저장했다. 원문 및 정규화 응답은 기존 DatasetPackage 6개로 발행했다.
API의 `검색결과개수=1`은 조회된 기준 용어 수이고 중첩 간선·조문 행 수가 아니다.

목록만 수집된 상태를 “API에 연결이 없다”고 설명하면 안 된다. ADR-0361 동결 시점에는
목록 3종만 저장되어 있었고, ADR-0362에서 위 관계 응답 6개를 추가 저장했다.
관계 전체를 수집한 것은 아니며 **운영 RAG의 관계 패키지 자동 소비는 아직 적용하지 않았다.**

## 현재 법령 데이터

`law_index.json`과 원본 수집 manifest에는 이미 수집 기준 최신 현행본이 지정돼 있었다.
반면 RAG 세대에는 과거 판본도 함께 들어 있었다. 동일 법령명 37그룹의 최신본을
이 지정·시행일·원본 SHA-256과 대조해 남겼다. 수집 기준일은 **2026-09-04**다.
2026-09-11 시점의 법령 전체를 다시 수집했다는 뜻은 아니다.

| 대상 | 적용 전 | 적용 후 |
|---|---:|---:|
| 문서 | 207 | 159 |
| 중복 법령명 그룹 | 37 | 0 |
| 원문 블록 | 437,691 | 308,795 |
| 벡터 행 | 120,445 | 54,825 |
| 의미 엔티티 | 7,631 | 7,631 |
| 의미 관계 | 375 | 375 |

현재 로컬 선택: `ACTIVE_RELEASE.json` generation **10**, 데이터 세대
`semantic-latest-laws-20260911-v1`. 본문·구조·FTS·벡터에서 이전 판본을 함께 제외했다.
남긴 원문과 의미 payload는 그대로이며, 의미 근거 749건의 원문 위치와 해시도 검증했다.
원본 패키지와 이전 세대는 이력·롤백용으로 보존한다. GENOS 원격 배포는 수행하지 않았다.

## 같은 파이프라인에 연결할 때의 계약

`질문 → 일상용어 → API가 지정한 법령용어 → API 조문 좌표 → 현재 선택 법령의 실제 조문`
을 기존 `retrieve`의 후보 경로로 합친다. 이어서 같은 `select → assemble → answer`를 쓴다.
API에 있는 간선을 찾는 LLM은 필요 없다. 질문에서 명시적으로 드러나지 않는 의미를 찾거나,
여러 조문의 실제 적용 관계를 판단하는 작업은 별개다.

- 조문 링크의 법령 `ID`와 6자리 `JO`를 보존한다. 현재 정규화 레코드의 `source_id`가
  비어 있어도 링크에 좌표가 있다. 빈 ID를 임의 생성하지 않는다.
- 같은 API 조문이 여러 번 나올 수 있으므로 ID·JO로 중복을 구분하고, 현재 원문 버전에
  재착지시킨다. API의 조문내용만으로 기존 원문의 버전을 바꾸지 않는다.
- 본문과 부칙의 동일 조번호 충돌은 여전히 별도 처리해야 한다.
- 이번 처리는 현재 데이터 세대의 정리다. 차기 전체 적재에서도 최신 법령 선택을
  다시 적용해야 한다. 과거 세대 전체를 재적재하면 제외했던 판본이 다시 들어갈 수 있다.

선택·검증·적용 영수증과 롤백 명령은
[ADR-0362](../../../04_EXPERIMENTS/ADR/ADR-0362-latest-law-serving-selection/README.md)에 있다.

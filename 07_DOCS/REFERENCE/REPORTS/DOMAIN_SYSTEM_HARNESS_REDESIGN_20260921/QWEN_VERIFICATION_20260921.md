호출·지연 감소에는 탐색 조기 종료가 포함되므로 효율 개선으로 판정하지 않는다. v3는 빈 출처의 확인 한계 응답을 게시했고, v4는 외부 전송 승인과 원본 export flag 비교 충돌로 게시6건이 모두 차단됐다. 이를 GENOS 현장 실패로 확대하지 않는다.

실제 확인된 문제:

1. CM003 두 반복 모두 상장규정만 남기고 시행세칙을 빠뜨렸다. 선택 이유는 제3호·제4호를 말하지만 정확 발췌는 제2호·제4호였다. article 회수와 필요한 span 회수를 구분해야 한다.
2. CM018 첫 반복은 새 검색 후보40개를 얻고도 no_progress 종료했다. v4 progress_key가 새 후보 발견을 세지 않아 READ 기회를 잃었다.
3. CM018 둘째 반복은 READ까지 진행했으나 REVIEWED 오제안과 1600자 초과 선택에서 복구하지 못했다.
4. 실험별 전송 승인과 원본 export_allowed를 v4 publication guard가 동일 필드로 비교해 BLOCKED. 원본 flag와 게시 검사는 그대로 유지했다.

모의 계약24개는 이번 동결 snapshot에서도 통과했다. Qwen이 실제 고른 카드2건의 원문 무결성은 통과했지만 관련성·완전성은 통과를 보장하지 않았다. 동일 CM003 카드의 Qwen 관련성 평가는 false/true로 갈렸다. 주변 답변과 익명 위치도 달라 동일 전체 입력의 재채점 실험은 아니다. 자동 precision 1/2도 미교정 수치다. 평가자가 발췌 호를 잘못 설명한 기록까지 보존했고 재채점하지 않았다.

제품·평가 결과를 본 뒤 코드·프롬프트·한도를 수정하거나 추가 반복하지 않았다. MAIN·활성 릴리스·불변 원본은 유지했다. CM3 인샘플이며 법령/기준답 현행성, 새 OOS 성능, GENOS 내부 모델·권한·화면은 확인하지 않았다.

완료 검사: ADR-0488 `validate --final` 통과, frozen 코드·모델 정책·활성 MAIN 포인터 hash 불변, `git diff --check` 통과. 전역 graph 파일은 생성했으나 기존 다른 ADR의 오류3건이 남았다: ADR-0305 run purpose 값, ADR-0444의 ADR-0432/navigation 부모 기록, ADR-0158/v2-candidate graph source 부재. 이번 검증 때문에 과거 완료 ADR을 고치지 않았다. 전역 graph 전체 통과로 보고하지 않는다.

골드 등록용 테이블·엔티티·컬럼 정의서 R9

이번 R9을 사용해 주세요. 앞서 발송한 R8을 대체하는 수정본입니다.

1. 명칭 표시
- 엔티티명: 논리 모델에서 사용하는 한글 이름
- 테이블명: 물리 모델에서 사용하는 영문 이름
- 컬럼 논리명: 속성의 의미를 나타내는 한글 용어명
- 컬럼 물리명: 데이터베이스에서 사용하는 영문 컬럼명
- 첫 번째 '00_테이블목록' 시트에 10개 엔티티명과 테이블명을 함께 기재했습니다.
- 각 상세 시트 상단에도 엔티티명과 테이블명을 표시했습니다.
- 이번 정의서에서는 엔티티와 테이블을 한 쌍으로 대응했습니다.

2. 정의 작성
- 10개 엔티티 정의와 49개 컬럼 정의를 전체 수정했습니다.
- 특정 업무나 제품에 한정하지 않고 저장하는 정보의 의미와 용도를 중심으로 작성했습니다.
- 파일명, 저장 형식, 특정 알고리즘, 프로그램 처리 방식은 정의에서 제외했습니다.
- 같은 의미의 컬럼은 여러 테이블에서 동일한 정의를 사용했습니다.
- 컬럼 정의는 공통 의미를 설명하고, 테이블별 관리 대상과 한 건의 단위는 엔티티 정의에 적었습니다.
- 같은 의미와 구조의 데이터를 관리하는 다른 프로젝트에서도 정의를 재사용할 수 있습니다.

3. 기존 설계와의 관계
- R8의 테이블명, 컬럼명, 타입, 길이, PK, 필수 여부 및 제약조건을 유지했습니다.
- 이전에 조정한 VARCHAR2 1000 BYTE도 유지했습니다.
- 문서의 정의를 수정한 것으로, 데이터베이스 생성이나 실제 프로그램 변경을 포함하지 않습니다.

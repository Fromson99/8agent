- 원문 대상: 제13조제5항제1호 **나목 단서**.
- 저장된 mention_text/locator: `제5항제1호`.
- 저장된 target_unit_path: `⑤ / 1.`. target blocks193·194·195: 제1호 머리 + 가목 + 나목.
- 저장된 판정: `coordinate_status=EXACT`, `resolution_state=RESOLVED`.
- 나목 구조는 실제 존재한다: unit183, parent181, block195. 구조가 없어서 찾지 못한 경우가 아니다.

법률 에이전트 B03·B05 골드 등록용 엑셀 R8
작성일: 2026-10-28

사용 파일
법률에이전트_B03_골드등록용_테이블별_R8.xlsx
법률에이전트_B05_골드등록용_테이블별_R8.xlsx

기존 삼성메일의 R7 첨부 대신 이번 R8을 사용합니다.
각 파일은 기존과 같은 10개 테이블 시트·49개 컬럼으로 구성했습니다.
두 파일의 차이는 과제코드 B03/B05와 이에 따른 테이블명·참조 대상명입니다.

반영 사항
1. 사용자 사진 10장과 추가 사진 2장의 수정 내용을 반영했습니다.
   누락되어 보이지 않던 문서본문의 상단 3개 컬럼과 검색관계의 마지막 컬럼도 포함했습니다.

2. 문서ID·구조단위ID·상위구조단위ID·본문조각ID 및 검색·관계 문자열은
   VARCHAR2(1000 BYTE)로 통일했습니다. 대상 타입·길이 열에 512 BYTE는 없습니다.
   구조 관련 ID의 BIGINT 표기는 제거했으며 원천 식별 문자열을 보존합니다.
   조회자료ID·해시 등 기존 짧은 식별값까지 일괄 1000 BYTE로 늘린 것은 아닙니다.

3. 문서명은 VARCHAR2(2250 BYTE), SHA-256 해시 열은 VARCHAR2(100 BYTE),
   온톨로지게시ID는 VARCHAR2(64 BYTE), 개념그룹ID는 VARCHAR2(100 BYTE)입니다.
   같은 개념의 컬럼은 테이블마다 이름·타입·길이를 동일하게 맞췄습니다.
   문서위치 연결의 문서해시값은 현 원천에서 원문 판본으로 사용하는 전체 문서 해시를 뜻합니다.
   현재 SRC_VER_ID에 임의의 비해시 판본 문자열을 넣는 확장 경로까지 이 열로 포괄하지 않습니다.

4. 등록일시는 TIMESTAMP WITH TIME ZONE, 소수초 정밀도 6,
   NOT NULL / DEFAULT SYSTIMESTAMP로 정리했습니다.
   변경순번·작업버전은 NUMBER, 정밀도 30·소수자리 0으로 표기했습니다.

5. PK·FK·CHECK는 최종 컬럼명 기준으로 재작성했습니다.
   본문조각ID의 PK는 BODY_SLC_ID를 사용합니다.
   조회채널의 변경순번은 CHAN_NO >= 1,
   온톨로지선택의 변경순번은 CHAN_NO >= 0입니다.
   PK 전체 구성·순서와 필수 여부, FK의 참조 컬럼 및 타입·길이를 함께 점검했습니다.

6. 논리명·도메인·수식어를 일치시켰습니다.
   원문게시해시값·조회게시해시값·문서해시값은 값 도메인입니다.
   조회자료식별내용·소속자료식별내용·대상자료식별내용은 내용 도메인입니다.
   동일한 구조단위ID는 STRC_UNIT_ID, 동일한 명세해시값은 MNFST_HASH_VALU로 통일했습니다.

7. 49개 컬럼 정의를 저장 대상·업무 용도·생성 규칙·NULL 의미에 맞게 다시 작성했습니다.
   전체 부가정보를 삭제하는 것으로 오해되지 않도록 '부가정보본문생략여부'로 정리했습니다.
   이 값은 JSON 내부에서 본문내용과 중복되는 본문을 생략했는지 나타냅니다.

8. 검색 문자열의 한글 여부를 Y로 수정했습니다.
   원문·제목·부가정보·온톨로지 지식 등 한글 직접 저장 열은 Y입니다.
   원문게시정보·조회게시정보·조회자료내용의 JSON은 현재 직렬화 방식에서
   한글을 유니코드 이스케이프로 저장하므로 N이며 그 이유를 셀 메모에 명시했습니다.
   숫자·일시 열은 '해당 없음'입니다.

이행 메모
- 이번 결과는 등록용 정의서 수정이며 제품 코드·선택 MAIN·현장 DB를 변경하지 않았습니다.
- 영문명·타입을 실제 DB에 적용할 때는 셀 메모의 현재 개발계 컬럼 매핑을 함께 사용합니다.
- 여부값은 현재 1→Y, 0→N, NULL 유지로 변환하고 소비자에서 역변환해야 합니다.
- 문서명은 현재 로컬 1,547건에서 최대 1,163 BYTE를 확인했습니다.
  이후 원천값이 2,250 BYTE를 넘으면 잘라 저장하지 않고 초과 자료로 분리합니다.
- 검색키의 기존 512 BYTE 초과 해시 처리 규칙은 DB 컬럼의 1,000 BYTE 확대와 별개입니다.
- 기존의 PK·NULL·FK·CHECK 의미를 보존했습니다. 임의의 추가 FK나 새로운 필수조건은 넣지 않았습니다.
- 표준용어 승인·모델 승인·실제 DB 생성 및 적재·조회 검증은 이번 파일 작성과 별도 단계입니다.

검증 범위
각 파일 10표·49컬럼, 컬럼명 중복, 이름 길이, 논리명·수식어·도메인 일치,
PK 구성·순서·필수 여부, FK 대상·타입·길이, CHECK 참조, 공통 컬럼 일관성,
한글 표시, 원본 R7 보존 및 XLSX 내부 파일 무결성을 확인합니다.
기존 사진과 R7 원본은 그대로 보존합니다.

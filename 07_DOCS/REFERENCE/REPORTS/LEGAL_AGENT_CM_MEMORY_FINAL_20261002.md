# 실제 CM 데이터로 검증한 멀티턴 정정·경험 재사용

2026-10-02 · WSL 로컬 연구 후보 · ADR0611 → ADR0612 → ADR0613

실제 저장된 **CM038 대표자의 내부회계 보고 위임**, **CM003 신규상장 의무보유** 질문과 공개 원문을 사용했다. 질문별로 12턴·7턴을 강제로 진행했고, 최종 비교는 같은 19턴씩 수정 전후 총38턴이다. 후속 정정 발언은 실험용으로 작성했다. 세 번의 비교 전체는114턴이다. CM61문항 전수평가는 아니다.

사용한 자료는 현재 선택된 원문 세대의 공개145문서와26597개 정규 조문 좌표다. 내부 자료를 외부로 전송하지 않았고 원문 export 플래그도 바꾸지 않았다. 저장 CM 기준답은 제품에 넣지 않고 실행을 모두 마친 뒤 사후 평가에서만 사용했다.

## 핵심 판정과 원인

**정정 체인의 상태 복원·이력은 개선됐지만 전체 기능 완료로 판정하지 않는다.** 마지막 비교는 응답 완료16/19→18/19, 기능27/33→31/33, 실제 DB 조건 복원2/4→4/4, 이력 설명1/2→2/2다. 저장 CM 기준답 일치는7/12→6/12로 개선을 확인하지 못했다. 채택 상태는 Rejected이며 실행 중인 MAIN은 그대로다.

1. **추가 검색 연결 누락:** 선별 모델이 추가 탐색을 요청했으나 실행기가 그 신호를 받아 앞 단계로 돌아가지 않았다. CM003에서 시행세칙을 빠뜨린 직접 원인이다.
2. **근거 선택 오류:** CM038의 한 정정에서 근거 선택 모델이 두 번 모두 빈 목록을 반환해 답변이 중단됐다. 이후 턴에서는 저장된 사건 상태를 이어받아 복구했다.
3. **검사 기준 불일치:** CM038 최초 답변의 포괄적 위임불가 문장과 뒤따르는 예외를 제품 검사는 허용하고 사후 평가는 불일치로 판정했다. 두 판정을 보존하며 정답 점수를 바꾸지 않았다.
4. **온톨로지 적재 의미 미완:** 최종 경험의 조사 원문 전체에 SUPPORTED_BY가 붙는다. 조사 자료·채택 근거·답변 인용을 구분해야 한다. 법률 개념·관계 자체를 승인된 목록으로 강제하는 통제도 아직 설계 범위다.

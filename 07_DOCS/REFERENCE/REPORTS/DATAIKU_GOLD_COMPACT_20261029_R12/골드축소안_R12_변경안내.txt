골드 레이어 테이블 축소안 R12

기존 R11 검토안 대신 이번 R12 축소안을 사용해 주세요.
- R11: 16개 테이블, 전체 컬럼 합계 88개
- R12: 13개 테이블, 전체 컬럼 합계 60개
- 기존 골드 10개 테이블의 49개 컬럼 유지
- 벡터 3개 테이블의 11개 컬럼 추가: 게시정보 2개 / 구간데이터 6개 / 활성선택 3개

전문검색은 기존 검색관계 테이블(SRCH_ROW)을 재사용합니다.
모델·판본·건수·시각·입력 해시 등은 JSON에 보존하고 검증합니다.
검색에 필요한 문서ID·원문단위ID·일반 인덱스와 활성 선택 PK·변경순번은 유지합니다.
관계 무결성은 소프트 FK 방식으로 코드에서 일괄 검증하도록 설계했습니다.

B03/B05는 같은 공통 모델의 명명안 두 가지입니다.
공통 데이터를 두 벌 생성하라는 의미는 아닙니다.
엑셀의 축소요약, 축소내역, 소프트관계, 코드검증 시트에서 상세 내용을 확인할 수 있습니다.

이번 자료는 설계 후보입니다. 실제 DB·제품·MAIN·GENOS는 변경하지 않았습니다.
메타 표준·도메인·VECTOR 지원 및 실제 Oracle 성능 검증은 별도입니다.
28개 컬럼 감소가 저장 용량 또는 속도 31.8% 개선을 뜻하지는 않습니다.
전문검색의 페이지 반복 계산 등은 조회 코드에서 별도로 개선해야 합니다.

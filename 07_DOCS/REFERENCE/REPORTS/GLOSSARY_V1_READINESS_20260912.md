# 용어집 v1 — 자동 정리·의미 검토·자료 보완 범위 감사

확인일: 2026-09-12. **데이터를 읽기 전용으로 집계한 현황 감사**다. 모델 성능 비교·정답률 평가·용어집/RAG 변경은 실행하지 않았다. LLM API 호출은 0회다.

## 결론

경제배움e·국세청의 원천 4,747항목을 공백 제거 표제어 기준으로 묶으면 4,572개다.
이 표제어에 현재 확보한 법제처 설명을 함께 대조한 결과, **4,130개(90.33%)는 원문 설명을 기계적으로 정리할 수 있는 대상**, **442개(9.67%)는 의미 비교 검토 대상**이다.
이것은 설명 정리 작업의 분류이며, 동음이의어 분리·별칭 연결·법률 의미 승인을 포함한 용어집 완성률이 아니다.

## 분모와 판정 기준

- 원천: 법제처 목록 437,778항목, 이미 완료된 세 수집 snapshot의 중복 제거 상세 레코드 43,641건, 경제배움e 3,029항목, 국세청 1,718항목.
- 전체: 공백 제거 표제어 362,843개. 괄호·대소문자·구두점은 보존한다.
- 금융·세무 원천 범위: 경제배움e·국세청에 있는 4,572개 표제어. 경제배움e의 사회·과학·공공 등도 포함하므로 모두 금융 전문용어라는 뜻은 아니다.
- 본문 범위: 명시된 `semantic-moleg-links-20260911-v1`의 159개 법률·규정 문서. 기존 해시 검증된 v1 출현 색인의 표기 일치 결과만 재사용했다. 새 질의 검색이나 RAG 효과 평가는 하지 않았다.
- 자동 정리: 확보한 정의/설명 본문이 하나의 텍스트 종류이고 원천 의미 비고와 충돌 후보가 없는 경우. 원문을 복사·보존하는 의미이며, 없는 뜻이나 연결을 승인하지 않는다.
- 의미 검토: 설명·의미 비고가 두 종류 이상인 경우. 같은 의미의 다른 설명, 실제 동음이의어, 적용 범위·시점 차이가 섞여 있다. LLM 또는 사람이 비교할 작업 목록이며 LLM 필수/해결 가능 판정은 아니다.
- 자료 보완: 나머지 정의 본문 미확보 항목. 원천의 짧은 의미 비고·번역 대응·안내 링크는 별도 정보로 남긴다.

법제처 목록 항목이 많다고 정의·의미 관계까지 확보됐다고 보면 안 된다.
사전 설명이 없다는 것은 법률 본문에도 정의가 없다는 뜻이 아니다. 기존 본문 정의 단서 8,520행/4,345표제어 중
사전 설명 보완 대상과 겹치는 표제어가 **1,006개** 있다. 이 부분은 보유 본문에서 먼저 보강할 수 있는 조사 대상이다.
정의가 다중 호·목·참조에 걸치는 경우가 있어 단서 한 줄을 완성 정의로 세지 않았다.

## 원천 타입을 구분해야 하는 이유

상세 응답의 `definition` 필드에 서로 다른 종류의 값이 들어 있었다.

| 원천 구분 | 레코드 수 | 용어집에서의 처리 |
|---|---:|---|
| 법령정의사전 011402 | 34,022 | 출처·시점이 있는 정의 원문 |
| 법령용어사전 011401 | 17 | 사전 설명 원문 |
| 법령한영사전 011403 | 9,349 | 한영 대응 표현; 정의와 분리 |
| 생활용어사전 011405 | 253 | 외부 안내 링크; 정의 확보로 집계하지 않음 |

최초의 필드 단순 집계는 보존했고, 위 원천 코드로 타입을 구분한 이번 `typed` 감사가 최종 결과다.
예를 들어 '국민주택채권'의 금융 설명과 'national housing bond'를 서로 다른 정의로 세면 의미 검토 대상이 부풀려진다.
반대로 법률의 이름에 영문 명칭만 달린 것을 충분한 정의가 확보된 용어로 세어도 안 된다.

## LLM 없이 보존·구성할 수 있는 표현 연결 근거

- 법제처 한영 대응 레코드 9,349건은 원천이 제공한 대응으로 저장할 수 있다.
- 원천의 세미콜론만 구분자로 사용하면 대응쌍 11,919개다. 복수 대응을 담은 레코드는 1,717건이므로, 한 표현을 무조건 하나의 뜻으로 치환하지 않는다.
- 이 대응쌍 중 2,078개는 현재 본문에 없는 원천 표제어에서 본문에 있는 대응 표현으로 이어진다. 출발 표제어는 1,851개다. 대부분 언어 간 대응이며 모든 한국어 일상표현의 연결을 해결한 숫자가 아니다.
- 경제배움e·국세청에는 영문 필드 1,618건, 한자 필드 1,632건이 있다. 원문 필드로 보존 가능하나 오기·축약·복수 뜻까지 자동 검증된 것은 아니다.
- `ETF(상장지수펀드)` 같은 닫힌 약어–한글 표제 형식은 외부 사전에 23건 있다. 나머지 괄호 표제 1,103건은 단순히 같은 규칙으로 모두 동의어 처리하지 않는다.
- 명칭 변경 화살표가 있는 외부 표제는 4건이다. 변경 이력으로 보관하고 현재 동의어로 일괄 승인하지 않는다.
- 현재 선택된 검색 세대에 이미 컴파일된 관계는 7개이며 모두 RELATED다. 동의어가 아니다. 이번 감사에서 발견한 한영 대응쌍은 이 7개와 별개의 미통합 원천 데이터다.

대응쌍은 원천 관계를 보존하는 것이며, 출처를 넘어 의미 ID를 합치거나 법률 적용을 승인하는 것은 아니다.
전체 일반표현의 정답 연결 목록이 없으므로, **일반표현→법률용어 연결의 자동 완성률이나 LLM 해결률은 이번 데이터만으로 수치화하지 않았다.**

## LLM 도움을 어디에 집중할 것인가

금융·세무 표제어의 의미 비교 검토 442개 중 395개는 우리 본문에 등장하고, 47개는 현재 표기 일치가 없다.
첫 도움 범위는 이 395개의 출처별 설명 비교다. 각 원문을 제공하고 같은 의미/다른 의미/범위 차이/근거 부족의 후보를 받되,
출처·시점·원문을 보존하고 사람이 확정하거나 미확인으로 남긴다. 없는 정의·별칭을 자유 생성하도록 하지 않는다.

- '채권': 지식용어 비고 두 종류와 국세청 설명이 있어 의미 구분·연결 검토가 필요하다.
- '투자신탁': 원천 항목은 여러 개지만 현재 확보한 설명 종류는 하나다. 항목 ID 수만으로 사용자에게 여러 뜻이라고 제시하면 안 된다.
- '주기장': 비슷한 설명 사이에 일부 표현 차이가 있다. 텍스트가 다르다는 사실이 동음이의어의 증거는 아니다.
- '국가유산'·'증권': 정의 참조·직접 정의·범위가 다른 설명이 함께 있어 출처·적용 범위 비교가 필요하다.
- '환불': 현재 자료에는 짧은 의미 비고가 있지만 이 기준의 사전 정의 본문은 없다. 의미 비고는 유용한 정보로 그대로 유지한다.

표본은 사전 고정한 해시 순서와 지정 사례로 확인했다. 정답 라벨링 또는 모델 성공률 평가 표본은 아니다.

## v1 완성 순서 제안

1. 원천 타입을 나누어 설명·번역 대응·안내 링크가 섞이지 않게 한다.
2. 4,130개는 단일 원문 설명을 보존하는 표제어 항목으로 구성한다. 유일한 법률 의미라는 주장은 하지 않는다.
3. 명시된 한영·약어 관계를 출처가 있는 별도 연결로 구성하고, 복수 대응은 선택 후보로 유지한다.
4. 본문 출현이 있는 의미 검토 395개를 먼저 비교하고 나머지 47개를 뒤이어 검토한다.
5. 정의 미확보 항목은 기존 본문 정의 단서부터 대조한다. 여전히 근거가 부족한 항목은 자료 보완 대상으로 남긴다.
6. 의미 미확인과 표현 연결 미확인을 별도로 유지한다. RAG 연결은 이번 작업 범위가 아니다.

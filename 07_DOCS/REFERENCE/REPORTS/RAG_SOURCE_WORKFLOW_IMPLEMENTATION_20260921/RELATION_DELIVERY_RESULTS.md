# 직접 연결 소량 전달 — ADR0495

명시적으로 읽은 원문의 직접 참조 연결을 양방향으로 조회한다. 작은 묶음은 연결 대상을 전부 읽어 보여주고, 대상 수·분량·조회/도구 예산을 넘으면 이유와 선택/다음 페이지 동작을 제공한다. 자동 읽기는 다음 관계를 재귀 확장하지 않는다. 모델이 그 원문을 직접 읽으면 다시 직접 연결을 조회한다.

- 격리 후보4개 파일 변경. 동결 후보 계약35개 통과.
- Qwen 실제 자동 읽기7건 모두 모델 입력 전달, 자동 재귀 조회0건.
- 실제 제3호 색인 연결2개 확인. CM003 모델은 조 전체를 읽었으므로 제3호 단독 경로의 실제 모델 성공으로 세지 않는다.

| 문항 | 발견 → 읽기 → 전달 → 게시 조문 | 검토된 답변 | 남은 실패 |
|---|---|---|---|
| CM003 | 58 → 8 → 8 → 2 | 없음 | 필수 시행세칙 미확보, 선택하지 않은 발췌 ID를 초안에서 인용 |
| CM018 | 120 → 0 → 0 → 0 | 없음 | 검색어를 바꾸면서 이전 커서를 재사용, 같은 오류 반복 |
| CM038 | 56 → 9 → 9 → 4 | 없음 | 필요한 법 조문 미확보, 선택하지 않은 발췌 ID를 초안에서 인용 |

저장 기준답 일치0/3, 필수 출처1/5, 출처 관련성1/6. 신규 제품32회·별도 평가6회. 단회 인샘플 후보이며 이전 실행과의 A/B 효과를 추정하지 않는다. MAIN·GENOS 미반영, 채택 거부(Rejected).

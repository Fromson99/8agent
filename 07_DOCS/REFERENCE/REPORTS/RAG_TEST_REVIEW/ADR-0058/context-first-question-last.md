## cm-001 · 오답

**실제 질문**

> 벤처금융 및 전문투자자의 100분의 10 한도는 합산 기준인가?
> (업무 문맥: 신규상장 의무보유 - 코스닥시장 상장규정 제26조)

**당시 기준답변 — 채점용**

> 제26조 제1항 제4호 조문상 "벤처금융 또는 전문투자자가 취득한 주식등 중에서 상장신청일 현재 상장신청인의 자본금을 기준으로 각각 100분의 10에 상당하는 한도까지의 주식등으로 한정한다"로 규정

**실제 답변 전문**

````text
제공된 조문에는 벤처금융과 전문투자자의 100분의 10 한도를 합산 기준인지 개별 기준인지 명확하게 규정하지 않습니다. 제26조 제1항 제4호에서 '벤처금융 또는 전문투자자가 취득한 주식등 중에서 상장신청일 현재 상장신청인의 자본금을 기준으로 각각 100분의 10에 상당하는 한도까지'라고 규정하고 있으나, '각각'의 의미가 개별 한도를 의미하는지 합산 한도를 의미하는지는 세칙이나 유권 해석이 필요합니다. 정확한 답변을 위해서는 코스닥시장 상장규정의 '세칙' 또는 거래소 유권 해석을 확인하시기 바랍니다.
````

**당시 판정 근거**

- 판정 1: **오답** · 유형: 필수 쟁점 누락 (`required_issue_omission`)
- 결론 정확: false / 필수 내용 완전: false / 중대 오류 없음: true

> 기준답변은 조문상 '각각 100분의 10' 즉 개별(각자) 한도임을 제시하는데, 시스템 답변은 조문을 인용하면서도 합산/개별 여부가 불명확하다며 결론을 회피했다. 따라서 요구된 결론을 지지하지 못했다.

누락 사항: '각각' = 벤처금융·전문투자자 각자 별도 한도(합산 아님) 결론 미제시

- 판정 2: **오답** · 유형: other (`other`)
- 결론 정확: false / 필수 내용 완전: false / 중대 오류 없음: true

> 조문 문언('각각 100분의 10')은 인용했으나 그 의미를 판단하지 못하고 해석 유보·회피로 답했다. 기준답변이 요구하는 '각각(개별) 기준' 결론을 명확히 지지하지 않았다.

누락 사항: '각각'은 벤처금융·전문투자자 개별 한도임을 명시 / 합산 기준이 아니라는 결론 제시

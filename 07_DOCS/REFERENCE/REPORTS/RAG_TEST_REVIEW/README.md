# 과거 RAG 테스트 · 실제 답변과 판정 기록

작성일: 2026-09-07 · 범위: ADR-0056, ADR-0058, ADR-0188

**Word 버전:** [요약 보고서](WORD/00_요약보고서.docx) · [모델별 전체 기록](WORD/01_모델별_전체기록.docx) · [프롬프트별 전체 기록](WORD/02_프롬프트별_전체기록.docx) · [RAG 기준선 전체 기록](WORD/03_RAG기준선_전체기록.docx) · [전체 ZIP](WORD/RAG_테스트_보고서_전체.zip)

요약 보고서에는 성능 그래프 5개와 설명 그림 2개가 포함되어 있습니다.

세 실험의 **1,128개 답변 전체**를 모델 또는 프롬프트 조건별로 정리했습니다. 각 상세 문서에는 실제 질문, 당시 기준답변, 답변 전문, 정오 판정, 판정 이유, 누락 사항, 원본 링크가 있습니다. 오답을 먼저 배치하고 정답도 모두 수록했습니다.

| [ADR-0058](ADR-0058/README.md) | 동일 Haiku의 프롬프트 11종 비교 | 561 | 프롬프트별 11개 |

## 읽는 순서

1. 실험 요약에서 모델·조건별 정답 수와 오답 수를 확인합니다.
2. 조건별 문서의 **오답 바로가기**로 실패 사례를 펼칩니다.
3. 실제 답변을 기준답변과 비교한 뒤 **당시 판정 근거**와 누락 사항을 읽습니다.
4. 같은 질문의 다른 조건을 보려면 실험 요약의 **질문별 비교표**를 이용합니다.

처음 볼 사례: [Qwen의 cm-002 — 기준일 일부 누락](ADR-0056/baseline.md#cm-002), [Haiku 기준 프롬프트](ADR-0058/baseline.md), [실제 RAG의 cm-011 — 근거 선택 단계 탈락](ADR-0188/baseline.md#cm-011).

## 판정을 읽을 때 구분할 것

- **결론 정확 / 필수 내용 완전 / 중대 오류 없음**은 서로 다른 채점 항목입니다. 결론이 맞아도 필수 내용 누락으로 최종 오답일 수 있습니다.
- ADR-0058은 조건부 다수결입니다. 각 투표의 이유를 모두 표시하며, 정답·오답 의견이 갈린 사례를 명시합니다.
- ADR-0056·0058은 정답 조문을 직접 제공했으므로 답변 생성 조건의 비교입니다. ADR-0188은 실제 검색·선택을 포함합니다. 세 실험의 정확도를 같은 조건의 순위처럼 비교하면 안 됩니다.
- “틀린 이유”는 당시 채점 모델이 남긴 판정 근거입니다. 새로 재채점하거나 법률상 정답을 확정한 문서가 아닙니다. 원문과 기준답변은 당시 버전 그대로이며, 모든 실험은 인샘플입니다.
- 빈 문자열이나 문장부호뿐인 답변도 원형 그대로 표시했습니다. 프롬프트·중간 호출·조문 전문은 각 사례의 원본 링크에서 확인할 수 있습니다.

## 원본과 문서 범위

기존 실험을 재실행하지 않고 저장된 완료 결과를 읽어 정리했습니다. 모델명과 답변은 저장값을 유지했습니다. ADR-0188은 완료 `run-006`을 사용합니다. 새 답변 생성·재채점·운영 변경은 없습니다.

원본 파일 SHA-256과 수록 건수는 [수록 내역](coverage.json)에 기록했습니다. 상세 문서의 답변 전문은 원시 JSON의 `answer` 필드와 일치하도록 확인했습니다.

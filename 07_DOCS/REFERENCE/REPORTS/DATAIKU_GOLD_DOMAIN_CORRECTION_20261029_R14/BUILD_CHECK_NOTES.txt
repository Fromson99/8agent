R14 작성 검증 기록

첫 실행에서 공통 컬럼 전체 설명까지 동일해야 한다는 검사 조건이 실패했다.
기존 벡터 표의 설명은 같은 ID의 게시·참조·선택 역할별로 달라 이 차이는 보존했다.
대조 과정에서 DOC_ID·SRC_UNIT_ID의 한글 Y 및 숫자 CHAN_NO의 한글 N 표기를 발견했다.
실제 데이터와 생성 규칙에 맞춰 각각 N / 해당 없음으로 정정했다.
공통 컬럼 검사 범위는 논리명·도메인·구성 단어·물리 타입·한글 표시로 바로잡았다.
최종 결과는 VALIDATION.json으로 확인한다. 초기 실패를 최종 통과로 소급하지 않는다.

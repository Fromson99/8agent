Oracle Agent 기록 저장 축소안 R2 — 2026-10-30

사용자 요청: 기존 기록을 Oracle Agent에 보존하고 온톨로지의 원기록으로 사용하되,
신규 테이블·컬럼 수를 줄인다. 이번 결과는 검토 가능한 설계안이며 구현/이관 완료가 아니다.

1. 축소 결과
  R1: 신규 7테이블·85컬럼
  R2: 신규 3테이블·21컬럼

    LGL_AGT_REC_A  세션·판단·사건·호출·근거·연결 공통 기록 8컬럼
    LGL_AGT_BODY_A 큰 원기록·모델 입출력 무손실 본문 조각 4컬럼
  기존 LGL_EXEC_ST_A 1테이블·5컬럼 재사용. 기존 컬럼 추가·변경 제안 없음.
  총 Agent 사용 구조: 신규 포함 4테이블·26컬럼.
  기존 Gold 13테이블·60컬럼 유지. Gold 신규·ALTER DDL 0.
  물리명·타입은 모두 등록 전 후보이며 실제 DB에서 생성하지 않았다.

2. 줄이는 방법
  검색/정렬/CAS에 필요한 키·종류·순번만 컬럼에 둔다.
  사유·판단·원 식별값·조건·입출력·해시·권한·판본·실패는 JSON 본문에 그대로 보존한다.
  공통 기록의 판본 1 이상은 불변 이력, 판본 0은 재생성 가능한 현재/검색 투영이다.
  관계 정방향/역방향, 호출 상태 등은 종류별 조회 행을 둔다. 전체 본문 스캔을 기본으로 하지 않는다.
  삭제·요약으로 컬럼을 줄인 것이 아니다. 표 수 감소가 구현 작업량·SQL 비용 감소를 보장하지 않는다.

3. 실제 변경 범위
  SQLite 연결문 하나 교체로 끝나지 않는다.
  원장·v3/v4 대화·부모자식 workflow·예산·발행·출처·진행·온톨로지 수집을 같은 저장소로 연결해야 한다.
  현재 MAIN124는 shortcut capture와 workflow가 켜져 있어 v4 경로도 범위에 포함했다.
  18개 정의 파일군의 141표 정의·832컬럼 항목을 정적 추출했다. 실제 운영 DB 개수/행수가 아니다.
  34개 직접 경계 파일을 변경 지도에 표시했다. 전체 영향 파일 수의 확정치는 아니다.

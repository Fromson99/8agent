테이블별 컬럼 정의 R17 — 2026-10-30

R16 대신 법률에이전트_B03_테이블별_컬럼정의_R17.xlsx를 사용한다.
01~13은 각 테이블의 컬럼 전용 시트이다. 파일을 열면 첫 테이블부터 보인다.
첫4열: 논리명 / 물리명 / PK / NULL 허용.
PK Y는 기본키, NULL 허용 N은 필수값이며 Y는 빈 값 허용이다.
PK 순서·타입/길이·기본값·컬럼 정의는 오른쪽에 있다.
1~3행은 안내,5행은 제목,6행부터 컬럼 값이다. 데이터 영역에는 병합·수식이 없다.
00_테이블목록에서 테이블명과 정의를 보고 해당 시트로 바로 이동할 수 있다.
인덱스·파티션은 마지막 참고 시트2개에 보존했다.

13테이블60컬럼 값·PK/NULL/기본값과 인덱스/파티션이 R16과 동일한지 재열기 검증했다.
명세해시값 물리명은 DTLS_HASH_VALU이다.
연결된 로컬 Oracle A8_GR12_CM1208의 해당4컬럼도 실제 변경했고 활성 매핑·실제조회 확인을 마쳤다.
엑셀은 신청 타입/크기이며 로컬 Oracle의 기존 실제 타입/크기는 보존했으므로 길이가 같은 의미는 아니다.
현장 Oracle·신청 시스템 입력은 수행하지 않았다.

11월 7일
[완료] 로컬 MAIN171에 큰 자료의 반복 조회를 줄이는 수정을 반영했다. 축소 규모 점검의 한도 초과 읽기는 7곳에서 0곳이 됐고 Oracle SQL 3,694회에서 오류가 없었다. 10,202개 원문 범위 검사는 기존 1/6에서 6/6으로 늘었다. MAIN172~175에는 연결 원문 읽기, 문서 대사, 벡터 구조 범위와 게시 온톨로지 경로가 이어졌다. [1, 2, 3]
[완료] 현장 276.1초 요청에서 Agent 기록이 SQL 시간의 70%를 차지해 원장 본문 쓰기·재읽기를 줄였다. 선택 MAIN176의 로컬 Oracle·모의 모델 한 질문에서 왕복 1,386→896회, 본문 쓰기 256→11회였다. 회귀는 1,065통과·기존 실패 204개 동일, 새 실패 0이었다. MAIN176 전달본 7첨부를 발송했고 현장 개선 폭은 미확인이다. [4]
[진행] 새 주제로 전환하는 요청과 예전 질문을 다시 가리키는 요청을 구분하는 멀티턴 후보를 시험했다. r7 관련 회귀 48파일에서 기존 실패 127개가 같았고, 일부 실제 후속은 원문 재조사 대신 이전 답변 제시를 선택했다. [5]

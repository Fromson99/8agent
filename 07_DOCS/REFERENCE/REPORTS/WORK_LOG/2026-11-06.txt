11월 6일

[검증] MAIN161의 외규 R5는 서로 다른 질문 30개 모두 등록 기대내용과 일치했다. 화면 10행은 미실행이고 의무를 가능으로 표현한 부수 문장 오류가 남았다. 별도 financial CM 51문항은 일치 18, 부분 5, 실패 28이었다. 모든 요청이 HTTP 200이었지만 필수 조문 98개 중 확보 48개, 답변 인용 36개였다. 미확보와 답변 전송 성공을 별개로 기록했다. [3, 4]
[현장] MAIN170 설치 자료와 검증 기록을 준비했다. 현장 DB에서의 대규모 조회 성능과 문항별 답변은 추가 확인 대상이다. [2, 5]

11월 7일 00시 이후
[실패] 문서 대사 ADR1443은 입력 한도를 개선한 뒤 32묶음 중 12묶음까지 끝냈다. 좁힌 검색 범위를 재검사할 때 전체 외규 목록과 비교해 HTTP 500으로 종료했다. 모델 429호출, 결과 불명 0이었다. [6]
[진행] 00시 54분에 MAIN170과 Oracle 조회 후보 r10의 속도 비교가 기록됐다. MAIN171은 이 일지의 마감 후인 01시 19분에 선택됐다. [5, 7]

3. 큰 문서의 Oracle 조회 한도를 확인한다. MAIN170과 r10의 같은 질문에서 반환 행 수와 결과를 대조하고, 한도 초과와 문서별 반복 조회가 모두 해소됐는지 판정한다. [5, 7]

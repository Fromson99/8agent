# 표현 학습·탐색 재사용 첫 구현 자체 검토

검토일: 2026-09-16. `design-reality-review` 스킬 기준의 **작성 에이전트 자체 검토**다. 별도 에이전트 독립 검토·금융/법률 전문가 인증·GENOS 현장 검증이 아니다.

검토 대상은 [구현·운영 계약](../OPERATIONS/GLOSSARY_LEARNING.md), `navigation_learning.py`, `learning_store.py`, `navigation_agent.py`, `navigation_loop.py`, `app.py`, `control.py`, glossary learn CLI 및 연결 테스트다. 최종 파일 SHA-256과 실행 결과는 `09_ARTIFACTS/AUDITS/20260916-glossary-learning-v1/verification.json`에 고정한다.

## 판정

**구현: 제한된 범위에서 조건부 타당.** 실제 저장 실행에서 후보를 수집하고, CLI 검토·발행을 거쳐 `/ask`가 용어 단서와 검토한 절차를 사용하며 원문을 새로 읽는 연결을 확인했다. 기본 설정은 비활성이고 선택된 운영 릴리스는 바뀌지 않았다.

**예상 효과 수치: 판단 유보.** 정확도·속도·총비용 개선을 측정하지 않았다. 계약 테스트 통과를 그 성능의 증거로 바꾸지 않는다. 문구 기반 적용 조건과 사람 검토의 정확성은 별도 평가가 필요하다.

## 정상·반례 확인

모의 문서에서 ‘은행 문 여는 날’ 입력을 수집 → 기존 `fixture:day` ID 승인 → 번들 발행 → 같은 API에서 용어 시작점 확인 → 절차 제출·별도 승인·새 번들 발행 → 정의/목록 조회 → 새 원문 READ → REFERENCES/JUDGE → 근거 있는 모의 답변 반환을 검사했다. 외부 모델은 호출하지 않았다.

해시·세대 변경, 루트 탈출, 미등록 ID, 문서 범위 불일치, 상충하는 표현, 복수 절차 일치, 근거·참조 조회 생략, 예산 소진, 동시 수집·중복 승인, 기존 번들 덮어쓰기, 구버전 실행 수집을 반례로 검사했다. 권한 필터는 사용자 인증이 아니며 검토자 이름 입력은 서명 검증이 아니다.

RP 연결 문서 등록 순서 오류 수정 보존본

ADR-0930/fixed rev-007에서 이미 검증한 law_navigation.py 변경만 추출했다.
원문 읽기 대상의 권한·문서·예산 검사를 먼저 통과시킨 뒤, 처음 발견한 연결 문서를 조사 목록에 등록하여 LAW_SELECTION_DECISION의 KeyError를 막는다. 원문을 읽었거나 최종 근거로 채택했다고 대신 기록하지 않는다.

RP_ONLY.patch는 MAIN89 원본에 적용하면 기존 검증 후보의 해당 파일과 바이트가 같고, 역적용하면 원본으로 돌아감을 임시 디렉터리에서 확인했다.
PF 입력 압축 관련 3개 파일은 포함하지 않았다. 기존 혼합 후보·실험 결과는 수정하지 않았다.

이는 기존 수정의 독립 보관물이다. 별도의 서빙 후보 검증·엔진 해시 갱신·MAIN 승격은 아직 하지 않았다. 기존 ADR의 RP 검사 5개와 혼합 후보의 실제 RP 실행 결과를 계보로 연결하며, 이 보관물을 독립 서빙 후보로 시험했다고 주장하지 않는다.
이번 작업은 새 모델 호출 없이 기존 실행 기록을 진단하고 수정본을 보존했다. 작업 코드와 MAIN89 및 GENOS는 변경하지 않았다.

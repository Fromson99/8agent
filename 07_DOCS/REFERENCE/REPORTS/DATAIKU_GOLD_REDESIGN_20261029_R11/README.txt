후속 사용자 요청으로 13표·60컬럼의 R12 축소안을 작성했습니다.

아래 R11 16표·88컬럼 설명은 비교 이력으로 보존합니다.

최종안: 기존 10개 + 벡터 3개 + 전문검색 3개 = 16개 테이블, 88개 컬럼.
R10의 기존 49개 컬럼 정의/타입/PK/필수 여부는 유지합니다.
기존 표에 일반 컬럼 3개를 더하고 벡터 17개, 전문검색 19개 컬럼을 추가합니다.

B03/B05는 공통 설계의 명명안 두 가지입니다. 데이터를 두 벌 만들라는 뜻이 아닙니다.
각 엑셀은 요약/목록, 테이블별 16개 정의, 인덱스, 소프트FK, 코드 검증,
변경 지도, 테이블 Description의 23개 시트로 구성했습니다.

주요 결정
- PK와 NOT NULL 유지. 물리 FK/CHECK/PK 외 UNIQUE/함수 인덱스 없음.
- 일반 인덱스와 연결 ID 유지. 게시 전에 관계·판본·해시를 일괄 검증.
- 벡터: VCTR_POST / VCTR_ITEM / VCTR_HEAD.
- 전문검색: FTS_UNIT / FTS_POST / FTS_STAT.
- 본문은 선택한 페이지/READ에서 조회. 전체 JSON 복원·반복 계산을 줄이는 코드 변경 포함.
- A단계 기본+벡터 13개 표, B단계 전문검색 3개 표. 최종안은 16개 표.
- 벡터는 기존 Oracle native VECTOR 구조. 별도 벡터 DB 제품 도입 전제 없음.
- ANN은 기본안에 포함하지 않으며 원문 단위별 정확 검색 계약을 유지.

상태
문서와 DDL 검토 템플릿만 작성했습니다. DB 생성/적재, 제품/MAIN/GENOS 반영은 없습니다.
기존 개발계 Silver는 유지합니다. 실제 Oracle 성능과 신규 표준용어 승인은 미확인입니다.
DDL의 {{APPROVED_GOLD_OWNER}}는 실제 승인 owner로 확정할 값입니다.
PREVIEW_*.png는 엑셀 셀 내용 기반 미리보기이며 Excel 자체 렌더링 결과가 아닙니다.
VALIDATION.json은 정적 일관성 검사 결과이며 실제 Oracle 통과 증명이 아닙니다.
자체 검토 내역은 SELF_REVIEW.md, 근거 경로/해시는 SOURCES.json에 있습니다.

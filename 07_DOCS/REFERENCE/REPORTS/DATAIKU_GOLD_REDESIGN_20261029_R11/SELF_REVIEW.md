# R11 자체 검토

독립 에이전트 또는 DBA 검토가 아니다. 설계·생성 산출물의 일관성과 실제 코드 연결 가능성을 자체 확인했다. 데이터베이스·제품 코드는 실행하거나 수정하지 않았다.

| 확인 항목 | 판정·조치 |
|---|---|
| 기존 등록본 선택 | R10 B03/B05를 기준으로 사용. 두 원본의 명명 부분을 제외한 내용 동일 확인. 구형 R3 모델은 현행 테이블 원천 대응에만 사용 |
| 벡터 구현 기준 | R3 전달본 payload의 2표/6컬럼을 사용. 작업 루트의 이전 벡터 구현과 구분 |
| 표·열·관계 | 16표/88컬럼, 기존49 보존, 직접 논리 관계16개의 복합 부모 PK·타입 일치 확인 |
| 물리 제약 | DDL에 PK16·일반 인덱스16. 물리 FK·업무 CHECK·PK 외 UNIQUE·함수 인덱스 없음. NOT NULL은 유지 |
| 원천 누락 | 벡터 문서/원문/구조/블록/span/세 해시·profile 보존. 새 조회 ID로 바뀌는 벡터 manifest/segment ID 재결속을 설계에 명시 |
| FTS 의미 변경 위험 | ACL 이후 df로 변경하지 않음. global phrase df·BM25·동점·total·cursor 보존, 전용 투영의 신규 해시와 과거 generic row ID 구분 |
| 원문 단위별 벡터 순위 | 그룹별 MIN 거리 후 순위 유지. ANN 청크 top-k가 동등하다는 주장 제외 |
| 동시성 공백 | HEAD PK만으로 전체 적재를 보호하지 않음. 공유 원문 판본까지 포함하는 writer 제어키·fencing·검증 전 쓰기 중지·봉인·CAS 요구를 구체화 |
| 실제 코드 연결 | physical_mapping과 R3 schema 검사가 현행 물리 FK/CHECK/함수 인덱스를 요구하는 사실을 반영. 설정 변경만으로 전환할 수 있다는 주장 제외 |
| 문자 길이 | R10의 1000/2250 BYTE를 보존하되 현행 어댑터512 상한·원천CLOB 초과 가능성을 표시. 조용한 절단 금지 |
| 표준용어 작성 | 신규 컬럼의 수식어/도메인 분리. 필드명 도메인을 '명'으로 정정. 신규 약어는 미승인 후보로 표시 |
| 가독성 | 셀 내용 기반 목록/벡터 시트 PNG를 열어 한글·컬럼·내용 확인. 실제 Excel 인쇄/자동 줄바꿈은 미검증 |
| 성능 주장 | 과거 로컬 재생·journal SQL 감소와 이번 Oracle 설계를 분리. 신규 속도 향상률·SLA·처리량 인증 없음 |

남는 구현 전제는 Gold owner/공유 권한·VECTOR/인덱스 지원, 도메인 승인, 원천 최대 길이, writer 제어 상태의 실제 저장 계약, Gold/Agent 트랜잭션, 전용 FTS 어댑터와 실제 Oracle 계획·성능이다. 이들은 설계 완료를 제품 반영 완료로 확대하지 않기 위해 명시한 범위다.

생성 스크립트와 두 XLSX·MODEL·DDL의 대조는 `VALIDATION.json`에 남겼다. 각 상세 시트의 88개 컬럼, 기존49개 정의·타입·PK·필수 여부, B03/B05 동등성, ZIP/XML 파일 열기, 수식 없음, DDL 열 타입/순서, 관계 부모 복합키를 검사했다. 자체 검사 통과는 Oracle 컴파일이나 현장 적합성 인증을 뜻하지 않는다.

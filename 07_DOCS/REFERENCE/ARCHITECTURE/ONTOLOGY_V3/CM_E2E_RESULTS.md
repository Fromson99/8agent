# CM 원문 중심 지식 저장·재사용 실행 결과

[전체 목차](../ONTOLOGY_V3.md) · [원문 중심 저장 기준](SOURCE_ANCHORED_STORAGE.md) · [실험 정본](../../../../04_EXPERIMENTS/ADR/ADR-0987-cm-source-ontology-native-e2e/README.md)

2026-10-22. **질문으로 발견한 정보를 원문에 연결해 저장하고, 다른 질문에도 재사용하는 경로는 실행됐다. 탐색량과 응답시간은 줄었지만, 핵심 누락을 해결해 정답에 도달하는 효과는 확인하지 못했다.**

## 실제로 저장하고 실행한 것

1. 과거 실제 CM 실패 로그에서 CM051·008을 골랐다. 실패 기록을 성공으로 변경하지 않았다.
2. ‘정상 조사로 근거를 찾았다고 가정’하고, 현재 선택한 원문 세대에서 수치·조건·연결 위치를 직접 확인해 보완 후보를 만들었다. 자동 LLM 추출이 아니라 원문 기반 수작업 큐레이션이다.
3. 질문별 답변 묶음 대신 **원문4개에 연결한 개념·검토 지식**을 기존 `ShortcutRepository`와 package import 경로에 저장하고 `legal_wiki_compiler.rebuild`로 문서 보기를 만들었다.
4. 기존 `legal_knowledge.Service`로 원문 METHOD4개, 추상 METHOD2개, FIELD2개, APPLICATION1개를 저장·연구용 발행했다. 두 조건의 AND 식은 TRUE/FALSE/UNKNOWN 계약으로 실행했다.
5. 같은 질문2개와 관련 질문2개를 기존 네이티브 `/v1/rag/ask`로 각각 지식 사용/미사용 조건에서 실제 실행했다. 사전 동결된 후보 코드·모델·공개 원문 범위는 같고, 답변 캐시는 사용하지 않았다.

저장 단위의 정체성은 **문서 판본 + 원문 위치 + 개념**이다. 질문은 Agent 레이어의 발견 이력이다. 질문 검색용 단어와 실행 허용 질문 해시는 보조 색인·권한 확인에 쓰이며 Gold 지식의 일차 키가 아니다.

## 어디까지 연결됐고 어디서 빠졌는가

지식 사용4요청 모두 실제 모델 입력에 `legal_review_guidance`가 들어갔고, 원문 숏컷 실행 이벤트가 기록됐다. 확보한 근거의 원문 span·해시·권한 대조도 통과했다. 저장만 해 놓고 조회하지 않은 상태는 아니었다.

그러나 **조회→원문 읽기→모델에 전달→판단에 사용→최종 답변**은 같은 사건이 아니다.

| 확인 지점 | 관측 |
|---|---|
| CM051 시행규칙의 CB 환산 원문 | 지식 미사용은 해당 block 미확보, 사용은 확보. 그러나 지식 사용 모델 입력에서 해당 block 전체 문자열은 확인되지 않았고 답변에서도 환산 누락 |
| CM008 세칙의3년·2년 사유 | 지식 미사용은 해당 block 미확보, 사용은 확보. 구조화 검토 값은 입력에 들어갔지만 해당 원문 block 전체 문자열은 확인되지 않았고 답변에도 미반영 |
| CM007 잔여 인수 포함 | 양쪽 모두 해당 block 확보. 지식 사용 입력에 해당 block 전체 문자열이 확인되지 않았고 답변에서도 누락 |
| CM010 보유제외 | 근거는 확보·제시했지만 적용 결론 대신 자료 부족 상태로 종료 |

전체 block 문자열 검사는 **부분 원문도 전혀 전달하지 않았다는 증명은 아니다.** 기록으로 확인한 원문 확보·전달 범위와 모델의 실제 사용을 분리한다. LLM 내부 판단 원인을 이 로그만으로 확정하지 않는다.

## 다음 구현에서 필요한 연결

기존 [구현 단위](../../REPORTS/ONTOLOGY_V3_CONTROL_REVIEW_20261022/implementation/MODULES.md)의 책임으로 이어간다. 아래는 확인된 미완성 지점이며 이번 실험에서 구현 완료한 기능이 아니다.

| 담당 | 필요한 실행 계약 |
|---|---|
| M07 Knowledge Query Service | 질문 검색뿐 아니라 `source_anchor → concept/check/evidence_route` 조회. 일반 검색으로 새 원문을 읽은 뒤에도 실행 |
| M02 Evidence Route Index | 검토 항목이 가리킨 연결 원문의 현재 판본·권한을 확인하고 필요한 span을 전달 |
| M08 Knowledge Application Service | 검토 항목별 실제 입력 근거, 적용/비적용 이유, 해결/미확인 상태, 최종 주장 참조를 남김 |
| M11 Research Execution Policy | 확보한 근거로 해결한 항목은 재조사하지 않음. 미해결 항목은 추가 근거·사용자 사실·해석 불확실성을 구분하고 기존 예산 내에서 종료 |

‘검토 항목이 있으므로 전부 무조건 조사’하는 규칙을 추가하려는 것이 아니다. 현재 질문에서 적용하지 않은 항목도 이유를 기록할 수 있어야 한다. 의미가 불확실하다는 이유만으로 확보 원문 전달을 막거나 같은 조사를 반복하지 않는다.

## 검증 범위와 배포 상태

- Qwen3.8/Parasail FP8 실제50호출. 공개 원문44문서 범위. 사용량668,482토큰, 기록된 비용$0.18605. 독립 법률 전문가 채점은 수행하지 않았다.
- 원문 단위 저장·발행과7가지 계약 검사, AND 진리표4행을 확인했다. 실제 사건 사실을 자동 추출해 식에 대입하는 단계까지 검증한 것은 아니다.
- CM4문항은 이미 노출된 사례다. 관련 질문2개는 새 지식을 추가하지 않은 재사용 검사이며, 미사용 holdout·완전히 새로운 문제의 일반화 검사가 아니다.
- 로컬 연구 SQLite·후보 API 실행이다. Agent/Gold 저장 책임은 설계에 반영했으며, Dataiku Oracle 적재·GENOS 실행은 하지 않았다.
- MAIN99에서 동결한 후보로 실행했다. 종료 확인 시 별도 ADR0985가 MAIN100을 활성화한 것이 관측됐다. 이번 후보를 MAIN100에 통합·승격한 것은 아니다.
- 이전 [단일 호출 파일럿 ADR0984](../../../../04_EXPERIMENTS/ADR/ADR-0984-cm-knowledge-reuse-pilot/README.md)와 [모델 호출 전 해시 차단 ADR0986](../../../../04_EXPERIMENTS/ADR/ADR-0986-cm-experience-ontology-e2e/README.md)을 보존한다. 이들 결과를 네이티브 E2E 성공으로 합산하지 않는다.

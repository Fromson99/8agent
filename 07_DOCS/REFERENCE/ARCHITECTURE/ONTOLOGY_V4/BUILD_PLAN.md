## 2026-10-28 최신 적용 순서

[실제 적용 계획](APPLICATION_READINESS_20261028.md)의 P1~P6을 현재 실행 순서로 삼는다. 고정 레시피 생성·승인·원문 도착 시 소비 기반과 실제 Streamlit 승인 화면은 있으며, 화면을 더 그리는 것보다 **승인 모델/매핑 확인 → 영속 이관 원장·Dataiku 적재·검증·활성 전환 → GENOS 허용 조회 경로 → 다른 질문의 실제 재사용 확인**을 먼저 완성한다. 씨앗 지식 한 건과 Dataiku 인증·이벤트·작업 폴더 연결은 함께 준비한다.

첫 적용 뒤에 안정 개념 ID를 통한 여러 질문의 반복 축적, 개별 판단 재지시·턴 계약, 스키마 확장, 용어·별칭 랜딩, 실제 조건 변경 계산을 확장한다. 새 대시보드의 골드 요청 저장을 적재 완료로 세지 않는다. 기존 publish는 즉시 활성화하므로 운영 Gold에서는 적재·검증·전환을 분리하고 모든 쓰기 경로에 같은 게이트를 적용해야 한다.

아래 2026-10-24 단계0~8·`남은 결정`은 당시 설계 결정 기록이다. 설계 방향이 확정됐다는 뜻과 현장 계정/권한·승인 모델·실제 DB 매핑이 확인됐다는 뜻을 구분한다. 이번 문서 반영은 제품 구현·실험·MAIN 선택·배포를 수행하지 않는다.

## 먼저 할 것: 핵심 MVP (2026-10-24)

2026-10-26 후속 개발의 입력·응답 기준은 [행동별 최소 입력·응답 계약](ACTION_CHOICE_CONTRACT_20261026.md)이다. ADR1066 후보의 743파일 rev-002에서 구현·동일 동결본 합성 계약/API 80개 검사를 완료했으며 실제 확인 범위는 [구현 기록](MVP_EXECUTION_REPAIR_STATUS_20261026.md)을 따른다. 이 계약은 아래 멀티턴·S3·골드 단계의 구현 완료나 MAIN 반영을 뜻하지 않는다. 과거 입력 문자 상한과 실험 실행 지시를 새 개발에 다시 적용하지 않는다.

아래 단계 0~8보다 [핵심 MVP](MVP.md)를 먼저 한다. 온톨로지의 장점은 **컴파일**이다. MVP-1은 도착한 조문의 연결을 조립한 묶음으로 주면 에이전트가 더 잘 찾는지, MVP-2는 온톨로지가 없는 곳을 실행 후 온톨로지화 제안으로 채울 수 있는지 실험한다. MVP에 필요한 구현은 기준선 복구, 씨앗 묶음 JSON, 컴파일러, 도착 시 전달, 제안 단계다. 멀티턴 재지시·S3·Streamlit·SQL 적재는 MVP 결과를 본 뒤 진행한다. MVP 문항은 [씨앗 조문](SEED_ARTICLES_20261024.json)으로 구성한다.

컴파일은 맞는 조문에 도착한 뒤에 효과가 있으므로 [랜딩](LANDING.md)을 함께 다룬다. 용어집은 언제나 바꿔 넣는 별도 도구이고, 착지 예시(비슷한 과거 사례가 인용한 조문)는 첫 조문 후보를 앞으로 올린다. 첫 할 일은 모델 호출 없이 착지 예시 색인을 만들고 기준점을 재는 것이다.

순서의 이유:
- 단계 1·2는 온톨로지가 비어 있어도 바로 쓸모가 있다. 초기 "하나씩 읽는" 구간을 사용자가 재지시로 보완한다.
- 단계 3~5는 골드에 새 표·컬럼이 생기기를 기다리는 시간이 있다. 그동안 작업은 S3 JSON에서 계속할 수 있다.
- 재지시 "그거 읽어"는 "이 연결은 필요했다"는 가장 확실한 신호다. 단계 3·4의 재료가 된다.
- 스키마를 실제 판단 기록을 본 뒤 만들기 때문에 한 번에 다 만들 필요가 없다.

## 샘플 선정 기준

- 13문항이 위임, 준용, 예외·단서, 정의 사용, 별표 기준, 수치 한도를 각각 2개 이상 포함한다.
- 하나는 연결이 필요 없는 단순 질문으로 넣어 쓸데없는 탐색 확대를 본다.
- CM 문항은 기준답변과 대상 조문이 있어 확인이 쉽다. 예: cm-001 "벤처금융 및 전문투자자의 100분의 10 한도는 합산 기준인가? (업무 문맥: 신규상장 의무보유 - 코스닥시장 상장규정 제26조)" — 기준답변은 제26조 제1항 제4호의 "각각 100분의 10에 상당하는 한도까지의 주식등으로 한정한다"를 근거로 든다.
- risk_cm은 외규로 답할 수 있는 문항(외규만 가능 3개, 일부 가능 18개)에서 고른다. 내규가 필요한 80문항은 회사 내규 원문이 GENOS에 있으므로 로컬 샘플에서 제외하고 GENOS 단계에서 쓴다.
- 기준답변·판정은 평가 쪽에서만 쓴다. 샘플을 고른 기록은 이미 알려진 질문이므로 미사용 평가 세트로 부르지 않는다.

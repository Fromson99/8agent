조사 감시자 구현·실험 결과 — 2026-10-28

결론
최신 MAIN112 기반으로 감시·집행 MVP를 격리 구현했다. 실제 감시 모델은 2회만 호출했다.
7번에서 감시자도 무관한 같은 대상을 다시 선택했다. 이 결과를 실패로 보존하고, 추가 모델 호출 없이 실행 대상 동일성 검사를 보완했다.
최종 기술31검사는 통과했다. 실제 CM 질문의 원문 조사부터 최종 답변까지는 이번에 실행하지 못했으며 개선을 인증하지 않는다. 선택 MAIN112는 그대로다.

구현한 범위
- 현재 질문·쟁점별 진행 의견·기존 판단·원문·실행 이력·법령별 후보 메타데이터를 감시 입력으로 연결.
- 무진전·답변 가능 의견과 계속 조사 간 불일치·종료 제안을 감지.
- CONTINUE_TARGETED / REDIRECT / ASSESS_NOW / STOP_UNRESOLVED를 기존 조사 실행기에 연결.
- 실제 도구 실행 직전, 현재 입력과 승인된 행동을 다시 확인. 감시가 보류한 행동은 실행하지 않음.
- 감시 호출은 기존 조사 예산에서 최대2회. 전송/스키마 재시도0. 최종화 예약량 유지.
- 재개 시 감시 상태·카운터·입력/행동 결속 보존. 미확인 감시 응답을 새 시도로 반복하지 않음.
- 감시 종료 뒤 최종 검토에서 확인한 별도의 유효한 원문 부족은 제한된 독립 조회로 연결.
- 빈 근거 상태에서 ANSWERABLE의 불가능한 배열 스키마 제거.
- claim_evidence_refs의 참조 사전 키도 값과 동일하게 고정 번호 매핑.
- 후속 수리: 방향 전환은 실제 도구·대상·검색·구조 범위로 비교. 이유나 충분성 의견만 바꿔 같은 행동을 전환으로 통과시키지 않음.

실제 모델 관측
사용 모델: Qwen3.8 / qwen/qwen3.8-27b / OpenRouter Parasail FP8 / reasoning none / fallback 없음 / 출력상한 없음.
입력: 과거 ADR1161의 CM007·009 각각8번째 실제 입력과 실제 다음 행동 제안. 원문/후보는 저장 당시 값. 새 MAIN112 전체 요청 입력이라고 부르지 않는다.
실행: 각1회, 합계2회. 재시도0, 평가모델0, 후속 도구 실행0.
제공자 기록: 16.662초, 입력55,605토큰/출력844토큰, $0.015202. 요청 전체 응답시간이나 법률 품질 측정값이 아니다.

CM007
감시자는 '계좌의 통합 등 조항은 질문과 무관하다'고 설명하면서 실제로는 그 조항의 같은 target을 다시 READ로 골랐다.
유가증권시장 쪽 필요한 범위를 확보하지 않은 상태에서 코스닥 원문으로 충분하다는 의견도 반복했다.
REDIRECT라는 상태값과 자연어 설명만 믿을 수 없다는 실제 실패다.
처음 구현한 비교는 전체 decision에 reason이 포함돼 문구 변경을 방향 전환으로 인정할 수 있었다. 이 기술 결함을 후속 ADR1167에서 수정했다.
최종 수리본은 저장된007의 같은 대상 재선택을 거부한다. 올바른 유가 원문을 찾았다는 의미는 아니다.

CM009
감시자는 유가증권시장 상장규정 제13조 원문 읽기로 전환을 제안했다. 그 후보는 해당 저장 화면에 실제로 존재했다.
실제 조회·최종 판단은 실행하지 않았으므로 그 전환이 필요했는지, 유효한 근거와 답변을 만들었는지는 미확인이다.

전체 CM3 미실행 사유
전체 데이터 로딩 전에 호스트 스왑이 약3.5GiB로 관측되어 사전 동결한512MiB 보호 기준에 걸렸다. 당시 가용 RAM은 약5GiB였다.
CM001/007/009 전체 요청 모델 호출0. 이전 CM51 배치를 재개하지 않았다.
다른 작업 프로세스나 원본/실패 로그를 종료·삭제해 자원을 확보하지 않았다. 사전 설계에 정한 저장 입력 경량 실험으로 범위를 줄였다.
이 자원 기준은 이번 로컬 실험의 보호 조건이며 GENOS 제품의 고정 스왑 정책이 아니다.

검증
ADR1166: 격리459파일, 최종23기술조건 통과. 감시 모델의007 실패로 Rejected.
ADR1167: 실제 행동 동일성 수리 후31기술조건 통과, 추가모델0. Proposed / in_sample / decision_eligible=false.
31개는 앞선23개와 중복되므로54개 신규 검사로 합산하지 않는다.
감시 ON/OFF의 실제 로컬 합성 HTTP에서 원문 읽기→최종 판단→답변 저장→동일 요청 재조회 성공을 확인했다. 응답은 합성 모델이며 실제 Qwen 전체 조사 성공과 구분한다.
동일 대상 차단, 새 대상 허용, 미해결 마감, 전송 실패, 호출/시간 예약, 재개, 입력/상태 결속, 독립 원문 부족 복구와 번호 왕복을 검사했다.
초기 실행기 import 충돌·샌드박스 TestClient 대기·감시 phase 어댑터 연결 오류·원문 전달 presentation_id 누락을 보존하고 수리했다.
두 ADR 개별 validate --final 통과. 전역 graph에는 기존9오류가 남아 전체 통과로 보고하지 않는다.

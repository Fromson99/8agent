# CM023에서 실제로 모델에 준 내용과 받은 결과

[의문점 목록](README.md) · [원문 연결](01_CM023_원문연결.md)

**대상:** ADR1150의 CM023 첫 실행. 보관된 원문으로 사전 시나리오를 선택한 실험이다. 현재 MAIN 전체 요청의 입력·호출 횟수를 뜻하지 않는다.

## 1 실제 입력 구성

| 입력 | 실제 전달 내용 |
|---|---|
| 질문 | “상장차익 증여의제는 어떤 요건에서 성립하는가?”와 업무 문맥 |
| 쟁점 | 질문에 대응하는 쟁점 1개 |
| 선택 지침 | 일반 성립 질문은 성립과 제외·예외 경로를 함께 선택. 제시된 ID만 사용하고 본문을 다시 쓰지 않음. 충분하면 ANSWER, 부족하면 RESELECT 또는 SEARCH. |
| 시나리오 후보 | **5개 모두의** ID·제목·업무 용도·조립 완료 본문 |
| 근거 | 조문 출처 항목 10개, 현재 원문 근거 선택지 120개 |
| 제어·출력 계약 | 재선택 잔여 1회, 경로 선택·이유·부족 범위·부족 사실의 응답 스키마 |

## 2 모델이 읽는 조립 본문의 예

PATH2 본문의 **산식·처리 부분 발췌**다. 실제 본문에는 적용 대상·취득 경로·상장 조건, 정산기준일, 기업가치 증가분 계산, 검토 범위와 출처도 들어간다.

> 이익 = (정산기준일 현재 1주당 평가가액 − 증여·취득일 현재 1주당 최초가액 − 1주당 기업가치 증가분) × 증여받거나 유상 취득한 주식등의 수.
>
> 기준금액 = 다음 두 금액 중 적은 금액: ① (1주당 최초가액 + 1주당 기업가치 증가분) × 증여받거나 유상 취득한 주식등의 수 × 30%, ② 3억원.
>
> 이익이 기준금액 미만인 경우에는 법 제41조의3제1항의 적용에서 제외한다. 다른 과세 규정의 적용까지 배제한다는 뜻으로 확대하지 않는다.

이 본문은 **실험 전에 작성된 원문 기반 연구 자료**다. 이번 요청의 모델이 새로 쓴 문장이나 승인된 운영 지식이 아니다. [전체 본문·원문](../../../../../04_EXPERIMENTS/ADR/ADR-1150-scenario-complement-candidate-check/artifacts/package.json)

## 3 실제 모델 응답

선택 결과의 핵심 필드 발췌:

```json
{
  "issue_id": "Q1",
  "path_ids": ["PATH1", "PATH2"],
  "status": "GENERAL_RULE",
  "next_action": "ANSWER",
  "missing_scope": [],
  "missing_facts": []
}
```

선택 이유는 “일반 성립 요건”이므로 성립·산정 경로와 기준금액 미달 제외 경로가 함께 필요하다는 것이었다. [응답 원본](../../../../../04_EXPERIMENTS/ADR/ADR-1150-scenario-complement-candidate-check/artifacts/run-001/concise/cm-023__r1/output-1.json)

```text
사전 구성요소·의존 작성 → 코드가 경로 본문 조립
→ 질문 + 후보 경로 5개 + 원문 근거를 모델에 전달
→ 모델이 PATH1·PATH2 선택 → 선택 본문 그대로 발행
```

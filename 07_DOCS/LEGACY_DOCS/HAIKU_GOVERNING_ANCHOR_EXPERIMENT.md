# Haiku 지배조문 후보 패널 shadow 실험

## 결론

첫 검색 조문 하나를 지배규범으로 취급하는 것은 불안정했다. 동결 51건에서 E1이
골든 조문인 사례는 31/51(60.8%)뿐이었다. 법령·시장 범위, 질문 문언, 법적 참조를
분리한 10개 후보 패널은 제품에 선택된 골든 69/69를 모두 보존했다.

그러나 17건 Haiku 답변 A/B에서 전체 문맥은 12/17, 후보 패널은 11/17이었다.
입력 토큰은 29.4% 줄었지만 의미 정확도는 1건 낮았고 지연도 개선되지 않았다.
불일치 답변 5건을 Haiku 3표결로 재채점해도 full-only 2건, panel-only 1건으로
순손실 1건이 유지됐다. 메인에는 배선하지 않는다.

## 방법

단일 점수 1등 대신 다음 세 채널을 round-robin하여 닫힌 후보 패널을 만든다.

1. `scope`: 질문이 명시한 법령·시장·조문과 조문 표제의 일치
2. `issue`: 실제 질문 핵심어가 조문 본문에 존재하는지
3. `bridge`: 배제·준용·위임·정의·직접 인용 등 선택 조문 사이의 법적 연결

골든·기준답변·사례 ID는 selector 입력에 사용하지 않았다. 모든 생성과 의미 채점은
`claude-haiku-4-5-20251001`만 사용했다.

## 결정론 감사

| 지표 | 결과 |
|---|---:|
| 전체 사례 | 51 |
| 전체 골든 조문 | 70 |
| 제품 검색이 선택한 골든 | 69/70 |
| E1이 골든인 사례 | 31/51 |
| 8개 패널 골든 보존 | 68/70, 49/51 |
| 10개 패널 골든 보존 | 69/70, 50/51 |
| 실제 회수 누락 | `cm-031` 1건 |

`cm-031`은 코스닥시장 상장규정 제5조가 선택 목록에 없으므로 어떤 후단 재정렬로도
복구할 수 없다.

## 법적 참조 결함 수정

`cm-043`에서 상법 제415조는 본문으로 제388조를 감사에 준용하지만, 색인 간선은
단순 `인용`으로 저장되어 있었다. 또한 기존 타입 로직은 E1에서 이어진 경로만 보아
선택 목록 안의 제415조↔제388조 쌍을 평행 문맥으로 처리했다.

shadow 타입 계층에서 다음을 보완했다.

- 표제가 `준용규정`인 조문의 outgoing 인용을 `준용`으로 복구
- E1과 분리돼 있어도 선택 조문 사이에 존재하는 typed pair를 별도 표시
- typed pair는 후보 패널의 bridge 신호로 쓰되, 그 사실만으로 결론 근거 A로
  승격하지 않음

이 수정으로 `cm-043`의 두 골든 조문이 후보 패널에 함께 들어왔다.

## Haiku 17건 A/B

같은 동결 회수 결과에서 답변 생성 순서를 사례별로 교차하여 full context와
10개 패널을 비교했다.

| 지표 | 전체 문맥 | 10개 패널 |
|---|---:|---:|
| 의미 정답 | 12/17 | 11/17 |
| 입력 tokens | 633,586 | 447,530 |
| 입력 절감 | - | 29.4% |
| p50 | 6.047초 | 6.503초 |
| p95 | 8.565초 | 8.966초 |
| 둘 다 정답 | 9 | 9 |
| full만 정답 | 3 | - |
| panel만 정답 | - | 2 |
| 둘 다 오답 | 3 | 3 |

단일 채점 불일치 5건의 고정 답변을 각 3회 재채점한 결과는 full-only 2건,
panel-only 1건이었다. `cm-024`의 최초 차이는 채점 노이즈로 사라졌지만,
`cm-021`과 `cm-039`의 패널 회귀는 유지됐다.

### 실제 회귀

- `cm-021`: 원문은 일반 6개월, 증여세 대상 3개월인데 패널 답변 첫 문장에서
  상속세 3개월로 뒤집어 썼다. 골든 조문은 패널에 있었으므로 순수 조건-수치 포섭
  오류다.
- `cm-039`: 제361조와 제393조가 모두 패널에 있었지만, 사내규정 제정의 기본
  업무집행 권한을 이사회로 결론 내리지 않고 불충분하다고 회피했다. 역시 회수
  손실이 아니라 법률 적용 오류다.

### 개선

- `cm-051`: 패널 답변이 공동주관회사 선임 의무의 5%/10% 기준과 시행규칙
  제14조 준용을 함께 설명해 3표결에서도 개선이 유지됐다.

## 판단

불필요한 문맥이 많은 것은 사실이지만, 골든을 보존한 축소만으로 Haiku의 조건·수치
매핑과 기관 권한 포섭이 좋아지지는 않았다. 오히려 비골든 보조 문맥이 해석의 안전
장치로 작동하는 사례가 있어, 문맥 수를 줄이는 것과 의미 정확도는 단조 관계가 아니다.

다음 우선순위는 추가 pruning이 아니라 답변의 고위험 명제를 검사하는 것이다.

- 조건별 수치·기간 매핑의 역전 또는 자기모순
- `하여야 한다`와 `할 수 있다`의 양태 변경
- 본문·단서·예외의 적용 방향
- 주주총회·이사회·감사 등 기관별 권한 귀속
- 불명확한 문언을 확정적으로 단정한 경우

이 검사는 전체 답변을 다시 쓰는 라우터보다, 위험 명제를 표시하고 기존 답을
보존하는 shadow veto로 먼저 평가해야 한다.

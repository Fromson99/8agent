# 공통모듈화

기존 과제의 파이프라인과 기능을 공통 모듈로 정리한 명세·입출력 계약·코드 위치 안내를 모은다. 모듈별 폴더에 문서와 예제를 함께 보관한다. 제품 코드는 기존 브랜치 위치에서 관리한다.

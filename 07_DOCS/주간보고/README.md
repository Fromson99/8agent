# 주간보고

법률·규정 Q&A AI 에이전트(과제3·5) 주간보고 모음. 파일 하나가 한 번 제출한 보고서다.

- 파일 이름: `YYYY-MM-DD_주간보고.txt` (날짜는 그 보고의 금주 시작 월요일)
- 형식: 전주 / 금주 두 부분, 각각 [수행 업무] [Front 협의사항] [새 이슈·현업 요청] [특이사항]
- 다음 주 작성 시 이번 보고의 "금주"를 그대로 "전주"로 옮기고, 새 "금주"를 쓴다.
- 온톨로지 관련 내용은 2026-11-09 보고부터 제외(사용자 지시).

| 파일 | 전주 | 금주 |
|---|---|---|
| 2026-11-02_주간보고.txt | 10.26 ~ 10.30 | 11.02 ~ 11.06 |
| 2026-11-09_주간보고.txt | 11.02 ~ 11.06 | 11.09 ~ 11.13 |
